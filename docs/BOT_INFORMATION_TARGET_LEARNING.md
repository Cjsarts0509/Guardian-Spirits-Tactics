# 정보 수집 대상 선택 학습 1차

## 범위

동맹 지연 후보를 종료한 뒤, 기본 봇이 이미 정보 수집을 선택한 순간의 **대상만** 바꾸는 학습을 수행했다. 스킬·지정 이름·해당 행동 기회는 유지하며 동맹 제안은 건드리지 않는다. 이후 행동과 자원 상태까지 동일하게 유지한다는 뜻은 아니다.

보석/확인/스캔 중 현재 스킬이 사용 가능하고, 자기 관찰의 배정 확률로 다음 두 조건을 만족하는 다른 대상이 있을 때 적격이다.

- 적일 확률이 원래 대상보다 높다.
- 기대 정보량이 양수이며 원래 대상의50% 이상이다.

공개 보호·사망·자기 자신·이미 정체를 아는 대상은 제외한다(보호 무시 스킬 예외). 적격 대상 중 적일 확률이 가장 높은 대상을 선택하고 동률이면 뷰 순서를 유지한다. 이 대안 생성 규칙은 수동 설계이며, 대안을 사용할지 여부를 보상에서 학습한다. 숨은 정체·효과로 합법성을 시험하지 않는다.

## 사전 설계

각 current 봇의 첫 적격 기회에서 기존/대체 대상을50%로 무작위 배정한다. 나머지 행동은 기본 정책이다. 탐색 RNG는 정책/엔진 RNG와 분리한다. 입력 셀은 스킬 종류3개×경과6분 전/이후의6개다. 보상은 최종 자기 진영 승리1/패배0/90분 미종료0.5. 한 판의 여러 봇이 보상을 공유하므로 관찰 행을 독립 대전 표본으로 해석하지 않는다.

학습 시드95000–95047,4모드×3합성 상대×진영/순서 교차4판,8–12인,250ms 틱·활동확률0.012. Beta(2,2) 평균 보정 후 양쪽32관찰 이상이며 대체 가치가 기존보다0.03 초과 높아야 전환한다. 이는 후보 선택 규칙이며 통계적 유의성 검정이 아니다.

후보가 나오면 개발96000–96007에서 점수차이>0 및 미종료/초반실패 증가 없음, 그 뒤 고정 후보로 최종97000–97015를 실행하도록 설계했다. 최종95% 시드 구간 하한>0과 안전 게이트를 통과해야 승격 근거로 인정하며 자동 운영 반영은 없다.

## 결과

**2,304판 전부 종료,6,799개 선택 기록**을 수집했다.

| 조건 | 기존 관찰 수/가치 | 대체 관찰 수/가치 | 선택 |
|---|---:|---:|---|
| 보석·6분 전 | 473 / 0.6017 | 472 / 0.6134 | 기존 |
| 보석·6분 이후 | 107 / 0.7297 | 85 / 0.7416 | 기존 |
| 확인·6분 전 | 1,626 / 0.7196 | 1,584 / 0.7135 | 기존 |
| 확인·6분 이후 | 11 / 0.8667 | 11 / 0.7333 | 표본 부족·기존 |
| 스캔·6분 전 | 1,181 / 0.7376 | 1,226 / 0.7317 | 기존 |
| 스캔·6분 이후 | 15 / 0.8421 | 8 / 0.7500 | 표본 부족·기존 |

보석 셀의 학습 추정 차이는 약+0.0118로 사전0.03 기준에 못 미쳤고, 나머지도 전환 조건을 만족하지 못했다.6셀 모두 기존 선택을 유지하므로 **행동이 바뀌는 후보를 얻지 못했다.** 개발·최종 시드는 계획대로 미사용이다. 이는 독립 대전에서 대상 교체가 무효라고 입증한 결과도, 보석 승률이 개선됐다는 결과도 아니다.

결과를 본 뒤 기준을 낮추거나 늦은 확인/스캔 표본을 추가해 후보를 만들지 않았다. 원자료에 경과 시간을 명시적으로 보강한 뒤 같은 설계로 재실행했으며 모델이 동일함을 대조했다. 실제 실험 자료의 판 수는 재실행을 중복 합산하지 않았다.

## 검증·현황

원자료에서 첫 적격 기회 유일성6,799개, 대전 최종 보상 연결, 같은 스킬·이름/다른 대상, 대체 정보량·적확률 조건, 경과 시간/스킬 종류 셀, 재학습 모델과 소스 해시를 대조한다. 저장된 점수의 경계 검증이며 모든 순간의 자기 뷰를 다시 재생한 것은 아니다.

4회귀는 보상 기반 전환/표본 부족 유지, 잘못된 입력 거절, 동맹·공격 제외, 실제 자기 뷰의 대상 교체·동일 스킬/이름·입력 불변·공개 보호 제외·엔진 허용 사례를 확인한다. 전체428테스트·타입 검사·서버/웹 빌드 통과. 학습은 오프라인 스크립트에만 있으며 운영 정책 변경은 없다.

다음 연구에서는 특징을 계속 늘리기 전에, 같은 장면에서 대상 하나만 바꾼 대응 실행으로 학습 보상의 신호를 점검하는 것이 필요하다. 이번 자료에 맞춰 보상 가중치를 조정하거나 후보 승격을 주장하지 않는다.
