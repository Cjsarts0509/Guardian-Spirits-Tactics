# 동맹 필요도·대체 정보 행동 가치 학습 2차

## 설계

1차 마나·시간 모델은 행동 변경 후보를 얻지 못했다. 2차는 각 current 봇의 첫 동맹 제안에서 **동맹 실행/이번 기회 대기/정보 수집**을 비교한다. 이후에는 기존 정책으로 복귀한다. 기본 공표 배율1·재시도 실험OFF·확장 탐색OFF이며 서비스 정책은 수정하지 않았다.

자기 관찰로 계산한3개 이진 특징의8셀을 사용한다.

- 살아 있는 자기 동맹이 하나라도 있는가.
- 제안 대상의 정체가 자기 관찰로 확정됐고 아군인가. 확정되지 않은 공표는 이 조건을 만족하지 않는다.
- 사용 가능한 확인/스캔 중 양의 예상 정보량을 주는 대안이 있는가.

대안 선택기는 자기 뷰·관찰 지식으로 전체 배정 확률을 계산하고, 사용 가능하다고 표시된 확인/스캔의 대상·이름 조합 중 예상 정보량이 가장 큰 것을 고른다. 알려진 정체/사망/공개 보호 대상은 제외한다(보호 무시 스킬 예외). 엔진을 시험 실행해 숨은 보호를 알아내지 않으므로 선택이 실제로 거절될 수 있다. 입력 뷰·지식과 정책 RNG는 변경하지 않는다.

학습91000–91047, 개발92000–92007, 최종93000–93015.4모드×3합성 상대×진영/순서 교차4판,8–12인,250ms 틱·활동확률0.012. 학습은 각 셀에서 가능한2~3행동을 균등 무작위 배정한다. 보상은 최종 자기 진영 승리1/패배0/90분 미종료0.5. 같은 판 안에서 여러 봇이 탐색하고 보상을 공유한다. 관찰 행을 독립 대전 표본으로 해석하지 않는다.

Beta(2,2) 평균 보정, 실행/대안 각32관찰 이상, 대안 가치가 실행보다0.03 초과 높으면 그중 가장 높은 대안을 선택한다. 이는 사전 후보 선택 규칙이며 유의성 검정이 아니다. 개발 평균 점수차이>0이고 미종료/초반 실패가 증가하지 않아야 최종 평가한다. 승격 근거는 최종 시드 단위 부트스트랩95% 하한>0과 안전 게이트이며 자동 운영 적용은 없다. 이 설계와 후보를 결과 확인 후 변경하지 않았다.

## 학습 결과

학습 **2,304판·5,922개 첫 선택**, 전부 종료.8셀 중 한 셀만 기존 행동에서 달라졌다.

| 선택 조건 | 실행 관찰/가치 | 대기 관찰/가치 | 정보 수집 관찰/가치 | 학습 선택 |
|---|---:|---:|---:|---|
| 살아 있는 자기 동맹 없음·대상이 확정 아군·정보 대안 있음 | 365 / 0.6829 | 290 / 0.7143 | 283 / 0.7178 | 정보 수집 |

나머지7셀은 실행을 유지했다. 일부 셀은 표본이 부족했다. 가치는 탐색 분포의 학습 추정치이며 독립 검증 승률이 아니다. 마나·시간만 사용한1차의 결과와 시드/탐색 행동이 달라 숫자를 직접 개선율로 비교하지 않는다.

학습·개발·최종 총 **4,608판**. 후보는 미채택이며 기본 AI에 연결하지 않았다. 이후 실험에 최종93000–93015를 튜닝용으로 재사용하지 않는다.1차에서 보존한89000/90000 구간도 이번에 사용하지 않았다.

## 검증·산출물

전체424테스트(규칙377·서버47), 타입 검사, 서버·웹 빌드 통과.4회귀는 충분한 표본의 대안 선택/부족 표본 유지, 자기 관찰 특징과 입력 불변성, 실제 엔진에서 정보 대안 허용 및 공개 보호 제외, 선택 반환/누락 시 복귀를 확인한다.

- 코드: `packages/rules/scripts/ally-context-model.ts`, `ally-context-experiment.ts`, `verify-ally-context.ts`.
- 설계·모델·관찰·대전·요약·검증: `docs/evaluations/ally-context/`.
