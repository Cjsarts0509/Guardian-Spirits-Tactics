# 정체 배정 계산 비용 개선

## 변경과 보존 범위

`bot-belief.ts`의 부분집합 DP에서 이미 배정되었거나 후보에서 제외된 역할을 반복 순회하지 않도록 양의 가중치 비트마스크를 사용한다. 남은 비트는 기존 역할 인덱스의 오름차순으로 처리하므로 유효 항의 부동소수점 덧셈 순서를 유지한다. 역할 수별 부분집합 원소 수 표도 재사용한다. 최대 12명이며 전체 크기별 표를 모두 생성해도 8,191바이트다. 공유 표에는 관찰·확률·정체 정보가 없다.

공표 가중치, 실제 봇의 기억, 확정 정보와 후보 제약, 믿음 캐시의 무효화 조건, 표본 추출과 RNG, 액티브·패시브·쿨다운 및 탐색 예산은 유지한다. 모든 정책 입력은 기존 자기 관찰 경계를 따른다.

비교 기준은 수정 전 로컬 `73a7e26` / 원격 `2c48c2552da872a0804a99ac28d453d5fa02f7f2`다. 각 원자료에 정책과 측정 드라이버의 SHA-256을 기록했다.

## 배정 계산과 동등성

Node 24.19.0 x64 로컬에서 4모드×5시드(68000–68004), 8–12명, 다섯 후보 제약의 합성 위치 1,000개를 사용했다. 제한된 후보는 평가용으로 구성한 합성 관찰이며 정책에 상대 실제 정체를 추가로 전달한 결과가 아니다. 같은 위치를 순서를 교차해 3회 측정했으며 준비 복사는 측정 밖에서 수행했다. 별도 워밍업 제외는 없다.

| 후보 조건 | 수정 전 p95(ms) | 수정 후 p95(ms) |
|---|---:|---:|
| 넓은 후보·미공표 | 0.6063 | 0.3093 |
| 넓은 후보·공표 | 0.6153 | 0.2939 |
| 절반 확정 | 0.2813 | 0.1289 |
| 전부 확정 | 0.3090 | 0.0947 |
| 모순 | 0.2628 | 0.1225 |

각 행은 같은 200위치의 3회 반복 600표본이다. 독립된 600판이 아니다. p95는 약 49–69% 줄었지만 최대값은 미공표(2.5673→3.0046ms)와 모순(1.2160→1.9468ms)에서 증가했다. 모든 꼬리 지연이 줄었다고 해석하지 않는다.

확률·기억 3,000회, 배정 표본·RNG·기억 1,000위치, 별도 시드 69000–69004의 기본/확장 행동·기억·입력 400회가 정확히 일치했다. 각 위치에서 최대 16개 세계를 요청했으며 모순 조건은 표본이 없다.

전체 대전은 새 시드 70000–70004로 기본/확장 각각 80조건을 전후 실행했다. 총 320회 실행에서 10,060회 시도 행동의 시각·플레이어·선택·결과·이벤트와 전체 결과 객체가 일치했다. 이 비교는 새 승률 개선 증거가 아니다.

## 전체 정책 판단 비용

별도 새 시드 71000–71004로 기본/확장 각각 800위치(총 1,600 정책/위치 쌍)를 준비했다. 4모드, 8–12명, 정체 공개 여부와 턴까지 50/10초 조건이며 마나 100·공표 설정은 평가용 합성 상태다. 3회 순서 교차 측정에서 행동·전체 지속 기억 4,800회, 입력 불변과 확장 내부 수순 반환값 800위치가 일치했다. 준비 복사는 측정 밖이고 워밍업은 제외하지 않았다.

| 정책 / 정체 / 턴까지 시간 | 수정 전 p95(ms) | 수정 후 p95(ms) |
|---|---:|---:|
| default/identities-private/turn-in-50s | 1.4031 | 1.0551 |
| extended/identities-private/turn-in-50s | 45.2658 | 42.6932 |
| default/identities-public/turn-in-50s | 0.6897 | 0.4768 |
| extended/identities-public/turn-in-50s | 0.8197 | 0.5018 |
| default/identities-private/turn-in-10s | 1.3912 | 0.8003 |
| extended/identities-private/turn-in-10s | 67.2312 | 64.4409 |
| default/identities-public/turn-in-10s | 0.6359 | 0.4404 |
| extended/identities-public/turn-in-10s | 0.7735 | 0.5127 |

각 행은 같은 200위치×3회다. 기본 정책의 p95 감소는 약 25–42%다. 비공개 확장 탐색은 약 4–6% 감소에 그쳐 다른 탐색 비용이 남아 있다. 공개·50초 확장 조건의 최대값은 51.0276→51.9864ms로 증가했다. 이 표의 수정 전 수치도 이번 별도 실행에서 새로 측정한 값이며 과거 다른 실행의 절대 시간과 직접 비교하지 않는다. 로컬 합성 판단 비용으로 VM 전체 틱 개선을 보장하지 않는다.

## VM 기준선과 남은 확인

사용자가 제공한 Node 22.23.3 arm64 콘솔 요약에서 기본 1방/기본 4방/고빈도 4방의 틱 p95는 6.59/5.07/35.94ms, 최대는 10.93/10.78/82.03ms였다. 이벤트 루프 최대는 17.83/17.01/90.77ms이고 세 조건 모두 처리 250ms 초과와 HTTP/WS 오류가 0이었다. 상위 간격은 CPU 활동과 겹쳤지만 프로세스 CPU는 여러 스레드를 포함한다. cgroup throttling은 unknown이므로 없었다고 단정할 수 없다.

이것은 사용자 콘솔 증거다. `/tmp/gst-audit.5tE7c4/gst-audit-results.tar.gz` 원자료를 직접 받거나 해시·소스 커밋을 대조하지 않았다. 최신 최적화의 VM 효과, 장기 부하, GC 할당 원인과 인간 연결 부하는 아직 확인하지 않았다. 운영 서비스·main·릴리즈 변경 없이 동일 임시 부하 runner로 새 소스를 재측정한다.

## 재현

수정 전 체크아웃을 만들고 의존성을 준비한 뒤 `packages/rules`에서 실행한다. JSON은 저장소 루트 `docs/evaluations/`에 있다.

```bash
node --import tsx scripts/belief-cost-audit.ts /absolute/baseline/packages/rules/src/bot.ts > ../../docs/evaluations/belief-cost-audit.json
node --import tsx scripts/belief-compatibility.ts /absolute/baseline/packages/rules/src/bot.ts > ../../docs/evaluations/belief-compatibility.json
node --import tsx scripts/belief-policy-cost.ts /absolute/baseline/packages/rules/src/bot.ts > ../../docs/evaluations/belief-policy-cost.json
```

비용 측정은 다른 테스트·빌드·부하 측정과 동시에 실행하지 않는다. 이번 변경의 전체 규칙 332개+서버 23개 테스트, 타입 검사와 서버·클라이언트 빌드가 통과했다.
