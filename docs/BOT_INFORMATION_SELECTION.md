# 운영 봇 대비 전체 성능 개선: 보석 정보 대상 선택

## 결과와 적용

운영 기본 봇(main 7e18a65)과 새 시드 **100개·1,600판**을 직접 대결한 최종 정책은 **875승 / 725패**, 네 모드 동일 가중 평균 **54.6875%**, 시드 블록 부트스트랩 95% 구간 **[53.3125%, 56.125%]**였다. 전체 구간이 대등한 정책의 기준 50%를 넘었다.

| 모드 | 판수 | 새 정책 승/패 | 승리 점수 | 시드 95% 구간 |
|---|---:|---:|---:|---:|
| 내전 | 400 | 214 / 186 | 53.5% | 50.0–57.25% |
| 태초 | 400 | 207 / 193 | 51.75% | 49.75–54.0% |
| 황야 | 400 | 254 / 146 | 63.5% | 60.0–67.25% |
| 트롤 | 400 | 200 / 200 | 50.0% | 50.0–50.0% |

전체 개선은 확인됐지만 **각 모드가 모두 유의하게 개선됐다는 뜻은 아니다**. 태초의 구간은 50%를 포함하며 트롤은 기존 동작을 유지한다. 개선의 큰 부분은 황야에서 발생했다. 위 구간은 명시한 자기 대결 환경에 관한 것이며 사람 상대 승률이 아니다.

## 변경

내전·태초·황야의 진실의 보석 대상은 다음 점수를 최대화한다.

`보석 결과의 정보량 × (1 + 적 진영일 확률)`

현재 배정 믿음과 자기 뷰만 사용한다. 보석으로 구별할 수 없는 지휘관 후보들만 남아 결과 정보량이 0인 대상은 건너뛴다. 믿음이 일관되지 않으면 기존 선택으로 복귀한다. 트롤의 대상 선택·난수 소비는 기존과 같다. `gemTargets: 'legacy'`는 비교용 기존 선택을 지정한다. 전투 우선순위·스킬 비용·쿨다운·공표 규칙은 변경하지 않는다.

## 선택과 검증의 분리

먼저 시드 17000–17029에서 정보량, 적 가중 정보량, 확인 성공 확률을 사용하는 세 후보를 운영 봇과 직접 비교했다(각 480판, 총 1,440판). 전체 점수는 53.125%, 55.625%, 52.7083%였다. 적 가중 정보량의 모드별 점수는 내전 56.6667%, 태초 52.5%, 황야 63.3333%, 트롤 50.0%였다. 이 개발 결과만 보고 **트롤을 기존 선택으로 두는 최종 후보를 고정**했다.

이후 사용하지 않은 시드 18000–18099에서 최종 후보를 검증했다. 결과를 보고 모드나 계수를 다시 바꾸지 않았다. 승격 판단은 전체 시드 95% 구간이 50%를 넘고, 모드별 관측 점수가 50% 이상이며, 종료·정보 은닉·초반 공격 실패 회귀가 없는지를 기준으로 했다. 이 기준은 모드마다 통계적으로 비열등함을 증명하는 기준은 아니다.

운영 코드로 분리한 최종 구현을 같은 검증 시드에서 다시 실행해 후보와 **모든 시드별 점수 및 전체 집계가 동일함**을 확인했다. 이 재실행은 독립 표본 추가가 아니므로 검증 표본 수를 3,200판으로 부풀리지 않는다. 최종 소스 해시는 information-selection-final.json에 포함한다. 개발·후보 단계 원본은 PR #4의 overall-information-*.json에 보존한다.

대결은 같은 역할→ID 배정에서 두 진영과 플레이어 순서를 교환한 4판/시드/모드, 8–12명, 기본 90초 턴, 틱 250ms, 활동도 0.012, 제한 90분이다. 각 시드에서 네 모드 점수를 동일 가중 평균하고 시드 100개를 2,000회 재표본한다. 인원·진영·순서와 독립 단위를 분리해 전체 평균을 계산했다.

고정 기준은 main 7e18a65의 기본 truthful 정책과 동일한 결정 본체인 c505d4b pre-adaptive 스냅샷이다. 선택 옵션을 끈 개발 코드와 고정 기준의 5개 시드·80판 대조는 네 모드 모두 정확히 50%였다. 최종 트롤 400판은 고정 기준과 같은 동작을 유지해 50%였다.

## 검증 및 한계

최종 1,600판 모두 종료했고 초반 공격 실패는 0건이다. 새 정책 스킬 거절률은 내전 약 0.38%, 황야 약 0.60%, 태초·트롤 0%였다. 타입 검사·전체 테스트 **279개**(규칙 260개·서버 19개)·서버/클라이언트 빌드 통과. 새 테스트는 같은 정보량에서 적 확률 우선, 지휘관만 남은 0정보 대상 제외, 트롤의 기존 행동·난수 경로 유지를 검증한다.

전체 개선 주장은 이 고정 운영 봇과의 합성 직접 대결에 한정한다. 실제 사람의 공표·동맹·채팅 분포나 다른 활동도·턴 길이에서도 개선되는지는 별도 검증이 필요하다. PR #4의 공표 시간 제약 실험 결과를 개선의 증거에 합산하지 않는다.

재현은 `packages/rules`에서:

```sh
node --import tsx scripts/information-selection.ts 100 18000 > ../../docs/evaluations/information-selection-final.json
```
