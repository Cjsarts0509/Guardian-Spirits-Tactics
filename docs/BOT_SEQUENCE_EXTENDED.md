# 성장·희생·다음 턴 수순 평가

후속 우선순위 복구와 독립 검증은 [BOT_TACTICAL_PRIORITY.md](BOT_TACTICAL_PRIORITY.md)를 참조한다. 이 문서는 수정 전 확장의 기록이다.

운영 기본 정책은 변경하지 않았다. `sequenceSearch: true`, `sequenceSkills: true`, `sequenceExtended: true`를 함께 지정하는 실험이다. 최종 정책은 원격 `936c5f439254e209ea4b0c2ee5bea1a57a336266`, 로컬 `ceda7ad`, 트리 `6ab7ffdcd0dbc2bf0718637af796235c2cab4887`로 고정했다. 이전 25종 후속 스킬 정책(`b7c56ee`)을 직접 비교 상대로 사용한다.

## 구현 범위

| 범위 | 평가 조건과 처리 |
| --- | --- |
| 최종 진화 | 본인의 레지스턴스·아이언 스킨·상급 공격을 모두 확인한 경우만 후보. 획득한 학살을 후속 행동에서 실행 |
| 전투 성장 | 사신트 전투 숙련, 세이로우 광폭화, 카즈로우 쿨다운 초기화. 자기 공표·차단 사유·쿨다운·사용 횟수 검사 |
| 보석 성장 | 고대의 주술은 본인 조각 단계·마나·쿨다운을 검사. 다음 턴 진명 보석 획득과 연결 |
| 매스 텔레포트 | 실제 규칙은 단일 대상 즉사기. 일반·상급 버전의 슬롯, 비용, 횟수를 검사하고 확인된 적만 대상으로 삼음 |
| 희생 | 무모한 돌진은 확인된 적 지휘관, 파괴자의 인도는 확인된 데카의 관측된 매드니스 제거 후, 영혼의 벽은 카이를 확인한 상황의 확인된 아군 지휘관만 후보 |
| 다음 턴 | 30초 이내이며 모든 생존자의 공표를 관측한 경우, 실제 턴 엔진으로 기본·동맹·진명 마나, 보석, 쿨다운 경과와 이후 행동을 평가 |
| 공표 경계 | 첫 행동의 공표가 마지막 미공표자를 해소하는 경우에도 다음 턴을 예측. 다른 미공표자의 자동 공표는 확정 추측하지 않음 |
| 패시브 | 가설 엔진의 목숨·보디가드·매드니스 및 공격 후 마나 회복을 유지. 관측한 족장 보호도 복원. 패시브는 시전 후보가 아님 |

첫 후보 최대 4개, 배정 표본 8개, 자원 스트레스 끝점 2개, 대응 유무 2개로 최대 128수순이다. 확장에서는 확인 후보 2개와 성장/희생 후보 2개를 비교하고 여유가 있으면 진명 공표를 넣는다. 기존의 첫 행동·10초 이내 후속 행동에, 조건부로 다음 턴 직후의 세 번째 행동을 더한다. 상대는 각 대응 지점에서 자기 관찰로 확인한 적에게만 행동한다. 이는 고정 스트레스 정책이며 인간 행동 확률이 아니다.

후속 정책과 캐시는 자기 뷰·수신 가능한 사건만 입력받는다. 실제 상대의 숨은 정체·마나·보석·flags를 읽지 않는다. 상대 보석은 알려지지 않았으므로 가설의 강/약 끝점에서 0 또는 3으로 두며 실제값으로 해석하지 않는다. 자기의 공개 메타데이터상 시간 해금만 다음 턴까지 예약한다. 미관측 과거 예약 작업과 상대의 전체 과거 비공개 기억은 복원하지 않는다.

희생은 기존 개인 생존 패널티 대신 팀의 사망·방어 자원·승패로 평가한다. 자기 사망은 일반 역할 4점, 지휘관 20점의 손실이며 최종 승패 ±1000점이 우선한다. 자기 보석과 새 스킬 획득에 각각 단계당 0.5점의 보조 가치를 둔다. 이 값은 학습된 승률이 아닌 명시적인 평가 휴리스틱이다. 희생은 즉시 실행하는 고정 후속 우선순위에 넣지 않고 첫 후보 간 비교에서만 고른다.

## 평가 방법과 소스 고정

개발 160판(시드 51000–51009)은 수정 전 `634d5be` 정책에서 51.875%, 시드 부트스트랩 95% 구간 46.875–56.875%였다. 이어서 수정 전 400판(52000–52024)을 완료했고 원자료를 `sequence-extended-before-publication-fix-*-25.json`에 보존했다. 첫 공표와 다음 턴을 연결하는 경계 사례를 보완한 뒤에는 이 자료를 최종 독립 평가로 사용하지 않았다. 수정은 회귀 사례에 따른 것으로, 수정 전 점수에 맞춘 가중치 튜닝을 하지 않았다.

최종 정책은 새 시드 54000–54024에서 모드당 100판, 총 400판을 평가했다. 같은 시드의 정방향/역방향 좌석과 양 진영을 교차한 네 경기를 한 블록으로 묶는다. 인원은 8–12명, 틱 250ms, 행동 확률 0.012, 종료 제한 90분이다. 비교 상대는 동일 엔진에서 새 옵션만 끈 이전 25종 정책이며, 이전 소스와의 80개 조건 결과 일치를 별도로 검증했다. 서로 다른 단계의 운영 정책 대비 승률을 개선 폭으로 빼지 않는다.

| 모드 | 승 / 패 | 점수 | 시드 부트스트랩 95% 구간 |
| --- | --- | ---: | --- |
| 내전 | 48 / 52 | 48% | 44%–52% |
| 태초 | 50 / 50 | 50% | 47%–53% |
| 황야 | 46 / 54 | 46% | 39%–52% |
| 트롤 | 46 / 54 | 46% | 40%–52% |
| 전체 | 190 / 210 | 47.5% | 45%–49.75% |

모두 종료했고 양측 초반 공격 실패는 0회다. 확장은 12,925회 행동 시도 중 9회 거절(0.070%), 비교 정책은 13,113회 중 14회 거절(0.107%)이었다. 스킬별 거절 집계도 원자료에 보존했다. 거절을 공격 실패로 합치지 않았다. 이 표본에서 전체 구간 상한은 50% 미만이고 모드별 개선도 입증하지 못했다. **새 확장은 이전 25종 정책보다 전체 열세이므로 기본 활성화·운영 승격을 하지 않는다.** 모드별 구간은 다중 비교 미보정이며 25개 시드 블록의 결과이므로 더 큰 모집단에 대한 확정적 승률은 아니다.

동일한 합성 400위치에서 이전 정책과 확장을 번갈아 먼저 실행한 비용 비교다. 모든 생존자는 진명을 공표했고 정체는 비공개이며 다음 턴까지 10초인 조건이다.

| 지연 | 이전 25종 정책 | 확장 |
| --- | ---: | ---: |
| 중앙값 | 26.17ms | 29.77ms |
| p95 | 42.73ms | 53.02ms |
| 최대 | 64.98ms | 97.33ms |

첫 행동 선택 차이는 25/400위치였다. 실제 수순은 최대 96개였고 정책 상한은 128개다. 후속 정책 평가 2,082회, 자기 관찰 캐시 적중 35,792회였다. 추가 턴 평가에는 비용이 들며 성능 개선으로 소개하지 않는다. 로컬 Node 24 수치이고 측정 중 타입 검사 작업도 있었다. 실행 순서 교차로 같은 위치를 비교했지만 VM Node 22/라이브 호출 분포의 지연을 대신하지 않는다. 원자료는 `sequence-extended-cost-audit.json`, 대전 집계는 `sequence-extended-heldout-summary.json` 및 모드별 파일이다.

## 검증 및 해석 범위

최종 전체 테스트 339개(규칙 320 + 서버 19), 타입 검사, 클라이언트/서버 빌드를 수행했다. 새 회귀 검증은 진화 전제·학살 획득, 미확인 대상 공격 금지, 희생의 최종 승패, 족장 보호, 매스 텔레포트 비용, 턴 마나·보석·쿨다운, 자동 공표 예측 제한, 첫 공표 뒤 턴 보너스, 상대 비공개 자원 변경에 대한 결정 불변성을 포함한다.

새 옵션을 끈 최종 소스와 이전 25종 소스를 80개 대전 조건에서 각각 실행한 160개 결과 객체가 모두 일치했다. 이전 기본 행동을 그대로 유지하는 호환성 증거이며 개선 승률 표본은 아니다. 원자료는 `sequence-extended-final-compatibility.json`이다.

이 단계에서 약속한 성장·희생·획득 즉사기·관측 가능한 다음 턴 평가와 통합 검증은 완료했다. 장기간 다중 턴 최적 전략, 모든 정보기의 지연 수순, 상대의 관측되지 않은 기억/예약 작업, 자원 끝점의 전체 이력 도달 가능성, 인간 상대 실력 및 VM 실측 지연까지 완료한 것은 아니다. 자기 효과가 있으면 탐색을 건너뛰는 보수적인 제한도 유지한다. 승률 증거와 비용을 확인하지 않은 전 모드 기본 활성화·운영 릴리즈·VM 업데이트는 하지 않았다.
