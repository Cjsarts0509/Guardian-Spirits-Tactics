# GST v1.33 공통 시스템 명세 (core)

근거는 `GST_v1.33_war3map.j`의 함수명. 인덱스 규칙은 다음과 같다.
- **슬롯 번호(1~12)**: 모드별 캐릭터 순번이다. `X[slot]`=유닛ID, `b[slot]`=캐릭터명, `O[slot]`=그 캐릭터를 맡은 플레이어. `j[slot]`=추가 목숨.
- **플레이어 번호(1~12)**: `GetPlayerId+1`. `o[p]`=영웅, `A[p]`=현재 공표 이름, `D[p]`=그 플레이어의 슬롯, `H[p]`=색상코드+"[p] 이름", `f[p]`=공격 대상, `d[p]`=스캔 대상, `K[p]`=영혼의 회복, `Rv[p]`=미명의 안개.
- **정체** = `b[D[p]]` = 영웅 고유이름. **진명** = `A[p] == 정체`.

## 1. 게임 시작 흐름

| 단계 | 함수 | 내용 |
|---|---|---|
| 0 | main | 12슬롯 모두에 메모 유닛 `u000`(참가자: A011/A014/A012/A013/A01E)을 만든다. 배열을 초기화한다. |
| 1 | Qr | 퀘스트 로그(제작진/명령어/개요)를 만든다. |
| 2 | Yr (0.01s) | Player(0)(1번 슬롯 = 방장)에게만 모드 다이얼로그를 띄운다. 버튼: 랜덤 / 왕자들의 내전 / 태초의 전쟁 / 리델루트 황야 / 트롤 부족의 반란. 메시지는 "모드 선택 (제한시간 15초)". 전원에게 "방장이 모드를 선택중입니다." 표시. 타이머 T=15s. |
| 3 | ri | 클릭하면 모드를 정한다. 랜덤은 `GetRandomInt(1,4)`로 고른다(1=내전, 2=태초, 3=리델루트, 4=트롤). `U`와 `X[1..12]`를 세팅하고 모드 퀘스트(Sr/Tr/Ur/Wr)를 만든다. 전원에게 "모드 - <U>", "직업을 분배중입니다." 표시 후 곧바로 ni. |
| 4 | ni | 15초 동안 선택이 없으면(`U=="없음"`) **왕자들의 내전**으로 강제한다. 문구에 "5초 후 게임이 시작됩니다"가 있지만 실제 대기는 없다. 플레이어 이름을 "[n] 이름"으로 바꾸고 `H[n]`을 만든다. |
| 5 | Ei | 인원(유저 & PLAYING)에 따라 12자리 패턴으로 쓸 슬롯을 정한다(§1.1). **2~7명이면 전원 패배**("사람 수가 부족합니다!"). 1명은 테스트 모드다. 배정 방식: 슬롯 1부터 차례로, 사용 슬롯마다 남은 플레이어 중 `ForcePickRandomPlayer`로 한 명을 뽑는다(균등 무작위 순열). 뽑힌 플레이어의 시작 위치에 영웅을 만들고, 본인에게 "당신은 <이름>입니다."(8초)를 보여준다. |
| 6 | Bi | 슬롯별 목표 문구를 본인에게만 보여준다. 포스 B[1]/B[2]를 편성하고 `j[]`와 시작 동맹을 설정한다(§1.2). |
| 7 | Fi | 다이얼로그를 구성한다. 공표 R은 배정된 전원이다. 공격 G[1]/G[2]는 진영별 목록이며 지휘관을 포함한다. 스캔 c는 양 진영 지휘관을 뺀 전원이다. 아군/적군 스캔 av[1]/av[2]는 진영별 목록이며 지휘관을 뺀다. |
| 8 | hi | 비참여 슬롯의 u000을 제거하고 멀티보드(Ki)를 만든다. "그러면, 게임을 시작합니다." 표시. 타이머를 동시에 시작한다: **턴 e=90s, y=120s, iv=180s, S=300s, z=360s**. |

**처음에 알려주는 정보**는 자기 캐릭터명과 목표 문구뿐이다. 아군은 알려주지 않는다. 예외로 시작 동맹(트롤: 울디안↔울피안, 카즈로우↔세이로우)이 엔진 동맹 상태로 들어간다.

**버그 (Bi, 트롤)**: 데카(O[8])에게는 목표 문구가 오지 않는다. 데카용 문구가 울피안(O[7])에게 대신 두 번째로 간다.

## 2. 턴 시스템 (qi, 타이머 e 90초 반복)
1. wb(승리 판정)를 실행한다.
2. 생존자 중 `A[p]==""`(한 번도 공표 안 함)이면 **황금공표**를 한다. 노랑 태그 "p : b[p]"를 띄우고 `A[p]=b[p]`로 둔다. `b`는 슬롯 배열이므로 **본인 정체가 아니라 '플레이어 번호와 같은 번호 슬롯의 캐릭터명'**이 들어간다. 배정이 무작위라 사실상 무작위 이름이고, 우연히 진명일 수도 있다. 그 슬롯이 제외 슬롯이면 빈 이름이 되어 매 턴 빈 태그가 다시 생긴다. 전체 채팅 공지는 없다.
3. 마나 += `CountPlayersInForce(ForceEnumAllies(p))`×10 + 10. 자기 자신이 포함되므로 동맹이 0명이면 +20이다. 문구는 "새로운 턴…마나가 20 회복", 동맹이 있으면 "(n-1)*10 추가"가 붙는다.
4. 진명이고 생존이면 마나 +10을 받고 진실의 조각이 한 단계 오른다: 빈 인벤토리 → I001(1/3), I001 → I002(2/3), I002 → I000(완성). I000은 그대로다. 메시지는 모두 본인에게만 간다.
5. e를 90초로 다시 시작한다.

모든 영웅은 마나 시작 120, 최대 150, 자연 재생 0이다(w3u umpi/umpm/umpr).

| 타이머 | 시각 | 트리거/함수 | 지급 |
|---|---|---|---|
| y | 120s | Qe / rV | 트롤 토크라(O[5]) A02X 야생의 정기 · 태초 킬데르(O[9]) A00Q 카사노바 |
| iv | 180s | qe / vV | 트롤 즈윈라(O[3]) A044 족장 탐색 · **내전에서만** 프레이아(O[4]) A006 신탁 · 트롤 치스(O[1]) A03P 정령의 주술 |
| S | 300s | Pe / Wn | 리델루트 카스파(O[3]) A02K 신탁 · 내전 카스파(O[12]) A018 그림자의 눈 |

**위키와 차이**: 울피안 정화의 주술(A03Q, "3분 후")과 네오니스 네비아탄의 화신(A03E, "2분 후")은 해금 코드가 없다. 유닛이 처음부터 가지고 있다.

## 4. 공표 (A000, Q, 마나 0, 쿨 40, 마나 +5)
- **ce→Wi**: 시전(쿨다운 소모) 시 공표 다이얼로그 R을 **6초** 띄운 뒤 자동으로 닫는다. 닫혀도 쿨다운은 돌려주지 않는다.
- **Ce→zi**: 이름을 클릭하면 다음 순서로 처리한다.
  1. 기존 태그를 지운다. 시전자가 죽었으면 여기서 끝낸다.
  2. 새 태그를 만든다. 색은 내전·태초·리델루트에서 1진영 이름이 빨강, 2진영 이름이 파랑이다. 트롤은 반대다(1진영 파랑, 2진영 빨강).
  3. 전원에게 10초간 "H : <이름> 로 공표를 하였습니다." 또는 "H : <이전> -> <이름> …"을 보여준다.
  4. 마나 +5, `A[p]=이름`.
- 진명이면 매 턴 마나 +10과 보석 조각을 받는다(qi).

## 5. 동맹 (A004, 마나 10, 쿨 10) / 동맹 파기 (A005, 마나 10)
SPELL_CAST 단계에서 처리한다. 조건이 맞지 않으면 `stop`으로 시전을 취소하므로 비용이 들지 않는다.
- **동맹**: 시전자→대상 방향으로만 ALLIED를 건다. 시전자에게 "<H> 에게 동맹 관계를 설정", 대상에게 "<H> 가 당신에게 동맹 관계를 설정"을 보여준다. 이미 동맹이면 취소한다.
- **파기**: 시전자→대상 방향만 UNALLIED로 바꾼다. 양쪽에 알림이 간다. 동맹이 아니면 취소한다.
- **마나 동맹**은 §2-3을 따른다.
- **동맹 채팅 가시성**은 스크립트에 없다. WC3 엔진 동작(발신자가 동맹 설정한 상대에게 전달)이다(unverified).
- 사망 시 Lr은 모든 사람→사망자를 ALLIED로, 사망자→모든 사람을 UNALLIED로 바꾼다.

## 6. 공격 / 상급 / 최상급 (A002 / A003 / A01Z, 마나 50, 쿨 60, 연쇄살인 A01D 공유)
1. **rn**: `f[p]=대상`으로 둔다. 시전자가 B[1]이면 G[2], B[2]면 G[1] 다이얼로그를 6초 띄운다. 목록은 상대 진영 이름이며 지휘관을 포함한다. 6초 안에 고르지 않으면 아무 일도 없고 비용은 이미 소모된다.
2. **cn**: 이름을 클릭한다(클릭한 사람이 살아 있어야 한다). 선택한 이름이 대상의 실제 정체 `b[D[대상]]`와 같은지 본다.
   - 틀림 → **qr**(실패)
   - 맞음 → 다음 순서로 판정한다.
     1. (Nn) 대상이 엘타스이고, 컨슘(O[12])이 살아 있고, S005 레벨이 1~2 → S005를 +1 올리고 전원에게 "…엘타스를 공격하였으나 살해하지 못했습니다. (보디가드)". 공격자에게 페널티 없음.
     2. (An) 대상이 라엘이고, 쿠마린(O[6])이 살아 있고, A01X 레벨이 1~2 → 위와 같은 처리.
     3. (Rn) 절대 보디가드 → **qr**(실패, 페널티 적용). 리델루트 카이+아린(O[2]) 생존 / 내전 카이+아린(O[9]) / 내전 단테스+켈후(O[3]) / 트롤 치스+(사토시 **또는** 즈윈라).
     4. 그 외 → **Pr**(성공).
3. **Pr**은 다음 순서로 판정한다.
   1. 대상이 A03K(블러디 매드니스)를 가지고 있고 마나가 25 이상 → 대상 마나 -25, 전원에게 "(블러디 매드니스!)".
   2. `j[대상슬롯]>0` → 전원에게 "-<공격자 영웅명>가 <대상 영웅명>를 공격하였습니다."와 "<j>회 더 공격받으면 사망합니다."를 보여주고 j를 1 줄인다. 공격자 마나 += S006×30.
   3. 그 외 → 전원에게 "…공격하여 살해했습니다." → Lr(대상) → "-살해당한 <대상>는(은) <H>입니다!" → 공격자 마나 += S003×50 + S004×50 + S006×30. 킬데르가 에오릴을 죽이면 A00Q를 빼고 A00N을 준다.
4. **qr**(실패)은 다음 순서로 처리한다.
   1. 대상에게만 "<공격자 영웅명>가 당신을 공격하였으나 실패하였습니다."
   2. `K[p]`(영혼의 회복)가 켜져 있으면 전원에게 실패 문구와 "영혼의 회복으로 인해 공격 실패 페널티를 받지 않습니다."를 보여주고 끝낸다.
   3. A003 레벨 1이면 전원에게 "…누군가를 공격하였으나 실패" + "공격에 한번 더 실패하면 사망합니다."를 보여주고 A003을 레벨 2로 올린다. 영구 적용이다.
   4. A01Z이면 전원에게 실패 문구만 보여준다. 페널티 없음.
   5. 그 외(A002, A003 레벨 2) → 전원에게 "…실패하여 살해당하였습니다." → Lr(공격자) → "<공격자>은 <H>입니다!"
   - 소엔 A01D가 실패하면 전원에게 "소엔이 연쇄살인에 실패하였습니다!"를 보여주고 A01D만 제거한다. 사망하지 않는다.
5. 판정이 끝나면 wb를 실행한다.

메시지 가시성 정리: 모든 공격 메시지는 전원에게 보이며 **공격자의 영웅 고유이름**이 드러난다(플레이어는 숨겨진다). 성공(살해) 시에는 대상의 플레이어도 공개된다. 실패 시 대상은 누가 공격했는지(영웅명)를 비공개로 알게 된다.
**위키와 차이**: 트롤 치스 보디가드는 툴팁상 "사토시와 즈윈라가 살아있으면"이지만, 코드는 **둘 중 하나만 살아 있어도** 공격을 막는다.

## 7. 확인 / 스캔
공통: 시전 즉시 전원에게 "누군가가 <H[대상]> 을 살피고 있습니다."를 보여준다(대상 플레이어는 공개, 시전자는 비공개). 결과는 시전자에게만 보인다.

**아군 확인 A009(쿨 45, 마나 15) / 상급 A02J(쿨 30)** — Ca. 아래 순서로 판정한다.
1. 변장 판정(Ra) → 가짜 성공 "이 사람은 <공표이름>입니다."
   - 소엔: 시전자∈B2, 소엔∈B1, A∈{카이, 카스파, 투마, 아린, 크레이트}
   - 네오니스: 시전자∈B1, 네오니스∈B2, A∈{치스, 사토시, 즈윈라, 토크라, 울디안, 울피안, 하치}
2. 대상이 하치가 아니고 진명일 때: 서로 반대 포스면 실패, 아니면 "성공…<정체>".
3. 그 외(진명 아님 또는 하치)는 실패.

지휘관 예외는 없다.

**적군 확인 A008(쿨 60, 마나 20) / 상급 A03H(쿨 45)** — Fa. 아래 순서로 판정한다.
1. `Rv[대상]`(미명의 안개)가 켜져 있으면 1회 소모하고 시전자에게 "미명의 안개에 가려져…"를 보여준다. 동시에 O[4]에게 "<시전자 영웅명>가 <H>를 **배틀 센스**로 확인하려 했습니다!"를 보낸다(문구 고정, 프레이아 생존·모드 검사 없음).
2. 진명이 아니면 실패.
3. 반대 포스이고 하치가 아니면 성공 "<정체>".
4. 그 외는 실패.

변장은 적군 확인에 영향을 주지 않는다.

**스캔** (다이얼로그 c, 지휘관 제외 전원, 자동으로 닫히지 않음)
- 대상: 일반 스캔 A016(내전)/A01L(태초)/A037(리델루트)/A02Q(트롤), 마나 20, 쿨 40. 상급 스캔 A017/A01M/A036, 쿨 30. A01M은 아무도 보유하지 않는다.
- Ua 판정 순서 (클릭한 슬롯을 mr이라 한다):
  1. b[mr]가 하치 → 실패.
  2. 그 캐릭터의 플레이어가 대상이다 → "성공했습니다. 이 사람은 <이름>입니다."
  3. 대상이 b[mr]를 공표 중이다 → 메시지 **두 줄**을 출력한다.
     - 첫째 줄: mr<8이고 (대상 S00A & 시전자∈B1)이면 성공, 아니면 실패.
     - 둘째 줄: mr>7이고 (대상 S001 & 시전자∈B2)이면 성공, 아니면 실패.
     - 결과적으로 변장이 통하면 "성공+실패"가 섞여 나오고, 통하지 않으면 "실패" 두 줄이 나온다(**버그**).
  4. 그 외 → 실패.
- **아군 스캔** A00T(리델루트)/A015(트롤): 자기 진영 목록 av만 보여준다(지휘관 제외). 판정은 Pa이며 Ua와 같다.
- **적군 스캔** A040(리델루트)/A03T(트롤): 상대 진영 목록 av를 보여준다(상대 지휘관 제외).

**지휘관 예외**는 판정 코드가 아니라 **다이얼로그 목록에서 지휘관을 빼는 방식**이다. 내전 단테스·카이, 태초 라엘·엘타스, 리델루트 카이·샤이닝, 트롤 치스·데카.
**하치 하이드**: 아군/적군 확인과 모든 스캔이 하치에게는 항상 실패한다. 진실의 보석과 배틀 센스는 예외가 없다.

## 8. 진실의 보석 (Za)
- 종류: I002(2/3) → A01B, 마나 50, 쿨 240, 1회 사용 후 소모. I000(완성) → A01A, 마나 75, 쿨 240. I001(1/3)은 사용할 수 없다.
- 효과: 대상 정체가 **카이·단테스·샤이닝**이면 "이 사람은 지휘관(카이, 단테스, 샤이닝)이다."를 보여준다. 그 외에는 "이 사람은 <정체>이다!"를 보여준다. 결과는 시전자에게만 보인다.
- **위키와 차이**: 지휘관 판정은 이 3명만 하드코딩돼 있다. 라엘·엘타스·치스·데카는 이름이 그대로 공개된다.
- I002를 쓰면 인벤토리가 비므로, 다음 진명 턴에 I001부터 다시 쌓인다.

## 10. 메모 유닛 u000
- A011 `!`(Q) / A013 `@`(W) / A014 `#`(E) / A012 `$`(R): 쿨 1초. 본인 메모를 15초간 보여준다(Nb/cb/Db/gb).
- A01E 사망자 확인(쿨 10, pN): 죽은 플레이어를 모두 "H : 영웅명"으로 본인에게 30초간 보여준다. 미참여 슬롯도 '사망'으로 취급되어 빈 이름으로 함께 나온다.
- 영웅이 죽으면 u000도 제거된다(Lr).

## 11. 사망·이탈·관전 (Lr, Si)
- **Lr(p)**: 영웅이 살아 있을 때만 실행한다.
  1. 공표 태그를 지운다.
  2. 동맹을 바꾼다: 전원→p ALLIED, p→전원 UNALLIED.
  3. 영웅과 u000을 Kill한다.
  4. 본인에게 "당신은 사망했습니다."를 보여준다.
  5. **wb**를 실행한다.
  6. 멀티보드 행을 흰색으로 바꾼다.
  7. **관전자로 전환**한다(PLAYER_STATE_OBSERVER).
  8. 전원에게 "-사망한 <영웅명>는(은) <H>입니다!"를 보여준다(정체와 플레이어 공개).
- **이탈(be/si/Si)**: 영웅이 살아 있으면 Lr을 실행하고 전원에게 "<이름>님께서 나가셨습니다!"(30초)를 보여준다.

## 13. 멀티보드 (Ki/mi)
- 제목은 "가디언 스피리츠 택틱스", 2열×13행이다.
- 1~12행에는 H[n]을 표시한다(비참여는 "-"). 13행은 "경과된 시간" 분:초다.
- 죽으면 그 행이 흰색 이름으로 바뀐다. 진영 표시는 없다.
- pi는 무한루프 버그가 있다(무해, 구현 불필요).

## 14. 행동불능 / 무적 공통 구현
- **행동불능**: ANdo 계열(교란 A00Y, 나이트메어 A00P, 플레임 쉐클 A01K, 블랙 스펠 A02D) 시전 후 핸들러가 대상 영웅에 `PauseUnit(true)`를 걸고 버프 BNdo가 사라질 때까지 1초마다 확인한 뒤 해제한다. 쉐도우 자일 A00H는 버프 B001 기준이고, 해제 시점에 BNdo가 남아 있으면 정지를 유지한다.
  - 정지된 영웅은 **모든 스킬**(공표·동맹·공격·확인·보석)을 쓸 수 없다(엔진).
  - u000의 메모·사망자 확인과 채팅 명령은 정지와 무관하게 쓸 수 있다.
  - 효과가 겹칠 때는 먼저 끝난 쪽이 Pause를 풀어버린다(버그).
  - 공지: 교란·나이트메어·쉐클은 "누군가가 <H>에게 행동 불능 주문을 시전하였습니다."로 시전자를 숨긴다.
- **무적**: Aams 계열(룬 프로텍션 A00W 45s, 쉐도우 자일 A00H 45s, 시잉 오브 리비도 A02C 35s) 버프다. 스크립트에 무적 판정 코드는 없다. 엔진이 대상 지정을 거부해서 공격·확인·스캔·보석 등을 **대상으로 고를 수 없게** 막는 구조다(unverified, 실측 필요).
- **시전 취소 패턴**: SPELL_CAST 단계에서 `IssueImmediateOrderById(stop)`로 끊는다. 비용이 들지 않는다.
