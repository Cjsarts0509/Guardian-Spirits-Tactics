# 가택 웹판 재설계 — 워3 제약 걷어내기

원칙
1. **규칙의 핵심은 유지**: 정체 은닉, 공표(진명/가짜 이름), 단방향 동맹, 이름을 맞혀야 하는 공격, 90초 턴 마나, 진실의 보석. 이게 가택의 정체성.
2. **워3 때문에 생긴 불편은 전부 제거**: 다이얼로그 6초 제한, 8초 뒤 사라지는 메시지, 채팅 명령어, 더미 유닛 메모, 단축키 의존.
3. **정보 비대칭은 건드리지 않는다**: 편의 기능은 "내가 이미 알 권리가 있는 정보"를 정리해주는 수준까지만. 남의 행동을 대신 추적해주지 않음.

## 1. 원본 → 웹판 대응표

| 영역 | 원본 (워3 제약) | 웹판 |
|---|---|---|
| 대상 지정 | 유닛 클릭 → 이름 다이얼로그, 6초 안에 안 고르면 취소 | 플레이어 카드 선택 → 이름 피커(검색·진영 필터·내 메모 표시). 시간 제한 없음, 취소 버튼 |
| 결과 메시지 | 화면에 8초 떴다 사라짐, 놓치면 끝 | **개인 정보 로그**: 턴·시각·출처 스킬 기록, 영구 보존, 필터(확정 정보 / 공개 이벤트 / 채팅) |
| 공개 이벤트 | 전체 텍스트 스팸 (사망, 공표, 스킬 공개) | **타임라인 피드**: 사망·정체 공개·공개형 스킬 사용을 카드로. 플레이어 카드에도 배지 |
| 메모 | 메모 유닛의 더미 스킬 4개 (!, $, @, #) | **추리 보드**: 12명 × 캐릭터 매트릭스, 칸마다 확정/유력/배제/의심 표시, 자유 메모. 확인 스킬로 확정된 정보는 자동으로 "확정" 체크 (본인 결과만) |
| 공표 | 스킬 → 다이얼로그 → 머리 위 텍스트태그 | 카드에 공표 이름 표시, 공표 이력(언제 무엇으로 바꿨는지) 전체 공개 — 원본도 텍스트태그로 다 보였던 정보 |
| 동맹 | 보이지 않는 단방향 동맹, 확인 불가 | **동맹 패널**: 내가 건 사람 / 나에게 건 사람(원본에서도 마나 보너스로 알 수 있던 정보) 분리 표시. 다음 턴 마나 미리보기 |
| 채팅 | `-숫자` 귓말, `-전체` 익명 방송, 동맹 채팅 구분 어려움 | 채널 탭: 전체 / 동맹 / 귓말(플레이어별) / 익명 방송(권한 있는 캐릭터만) / 사망자 |
| 쿨다운·지연 결과 | 스킬 아이콘 쿨만, "8초 후 결과" 같은 건 안 보임 | 스킬바에 쿨, 대기 중인 지연 효과(카사노바 8초, 심문 60초, 시련 60초 등)를 진행 바로 표시 |
| 진실의 보석 | 아이템 3종 교체 | 진행 게이지(1/3 → 2/3 → 완성), 다음 턴 획득 여부(진명 상태) 표시 |
| 시간 해금 | 아무 예고 없이 스킬이 생김 | 스킬바에 잠긴 슬롯 + 남은 시간 |
| 모드 선택 | 방장 15초 다이얼로그, 안 고르면 내전 | 로비에서 방 만들 때 모드 선택, 대기실에서 변경 가능. 인원에 따른 제외 캐릭터 미리 표시 |
| 역할 이해 | 퀘스트 로그 텍스트, 툴팁 수치 틀림 | 역할 카드: 목표, 스킬(실제 수치), 상호작용 관계도(예: 투마→켈후, 메르츠키엘↔레인딜라). 게임 중 언제든 열람 |
| 이탈 | 나가면 즉시 사망 | 재접속 유예(예: 60초) 동안 슬롯 유지, 이후 사망 처리 |
| 게임 종료 | 일시정지 + 정체 공개 텍스트 | **결과 화면 + 전체 리플레이 타임라인**: 누가 언제 누구에게 무엇을 했는지 전부 공개. 추리 게임은 사후 복기가 재미의 절반 |
| 사망 후 | 관전자 전환, 할 게 없음 | 사망자 채널, 제한적 관전(공개 정보만 / 전체 공개 중 방 설정으로 선택) |
| 플랫폼 | PC 워3 | 모바일 우선 반응형 |

## 2. 워3에선 불가능했던 신규 기능

### 반드시
- **계정·전적**: 진영별·캐릭터별 승률, 최근 판 기록
- **리플레이**: 이벤트 로그로 재생 (Supabase `match_events`)
- **튜토리얼 / 연습 모드**: 봇 상대로 1판 — 규칙 진입장벽이 가택의 가장 큰 문제였음
- **방 옵션**: 턴 길이(60/90/120초), 재접속 유예, 관전 공개 범위, 비밀번호 방
- **신고·차단·채팅 필터**

### 있으면 좋음
- **랭크 매칭**: 진영별 레이팅(지휘관/일반 분리 고려)
- **밸런스 텔레메트리**: 캐릭터별 승률·스킬 사용률·평균 생존 시간 → `balance.json` 조정 근거
- **도감**: 가디언 스피리츠 세계관 캐릭터 설정·스토리 (각 모드가 연대기 사건이므로 모드 선택 화면과 연결)
- **커스텀 룰**: 캐릭터 풀 수동 지정, 모드 혼합
- **연출**: 공격·즉사기·정체 공개 컷인 (원본은 이펙트 몇 개뿐)

## 3. 손대지 말아야 할 것 (재설계해도 유지)
- 실시간 진행 + 90초 턴 마나 리듬 (턴 길이는 옵션화만)
- 공표 이름을 자유롭게 고를 수 있는 것 (블러핑 핵심)
- 이름을 틀리면 공격자가 죽는 리스크
- 확인 스킬이 "진명 공표자만" 판별하는 구조
- 결과를 다른 사람에게 증명할 방법이 없는 것 (말로만 주장 가능) → 개인 로그는 본인만 보임, 스크린샷 외 공유 기능 넣지 않음

## 5. 아트 방향
원본 캐릭터는 워3 영웅 모델 재활용이었으므로 캐릭터 아트를 처음으로 정식 제작하는 셈. 필요 수량: 캐릭터 일러스트 48종(모드별 중복 캐릭터는 공유 시 약 40종), 스킬 아이콘 약 150종, 모드 키비주얼 4종.
