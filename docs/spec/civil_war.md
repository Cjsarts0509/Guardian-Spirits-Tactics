# 왕자들의 내전 (mode="civil_war") — v1.33 코드 기준 명세

근거 파일: `GST_v1.33_war3map.j`. 함수명은 난독화된 원본 이름 그대로 적었다.
용어: **role index(mr)** 는 1..12 직업 슬롯 번호다. `O[mr]`=그 직업을 받은 플레이어, `b[mr]`=직업 영웅 이름, `D[p]`=플레이어 p(1..12)의 role index, `o[p]`=플레이어 p의 영웅 유닛, `A[p]`=p가 현재 공표한 이름, `H[p]`=색을 입힌 플레이어 이름(정체 공개 시 이걸 보여 준다), `j[mr]`=추가 목숨(직업별), `K[p]`=영혼의 회복 중인지, `k[p]`=영혼의 벽 보호 여부, `f[p]`=p가 공격한 대상 플레이어.

## 1. 모드 선택과 직업 배정

- `Yr`: 방장(Player 0)에게 모드 선택 다이얼로그를 띄우고 15초 타이머 `T`를 건다. 버튼은 랜덤 / 왕자들의 내전 / 태초 / 황야 / 트롤이다.
- `ri`: 버튼을 고르면 `U="왕자들의 내전"`이 되고, 퀘스트 트리거 `ve`→`Sr`을 실행한 뒤 `X[1..12]`을 세팅한다. 랜덤 버튼은 `GetRandomInt(1,4)==1`일 때 내전이다.
- `ni`: 15초 안에 아무것도 고르지 않으면(`U=="없음"`) 내전이 강제로 선택된다. 메시지: "방장이 모드를 선택하지 않아 왕자들의 내전이 선택되었습니다."
- 직업 슬롯 `X[]`. 아래 표의 유닛 ID가 task 목록과 일치하는 것을 확인했다.

- `Ei` 분배 규칙
  - 인원수는 `Xi` = 슬롯 상태가 PLAYING이고 컨트롤러가 USER인 플레이어 수다(`Mr`).
  - 인원별 마스크 문자열 `Oi`에서 '0'인 자리는 배정하지 않는다.

| 인원 | 마스크 | 제외 |
|---|---|---|
| 12 | 111111111111 | 없음 |
| 11 | 111111011111 | 세피 |
| 10 | 111111011110 | 세피, 카스파 |
| 9 | 111110011110 | 레인딜라, 세피, 카스파 |
| 8 | 111110011010 | 레인딜라, 세피, 투마, 카스파 |
| 1 | 100000000000 | 단테스만 남김(테스트용) |
| 2~7 | — | 전원에게 `CustomDefeatBJ` "사람 수가 부족합니다!" |

- 배정 절차(`Ei`)
  1. mr=1부터 차례로 돈다. 마스크가 '1'이면 남은 인원 풀에서 무작위 플레이어 1명을 뽑는다(`ForcePickRandomPlayer`).
  2. 뽑힌 플레이어의 시작 위치에 `X[mr]` 유닛을 생성한다.
  3. `o[p]`, `b[mr]`, `D[p]=mr`을 세팅한다.
  4. 본인에게만 "당신은 |c00ff00ff<이름>|r입니다."를 보여 준다.
- 진영 배정(`Bi`)
  - O[1..7]을 force B[1], O[8..12]를 B[2]에 넣는다.
  - 각자에게 목표 문구를 보여 준다.
    - 단테스: "카이를 살해하면 승리. 당신이 살해당하면 단테스측은 패배"
    - 카이: "단테스를 살해하면 승리. 당신이 살해당하면 카이측은 패배"
    - 나머지: "단테스/카이를 도와 ... 살해하면 승리"
  - **목숨 세팅은 `set j[3]=2`(켈후)와 `set j[$A]=1`(투마) 두 줄뿐이다.** 나머지 직업은 j=0이다.
  - 제외된 직업 슬롯은 `b[mr]=""`, `O[mr]=null`로 남는다. 그래서 공표/공격/스캔 다이얼로그에 버튼이 생기지 않는다(`Fi`).

## 2. 승리 조건 (`wb`, 트리거 `yo`)

- `yo`가 실행되는 시점: 사망 처리 `Lr` 안, 공격 다이얼로그 처리 `cn` 끝, 매 턴 시작 `qi` 첫머리.
- 위에서부터 순서대로 판정한다(다른 모드 분기는 생략).
  1. `tb`: 카이(O[8]) 영웅이 죽었으면 전체에 "|c00ff8080단테스|r측이 승리했습니다."를 띄우고 `Yo`(게임 종료 연출)로 간다.
  2. `Tb`: 단테스(O[1])와 메르츠키엘(O[2])이 모두 죽었고, 메르츠키엘이 `A00E`(후계자)를 갖고 있으면 → "단테스가 사망하고, 후계자인 메르츠키엘도 사망했습니다. 카이측이 승리했습니다."
  3. `ub`: 단테스가 죽었고 메르츠키엘이 `A00E`를 **갖고 있지 않으면** → "카이측이 승리했습니다." 메르츠키엘이 살아 있어도 후계자가 아니면 즉시 패배한다.
  4. `Ub`: 단테스가 죽었고 메르츠키엘이 `A00E`를 갖고 있으며 살아 있으면 → "메르츠키엘이 단테스의 뒤를 이어받았습니다."만 띄우고 게임은 계속된다. 트리거를 파괴하지 않기 때문에 **이 메시지는 이후 yo가 실행될 때마다(매 턴, 매 사망) 반복 출력된다.**
- `Yo`=`yb` 게임 종료 연출
  - `PauseGameOn`을 걸고 턴 타이머를 멈춘다.
  - 4초 뒤 전 플레이어의 "플레이어 : 영웅이름"을 공개하고, 다음 방제를 출력한다.
  - 같은 함수의 '프레이아 배신(J)' 분기는 `J`가 항상 false라서 내전에서는 실행되지 않는다.
- 판정은 위 순서대로 첫 번째로 맞는 것 하나만 처리된다. 카이 사망을 먼저 보기 때문에 같은 처리 안에서 둘 다 죽었다면 단테스 측 승리다.
- 후계자 임명은 단테스가 살아 있을 때만 쓸 수 있다(단테스 본인의 스킬이므로). 메르츠키엘이 후계자가 된 뒤 단테스보다 먼저 죽으면, 단테스가 죽는 시점에 `Tb`로 카이 측이 승리한다.

## 3. 목숨 / 보디가드 / 공격 판정 (공통 공격 흐름, 내전 특화 부분)

- 공격 계열 스킬
  - 트리거 `ke`의 조건 `xn`/`en`: `A002` 공격, `A003` 상급 공격, `A01D` 연쇄살인(소엔), `A01Z`(타 모드)가 대상이다.
  - 처리 함수 `rn`: `f[공격자]=대상`을 기록한다. 공격자가 B[1]이면 G[2](카이 측 이름 b[8..12]), B[2]이면 G[1](단테스 측 이름 b[1..7]) 다이얼로그를 6초간 보여 준다. **고를 수 있는 이름은 상대 진영 직업명뿐이다.** 6초 안에 고르지 않으면 아무 일도 없고, 마나와 쿨다운은 그대로 소모된다.
- 이름 선택 처리 `cn`
  1. 정답 판정 `bn`: 대상의 실제 직업명 `b[D[f]]`이 고른 이름과 같은가.
  2. 정답이고 보디가드에 걸리면(`In`=`Vn` or `En`) 공격자 실패 처리 `qr`로 간다.
     - `Vn`: 대상이 카이이고 아린(O[9])이 살아 있음.
     - `En`: 대상이 단테스이고 켈후(O[3])가 살아 있음.
  3. 정답이고 보디가드가 없으면 명중 처리 `Pr`로 간다.
  4. 오답이면 `qr`로 간다.
- 명중 처리 `Pr(a)`
  - `j[대상 role]>0`이면 죽지 않는다.
    - 전체 메시지: "-<공격자 영웅명>가 <대상 영웅명>를 공격하였습니다."와 "-<대상 영웅명>는 N회 더 공격받으면 사망합니다."(N은 감소 전 값). 그다음 j를 1 줄인다.
    - 공격자가 소엔(H00B)이면 메시지가 "...살해하지 못했습니다.(연쇄살인!)"로 바뀌고, **소엔의 A01D(연쇄살인)가 제거된다.**
  - `j==0`이면 사망한다.
    - "-<공격자 영웅명>가 <대상 영웅명>를 공격하여 살해했습니다."(소엔이면 "(연쇄살인!)"이 붙는다)를 띄우고 `Lr(대상)`을 호출한다.
    - 이어서 "-살해당한 X는(은) <플레이어>입니다!"가 나온다. Lr 안에서도 같은 내용이 출력되므로 공개 메시지가 2번 뜬다.
    - 공격자 마나 회복: +S003 레벨×50(카스파의 정기 흡수), +S004×50, +S006×30. 내전에서는 S003만 해당한다.
  - **명중·사망 메시지에는 공격자의 영웅(직업) 이름이 전체에 공개된다**(플레이어는 공개되지 않는다).
- 직업별 목숨(공격 명중을 몇 번 버티는지)
  - 켈후: j=2이므로 3번째 명중에 사망한다(S000 하드스킨 툴팁 "3번"과 일치).
  - 투마: j=1이므로 2번째 명중에 사망한다(S002 화염의 근원 "2번"과 일치).
  - 나머지 10명: 1회 명중에 사망한다.
  - S000/S002는 효과가 없는 표시용 패시브(SCae 베이스)다. 실제 효과는 `Bi`의 `j[]` 값이다. 코드에 'S000'/'S002' 참조는 0건이다.
  - 목숨은 **일반 공격(Pr)에만 적용된다.** 백스탭, 소울 리버, 용맹한 돌진, 마황자의 명령은 `Lr`을 직접 호출하므로 목숨을 무시하고 즉사시킨다.
- 공격 실패 처리 `qr(a)`
  1. 공격자가 소엔이면: 전체에 "-소엔이 연쇄살인에 실패하였습니다!"를 띄우고 A01D를 제거한 뒤 종료한다. **소엔은 죽지 않는다.**
  2. 대상 본인에게만 "<공격자 영웅명>가 당신을 공격하였으나 실패하였습니다."를 보여 준다. 공격자의 직업이 대상에게 공개된다.
  3. `K[a]`(영혼의 회복)가 true이면: 전체에 "-X가 누군가를 공격하였으나 실패하였습니다."와 "- 영혼의 회복으로 인해 공격 실패 페널티를 받지 않습니다."를 띄운다. 페널티는 없고 A003 레벨도 오르지 않는다.
  4. A003 레벨이 1이면(상급 공격, 첫 실패): 전체에 "-X가 누군가를 공격하였으나 실패하였습니다." "-공격에 한번 더 실패하면 사망합니다."를 띄우고 A003 레벨을 2로 올린다.
  5. 그 외(A002 일반 공격, 또는 A003 레벨 2): 전체에 "-X가 누군가를 공격하였으나 실패하여 살해당하였습니다."를 띄우고 `Lr(a)`, 이어서 "-X은 <플레이어>입니다!"를 띄운다.
- 내전에서 공격 수단별 보유자
  - 상급 공격(A003): 카이, 투마, 메르츠키엘, 켈후.
  - 공격(A002): 단테스, 아린, 카스파.
  - 공격 없음: 크레이트, 프레이아, 세피, 레인딜라, 소엔(소엔은 백스탭/연쇄살인만).
- 보디가드 `A00K`(켈후→단테스), `A00X`(아린→카이)는 표시용 패시브다. 실제 판정은 `Vn`/`En`이 O[9]/O[3] 생존 여부로 한다. 아린과 켈후는 어떤 인원수에서도 제외되지 않으므로 항상 존재한다. 보디가드는 **일반 공격/연쇄살인에만** 적용된다.

## 4. 사망 처리 `Lr(p)` (요약, 상세는 core 담당)

- 대상이 살아 있을 때만 동작한다.
  1. 공표 텍스트태그를 제거하고 사망 로그 `s`에 추가한다.
  2. 동맹 설정: 모든 플레이어 → p는 ALLIED, p → 모든 플레이어는 UNALLIED.
  3. 영웅과 참가자 유닛(u000)을 죽인다.
  4. 본인에게 "당신은 사망했습니다."를 보여 준다.
  5. `yo`(승리 판정)를 실행한다.
  6. 멀티보드를 흰색으로 바꾸고 옵저버로 전환한다.
  7. 전체에 "-사망한 <영웅명>는(은) <플레이어>입니다!"를 띄운다.

## 7. 고유 스킬 상세

이벤트 표기
- [EFFECT]: SPELL_EFFECT. 이 시점에는 마나와 쿨다운이 이미 소모되어 있다. 스크립트가 stop 명령(`$D0004`)을 내려도 환불되지 않는다(WC3 엔진 동작, 스크립트 외부 사실이라 '엔진 추정'으로 표기).
- [CAST]: SPELL_CAST. 여기서 stop하면 시전이 취소되어 마나와 쿨다운이 소모되지 않는다(엔진 추정).

### A00A 마황자의 명령 (단테스) — `Se`[EFFECT] `IV`→`NV`
- 수치: 마나 0, 쿨다운 3600(사실상 1회), 단축키 V, 대상은 다른 유닛 1명.
- 판정 1. 대상의 실제 영웅 이름이 "카이"인 경우(`AV`)
  - 사운드 `Jv`.
  - 전체에 "-단테스 : 카이는<대상플레이어>이다! 놈을 체포하라!"와 "-<대상플레이어>의 정체는 카이였습니다."를 띄운다.
  - `Lr(대상)`을 호출한다. 이어서 "- 카이가 처형당했습니다! 단테스측의 승리입니다."가 나오고, Lr 안의 `yo`→`tb`로 단테스 측이 승리한다.
- 판정 2. 카이가 아닌 경우
  - 전체에 같은 선언 문구, "<대상플레이어>는 카이가 아닙니다!"를 띄운다.
  - `Lr(단테스 본인)`을 호출하고 "- 카이 : \"어리석군...\" - 카이가 단테스를 살해하였습니다!"를 띄운다.
  - 승리 판정: 후계자가 없으면 `ub`로 카이 측 승리, 후계자가 있으면 `Ub`로 게임이 계속된다.
- 무시하는 것: 보디가드(아린), 영혼의 벽, 목숨.
- 막는 것: 엔진 단계의 주문 면역(룬 프로텍션/쉐도우 자일 중인 대상은 지정 자체가 불가, 아래 참고).
- 스킬은 제거되지 않고 3600초 쿨다운으로 잠긴다.

### A00C 후계자 임명 (단테스) — `te`[EFFECT] `BV`→`CV`
- 수치: 마나 30, 쿨다운 3600, 단축키 Z.
- 대상의 실제 영웅이 메르츠키엘인 경우
  - 사운드 `kv`.
  - **전체**에 "단테스가 메르츠키엘을 후계자로 임명하였습니다!"를 띄운다. 누가 메르츠키엘인지는 공개되지 않는다.
  - 단테스 본인에게만 "<대상플레이어>를 후계자로 설정하였습니다."를 보여 준다.
  - 대상 본인에게만 "단테스가 당신을 후계자로 임명하였습니다!"를 보여 준다.
  - 대상에게 `A00E`(후계자 패시브)를 추가한다.
- 아닌 경우: 단테스에게만 "그 대상은 메르츠키엘이 아닙니다."를 보여 준다.
- **성공·실패와 관계없이 A00C를 제거한다(기회 1번).**

### A00E 후계자 (메르츠키엘, 획득형 패시브)
- 효과는 승리 판정 `Tb`/`ub`/`Ub`에서 보유 여부만 확인하는 것이다(2장 참조). 단테스가 죽어도 메르츠키엘이 살아 있으면 게임이 계속된다.

### A01C 배우자 (메르츠키엘) / A00R 배우자 (레인딜라) — `ue` `gV`→`hV` / `ex` `aE`→`VE` [EFFECT]
- 수치: 둘 다 마나 25, 쿨다운 40, 단축키 Z.
- 메르츠키엘의 A01C: 대상의 실제 영웅이 "레인딜라"이면 본인에게만 "이 사람의 정체는 레인딜라입니다!"를 보여 주고, 0.2초 뒤 A01C를 **제거**한다. 아니면 "이 사람은 레인딜라가 아닙니다."를 보여 주고 스킬은 유지된다.
- 레인딜라의 A00R: 같은 방식으로 "메르츠키엘"을 확인한다. 성공 시 A00R을 제거한다.
- 결과는 시전자 본인에게만 보인다.

### A00H 쉐도우 자일 (메르츠키엘) — `Te`[EFFECT] `DV`→`fV`
- 수치: 마나 35, 쿨다운 180, 지속 45초. Aams(안티매직 쉘) 베이스, 버프 B001/B000.
- 처리 순서
  1. 0.1초 대기.
  2. 전체에 "메르츠키엘이 <대상플레이어>에게 쉐도우 자일을 시전하였습니다."를 15초 동안 띄운다. 시전자의 직업명과 대상 플레이어가 공개된다.
  3. 대상 영웅을 `PauseUnit`으로 정지시킨다(행동 불능).
  4. 1초마다 B001 버프가 남아 있는지 확인하고, 버프가 사라지면 정지를 해제한다. 단 그 시점에 BNdo(교란/나이트메어) 버프가 있으면 해제하지 않는다.
- 주문 면역(엔진 동작): Aams 버프 동안 대상은 주문 면역이 된다. 다른 플레이어의 모든 대상 지정 스킬(공격·스캔·소울 리버·백스탭 등)이 이 대상을 지정할 수 없다. 스크립트에 이 판정은 없다(엔진 추정).

### A00L 충복 (켈후) — `Ue`[EFFECT] `jV`→`kV`
- 수치: 마나 25, 쿨다운 40.
- 대상의 실제 영웅이 "단테스"이면 본인에게만 "이 사람의 정체는 단테스다!"를 보여 주고 0.2초 뒤 A00L을 제거한다.
- 아니면 "이 사람은 단테스가 아니다."를 보여 주고 스킬은 유지된다.

### A00V 충복 (아린, 카스파) — `ax`[EFFECT] `gE`→`hE`
- 수치: 마나 25, 쿨다운 40.
- 같은 방식으로 "카이"를 확인한다. 성공 시 본인에게만 결과를 보여 주고 스킬을 제거한다.

### A00K / A00X 보디가드 (켈후 / 아린) — 패시브
- 3장 참조. 스크립트는 이 어빌리티를 참조하지 않고 직업 슬롯 O[3]/O[9]의 생존 여부로 판정한다.
- 일반 공격과 연쇄살인만 막는다. 소울 리버, 마황자의 명령, 백스탭은 막지 못한다.

### S000 하드스킨 (켈후) / S002 화염의 근원 (투마) — 표시용 패시브
- 실제 값은 `Bi`의 `j[3]=2`, `j[10]=1`이다. 일반 공격 기준 각각 3회, 2회 명중에 사망한다.

### A019 전사의 후각 (켈후, 투마) — `se`[EFFECT] `aV`→`OV`
- 수치: 마나 40, 쿨다운 180, 단축키 X.
- 판정 순서
  1. 대상이 공표한 이름 `A[대상]`이 "투마" 또는 "켈후"이면: stop 명령을 내리고 본인에게만 "투마나 켈후의 이름을 공표한 사람에게 사용할 수 없습니다."를 보여 준 뒤 종료한다. EFFECT 시점이라 마나와 쿨다운은 이미 소모됐다(엔진 추정).
  2. 대상의 실제 영웅이 **카이, 메르츠키엘, 켈후** 중 하나이면(`EV`, 이름 하드코딩): "이 사람은 상급 전사이다."
  3. 그 외: "이 사람은 상급 전사가 아니다."
- 결과는 본인에게만 보인다.
- **위키/툴팁과 차이**: 툴팁은 '상급공격 및 최상급공격 보유 여부'라고 하지만 코드는 고정된 이름 목록이다. 상급 공격(A003)을 가진 **투마는 "상급 전사가 아니다"로 판정**된다. 같은 함수 이름을 가진 A03B(황야)의 `hn`과 달리 내전용 A019는 어빌리티를 검사하지 않는다.

### A02H 조언 (소엔) — `Ye`[EFFECT] `SV`→`TV`
- 수치: 마나 50, 쿨다운 3600, 단축키 C.
- 대상의 실제 영웅이 "켈후"인 경우
  - 사운드 `wv`.
  - **전체**에 "-소엔이 켈후를 보좌하기 시작합니다."를 띄운다.
  - 켈후에게 `A02I 냉정함`을 추가한다.
  - **소엔과 O[3](켈후)을 상호 동맹(양방향 ALLIED)으로 만든다.**
  - 켈후 본인에게만 "-소엔의 정체는 <소엔플레이어>입니다!"를 보여 준다.
- 아닌 경우: 소엔에게만 "그 대상은 켈후가 아닙니다."를 보여 준다.
- **성공·실패와 관계없이 A02H를 제거한다.**
- 상호작용
  - 냉정함이 있으면 투마의 돌진이 실패한다.
  - 상호 동맹이 되면 켈후 → 소엔 동맹 상태가 성립한다. 따라서 소엔의 백스탭으로 켈후를 죽일 수 있다(코드상 가능).

### A02I 냉정함 (켈후, 획득형 패시브)
- 용맹한 돌진의 `lE`에서 보유 여부만 확인한다.

### A00M 백스탭 (소엔) — `ye`[**CAST**] `MV`→`QV`
- 수치: 마나 10, 쿨다운 1, 단축키 Z.
- 판정 순서
  1. 대상 소유자가 소엔 본인이면 stop하고 "자신에게 사용할 수 없습니다."를 보여 준다. 대상 조건에 notself가 있어 사실상 발생하지 않는다.
  2. `IsPlayerAlly(대상플레이어, 소엔)`: **대상이 소엔에게 동맹 설정을 한 상태**(일방이어도 된다. 소엔 쪽 설정은 상관없다)인지 본다.
     - 성립하면
       - 사운드 `Lv`.
       - 전체에 "-소엔이 <대상 영웅명>를(을) 암살하였습니다!"와 "-<대상 영웅명>은<대상플레이어>입니다!"를 띄운다.
       - `Lr(대상)`을 호출한다. 진영과 관계없이 죽인다. 목숨(켈후 3목), 보디가드, 영혼의 벽을 모두 무시한다.
       - 소엔에게 A01D가 없으면 추가하고, 본인에게만 "연쇄살인 스킬을 획득했습니다!"를 보여 준다.
     - 성립하지 않으면: stop으로 시전을 취소하고(CAST라서 마나·쿨다운 미소모, 엔진 추정) 본인에게만 "이 사람은 당신에게 동맹설정을 하지 않았습니다."를 보여 준다.
- 횟수 제한은 없다.

### A01D 연쇄살인 (소엔, 백스탭 성공 시 획득)
- 수치: 마나 30, 쿨다운 10, 단축키 V.
- 일반 공격과 같은 흐름(`ke`→`rn`→`cn`)을 쓴다. 소엔은 B[1]이므로 **카이 측 이름(b[8..12])만 고를 수 있다.**
- 결과
  - 정답이고 보디가드에 걸리지 않으며 목숨이 0이면: "...공격하여 살해했습니다.(연쇄살인!)"와 함께 죽이고, **스킬은 유지된다**(재사용 가능).
  - 정답이지만 목숨이 남은 대상(투마 1목): "...살해하지 못했습니다.(연쇄살인!)"를 띄우고 목숨을 1 줄인 뒤 **A01D를 제거**한다.
  - 오답, 또는 정답이지만 카이+아린 생존: 전체에 "-소엔이 연쇄살인에 실패하였습니다!"를 띄우고 A01D를 제거한다. 소엔은 죽지 않는다. 이 메시지로 소엔 직업이 존재한다는 사실과 실패가 전체에 공개된다.
- 백스탭에 다시 성공하면 A01D를 다시 받는다.

### S001 변장 (소엔) — 패시브, 아군 확인과 스캔에서 참조
- 아군 확인(`Ca`/`Oa`)
  - 조건: 시전자가 카이 측, 대상이 단테스 측, 대상의 실제 영웅이 "소엔", 대상이 공표한 이름이 카이/카스파/투마/아린/크레이트 중 하나.
  - 이 조건이면 **"확인에 성공했습니다. 이 사람은 <공표한 이름>입니다."라는 거짓 결과**가 나온다. 이 판정은 S001 보유가 아니라 영웅 이름으로 한다.
- 스캔/상급 스캔(`Ua`/`ua`)
  - 조건: 시전자가 카이 측, 고른 이름이 카이 측 이름(mr>7), 그 이름이 대상의 공표명과 같음, 대상이 S001 보유.
  - 이 조건이면 "성공했습니다. 이 사람은 X입니다."라는 거짓 결과가 나온다.
  - **버그**: 같은 분기에서 앞쪽 `mr<8` 블록의 else가 먼저 실행되어 "스캔에 실패하였습니다."도 함께 출력된다. 시전자는 실패와 성공 메시지를 **둘 다** 본다.
  - 카이 측에서 스캔을 가진 캐릭터는 크레이트(A017 상급 스캔)뿐이다.

### A00O 버닝 매직 (세피) — `ze`[EFFECT] `UV`→`wV`
- 수치: 쿨다운 100, 마나는 미수정(ACfa 베이스 기본값, unverified), 단축키 Z.
- 대상 영웅의 마나를 70 줄인다. 0 미만은 엔진이 0으로 맞춘다.
- 전체에 "-세피가 누군가에게 버닝 매직을 시전하였습니다."를 띄운다. 대상은 공개되지 않는다.
- 대상 본인에게만 "버닝 매직으로 인하여 마나가 70 감소하였습니다."를 보여 준다.

### A00Y 교란 (세피) / A00P 나이트메어 (크레이트) — `Ze` `yV`→`YV` / `nx` `jE`→`JE` [EFFECT]

## 8. 위키와의 차이 / 구현 주의

1. **프레이아**
   - 칭호: 유닛 데이터는 "프리스티스 오브 그리드"다. 퀘스트 텍스트와 위키는 "드로우 프리스티스"다.
   - 스킬: 시작 시 스캔(A016)만 있고, 신탁(A006)은 180초에 생존해 있을 때 획득한다. 위키의 '스캔+신탁' 구성 자체는 같다.
   - 리비도의 여사제 대상이자 단테스 측이다.
2. **투마**: 전사의 후각+용맹한 돌진+화염의 근원에 더해 **상급 공격(A003)**도 있다. 전사의 후각은 실제로 카이/메르츠키엘/켈후 이름 목록만 "상급 전사"로 판정하므로 투마 자신은 '아니다'로 나온다. 투마/켈후를 공표한 대상에게는 쓸 수 없다.
3. **목숨은 일반 공격에만 적용된다.** 백스탭, 돌진, 소울 리버, 마황자의 명령은 하드스킨/화염의 근원을 무시하고 즉사시킨다.
4. **연쇄살인 실패 시 소엔은 죽지 않는다**(스킬만 사라짐). 목숨이 남은 대상에게 명중해도 스킬이 사라진다.
5. **후계자**: 임명 없이 단테스가 죽으면 메르츠키엘이 살아 있어도 즉시 카이 측이 승리한다. 승계 메시지는 매 턴 반복 출력된다.
6. 진명 공표가 필요한 스킬(저주, 리비도)과 그림자의 눈은 조건을 못 맞추면 EFFECT 시점이라 마나와 쿨다운을 그대로 날린다(엔진 추정).
7. 퀘스트 `Sr`의 단테스 세력 목록 문자열은 원본에서 "|c00ff0"으로 잘려 있다(레인딜라 이후 누락). 퀘스트에 표기된 칭호 "석세스 오브 다크니스"는 오타이고, 유닛 데이터는 "석세서 오브 다크니스"다.
