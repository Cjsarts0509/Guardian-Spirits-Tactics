# 웹판 결정 사항

방침: **원본 버그는 재현하지 않는다.**
의도 판정 근거 우선순위:
1. 코드에 명시적으로 작성된 조건 (GUI의 Or/And 블록처럼 일부러 만든 분기)
2. 맵 내부 퀘스트 로그(`CreateQuestBJ`)·툴팁·오브젝트 데이터(레벨 수 등)
3. 나무위키 서술

수치는 **실제 플레이된 값(오브젝트/코드)** 기준. 툴팁이 틀린 곳은 설명문을 고친다.
기계용 목록: `web_overrides.json`

## G. 의도 확인 결과 (질문 6건 해결 + 재검토 1건)

| # | 질문 | 결론 | 근거 |
|---|---|---|---|
| G1 | 치스 보디가드: 둘 다 생존 vs 한 명 생존 | **한 명이라도 살아 있으면 치스 보호 (원본 코드 유지)** | 조건 함수 `Xn`이 `IsUnitAlive(사토시) or IsUnitAlive(즈윈라)` — GUI에서 Or 블록을 일부러 넣어야 나오는 형태. 툴팁 "사토시와 즈윈라가 살아있으면"은 "둘이 지키는 동안"의 느슨한 표현. 반란군의 치스 공략 수단이 무모한 돌격이고, 그 대응책으로 족장 보호가 따로 있는 구조와도 맞음 |
| G2 | 인원 부족으로 빠진 슬롯을 승리 판정에서 사망으로 볼지 | **사망(=없음)으로 취급 (원본 유지)** | 해당 승리조건의 의미가 "상대 지휘관을 죽일 수단이 남지 않음"(위키: 트롤 "공격 능력 무력화", 황야 "카이를 죽일 수 있는 기술이 없어서 게임 종료"). 처음부터 없는 슬롯은 수단이 아님 |
| G3 | 천사의 세례 반복 | **기사 1명당 1회** (A8) | S007 레벨 상한 4, 유이 퀘스트 문구 |
| G4 | 뱀파이어릭 등 아군 살해 마나 | **적만** (A9, A9b) | 툴팁 "적을 공격하여 살해하면" |
| G5 | 황야 특수 승리(위대한 의지 실패 + 유이·로네리스·수프라·카미카제 전멸 → 다크니스 승리) | **의도된 규칙 (유지)** | 위키: "샤이닝의 위대한 의지가 실패하면 카이를 죽일 수 있는 기술이 없어서 게임이 종료된다". 샤이닝·치즈코는 공격 스킬이 없음(오브젝트 확인) |
| G6 | 백스탭이 일방 동맹만으로 진영 무관 발동 | **의도된 규칙 (유지)** | 퀘스트·툴팁 "목표 대상이 소엔에게 동맹 상태일 경우 살해한다" — 진영 조건 없음. 동맹 신호를 함정으로 쓰는 캐릭터 |
| G7 | (처음엔 버그로 봤던 것) 야생의 축복이 성공 후에도 남아 울디안·울피안 둘 다에게 부여 가능 | **의도된 규칙 (유지)** | 툴팁 "사용 횟수 무한 … 실패하면 사라진다" — 성공 시 유지가 명시됨. 천사의 세례와 같은 구조(실패 시 소멸, 대상별 보상) |

### 웹판 설명문에 반영할 것
- 치스 보디가드: "사토시 또는 즈윈라 중 한 명이라도 살아 있으면 치스는 일반 공격으로 죽지 않는다"
- 승리 조건 화면에 "상대가 우리 지휘관을 죽일 수단을 모두 잃으면 승리" 계열 조건(트롤 반란군, 황야 다크니스 특수승)을 명시
