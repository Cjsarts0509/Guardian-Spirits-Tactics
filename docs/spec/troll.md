# 트롤 부족의 반란 (mode = "troll") — 원본 코드 기준 명세

근거: `GST_v1.33_war3map.j` (함수명은 난독화 이름 그대로), `objects.json`(w3a/w3u), `wiring.txt`.
표기: **[ALL]** 전체 메시지, **[SELF]** 시전자 본인만, **[TGT]** 대상 본인만, **[P n]** 슬롯 n 플레이어만.
"진명" = `A[pid] == GetHeroProperName(o[pid])` (현재 공표한 이름이 실제 이름과 같음).
"대상" = 지정한 유닛 주인 플레이어의 영웅 `o[1+GetPlayerId(GetOwningPlayer(GetSpellTargetUnit()))]`. 그래서 남의 더미유닛(u000)을 찍어도 그 주인 영웅이 대상이 된다.

## 2. 승리 조건 (`wb`, 트리거 `yo`)

`yo`는 `Lr`(사망 처리), `qi`(턴 종료), `cn`(공격 판정) 끝에서 실행된다. 검사 순서 (먼저 참인 것 하나로 끝나고, `Yo`=게임 종료 `yb` 실행):
1. `mb`: **사토시(O[2]), 즈윈라(O[3]), 울디안(O[6]) 모두 사망** → [ALL] "얼음 트롤에는 더 이상 공격할 힘이 남아 있지 않습니다! 트롤 반란자측이 승리했습니다."
2. `Mb`: **데카(O[8]) 사망** → "얼음 부족이 승리했습니다."
3. `pb`: **치스(O[1]) 사망** → "트롤 반란자측이 승리했습니다."

- `mb`가 `Mb`보다 먼저 검사되므로, 같은 판정에서 둘 다 참이면 반란자가 이긴다.
- 얼음 부족에서 공격 스킬을 가진 캐릭터는 사토시, 즈윈라, 울디안뿐이다 (치스·하치·토크라·울피안은 공격이 없음).
- 9인·8인에서는 울디안이 제외되어 `O[6]`이 null이다. 이때 `o[1+GetPlayerId(null)]`이 어떻게 평가되는지는 확인하지 못했다(unverified). 의도대로라면 사토시·즈윈라만 죽으면 반란자 승리다. 구현 시 "제외된 울디안은 사망한 것으로 취급"을 권장한다.
- 나간 플레이어(`Si`)는 `Lr`로 사망 처리된다.

## 4. 판정 엔진 메모 (WC3 이벤트 타이밍)

- `SPELL_CAST` 트리거에서 `stop`(`$D0004`)을 내리면 시전이 취소되어 마나와 쿨다운이 들지 않는다.
- `SPELL_EFFECT` 트리거에서 `stop`을 내리면 이미 마나가 빠지고 쿨다운이 돈 뒤다. 그래서 "진명이 아니라 사용 불가"로 거절되더라도 **마나와 쿨다운은 소비된다**. 쿨다운이 3600인 1회용(A044, A03R, A03S, A03I)은 이렇게 거절되면 사실상 잃는다. 이것은 WC3 엔진의 일반 동작이며 이 파일의 코드로 직접 검증한 것은 아니다.
- 이벤트 종류: CAST = A03O(do/Do), A02U(Fo), A03X(Ho), A03B(le). 나머지 troll 고유 스킬은 모두 EFFECT다.

## 5. 피격 판정에서 troll 전용 분기 (`cn` → `Pr`/`qr`)

공격 다이얼로그 버튼(`cn`)에서 이름을 고른 뒤:
1. 고른 이름 ≠ 대상의 실명 → `qr` (공격 실패: 일반 공격이면 사망, 상급 공격은 1회 유예, 최상급은 페널티 없음 — core 담당).
2. 고른 이름이 맞음 → `Nn`(태초 엘타스), `An`(라엘)은 troll과 무관 → `In()`:
   - `On`: 모드가 troll이고, 대상 실명이 **치스**이고, **사토시(O[2]) 또는 즈윈라(O[3]) 중 한 명이라도 살아 있으면** → `qr` (공격자 실패 처리). 이것이 **보디가드(A022)**다.
3. 그 외 → `Pr(attacker)`:
   - **블러디 매드니스 (가장 먼저 검사)**: 대상이 `A03K`를 갖고 있고 마나 ≥ 25이면 → [ALL] "-{공격자 실명}가 {대상 실명}를 공격하였으나 살해하지 못했습니다.(블러디 매드니스!)", 대상 마나 −25, 끝 (공격자 페널티 없음).
   - 아니면 추가 목숨 검사: `j[slot] > 0`이면 [ALL] "-X가 Y를 공격하였습니다." + "-Y는 {j}회 더 공격받으면 사망합니다.", 그리고 `j--`.
   - 아니면 살해 (`Lr`) + [ALL] 살해 메시지.

목숨 정리: 사토시 2, 즈윈라 2, 카즈로우 2, 세이로우 1(광폭화 후 2), 나머지 1. 데카는 1이지만 A03K가 있고 마나가 25 이상이면 공격을 버틴다 (공격마다 25 소모, 횟수 제한 없음).
블러디 매드니스, 추가 목숨, 보디가드는 **공격 판정에서만** 적용된다. 무모한 돌진, 정화의 주술, 파괴자의 인도 자살처럼 `Lr`을 직접 부르는 즉사에는 적용되지 않는다.

## 6. 공통 스킬의 troll 변형

### 아군 스캔 A015 (치스) — `Ge`: `Ka` → `La` → 다이얼로그 `av[1]` → `Pa`
- 쿨다운 40, 마나 20. 시전 시 [ALL] "누군가가 {대상} 을 살피고 있습니다."
- 다이얼로그 이름은 슬롯 2~7. 클릭한 이름을 `mr`이라 할 때 판정 (`Pa`):
  1. `b[mr]=="하치"` → [SELF] "스캔에 실패하였습니다." (하치 하이드: 하치라는 이름을 고르면 무조건 실패)
  2. 대상이 슬롯 `mr`의 플레이어(=실제 정체를 맞힘) → [SELF] "성공했습니다. 이 사람은 {b[mr]}입니다." (한 줄)
  3. 고른 이름 = 대상의 공표명 `A[target]`(정체는 틀림):
     - `mr<8` 이고 `Ma()`(대상이 **S00A 위장** 보유 = 네오니스이고 시전자가 B[1]) → "성공했습니다. 이 사람은 {A}입니다." **그 직후 "스캔에 실패하였습니다."도 출력됨** (아래 `mr>7` 분기의 else). 위장하지 않았으면 실패 두 줄.
  4. 그 밖 → 실패 한 줄.
- **버그 (원본 충실 재현 여부 결정 필요)**: 위장에 속은 경우 "성공 + 실패" 두 줄이 나오므로 진짜 성공(한 줄)과 구별된다.

## 7. 고유 스킬

## 8. 위키와 차이 / 인게임 퀘스트 텍스트(`Wr`)와 차이

1. **보디가드는 OR 조건이다**: 툴팁·퀘스트·위키는 "사토시와 즈윈라가 살아있으면"이라고 하지만, 코드 `Xn`은 사토시 **또는** 즈윈라 중 한 명만 살아 있어도 치스를 보호한다. 둘 다 죽어야 치스 공격이 통한다.
2. **네비아탄의 화신(A03E)은 시작부터 보유한다**: 퀘스트에는 "2분 후에 획득"이라고 되어 있지만 부여 코드가 없고, 유닛 기본 어빌리티다. **정화의 주술(A03Q)**도 퀘스트에는 "3분 후"라고 되어 있지만 시작부터 보유한다. 반대로 **야생의 정기(A02X)**는 퀘스트에서 기본 스킬처럼 쓰여 있지만 실제로는 **120초 후 획득**이다.
3. **무모한 돌진의 "네비아탄의 가호"는 코드에 없다**: 퀘스트 문구에는 "성공시 네비아탄의 가호가 없다면 자신도 즉사"라고 되어 있지만, 성공 시 시전자는 항상 죽는다. 또한 돌진 시 시전자 캐릭터명이 전체에 공개된다.
4. **사냥꾼의 표식에는 진명 조건이 없다** (퀘스트에는 "진명을 공표한 상태로 사용 가능"). 위키 요약의 "마나 50"은 맵 데이터에서 확인되지 않았다 (amcs 미설정).
5. **고대의 주술의 쿨다운은 오브젝트상 3600이다** (툴팁은 150). 그래서 사실상 1회용이고, 보유 검사 대상이 잘못되어 있다 (null 타겟 버그).
6. 야생의 축복은 **성공 시 사라지지 않아** 울디안과 울피안 둘 다에게 줄 수 있다. 야생의 길은 메시지가 두 번 나오고(트리거 중복), 진명 검사는 시작과 20초 시점 두 번뿐이다.
