# 리델루트 황야 (mode = "lidellut") — 코드 기준 명세

근거 파일: `GST_v1.33_war3map.j` (함수명은 난독화 이름 그대로). 메시지 표기: **전체** = `GetLocalPlayer()` 브로드캐스트, **본인** = 시전자만, **대상** = 대상 플레이어만. "진명" = `A[p] == GetHeroProperName(o[p])` (공표한 이름이 실제 이름과 같음).
슬롯 번호 `i`(1..12) = 역할 고정 인덱스. `O[i]` = 그 역할을 맡은 플레이어, `b[i]` = 역할 이름, `D[pid]` = 플레이어 → 슬롯 역매핑.

---

## 1. 모드 진입과 역할 배정

- 모드 선택 다이얼로그 `Yr`: 버튼 "리델루트 황야" = `E[3]`. 처리는 `ri`에서 함(직접 선택은 `xi()`, 랜덤 선택은 `a==3`). `U="리델루트 황야"`로 두고 `TriggerExecute(xe)`(= `Ur`, 퀘스트 텍스트 등록)를 실행한 뒤 `X[]`에 유닛 id를 넣음.
- 15초 안에 선택하지 않으면 `ni`에서 내전으로 고정됨(황야는 걸리지 않음).
- 슬롯과 유닛 매핑 (`ri` 625~638 / 689~702행):

| 슬롯 | 유닛 | 이름 | 칭호(유닛 데이터) | 진영(Force) |
|---|---|---|---|---|
| 1 | H00O | 카이 | 프린스 오브 다크니스 | B[1] 다크니스 |
| 2 | H00S | 아린 | 다크 템플러 | B[1] |
| 3 | H00R | 카스파 | 다크 샤먼 | B[1] |
| 4 | H00T | 프레이아 | 프리스티스 오브 그리드 (퀘스트 텍스트에는 "드로우 프리스티스") | B[1] |
| 5 | H00P | 투마 | 플레임 블레이더 | B[1] |
| 6 | H00Q | 세피 | 카오스 위치 | B[1] |

- 배정 `Ei`: 인원수 `Xi`(플레이 중인 유저 수)에 맞는 마스크 문자열 `Oi`를 고르고, 마스크가 '1'인 슬롯마다 남은 플레이어 중 무작위 1명을 배정함(`ForcePickRandomPlayer`). 각자에게 본인 전용 메시지 "당신은 X입니다."가 감.

| 인원 | 마스크 (슬롯 1→12) | 제외 |
|---|---|---|
| 12 | 111111111111 | 없음 |
| 11 | 111110111111 | 세피(6) |
| 10 | 111110111110 | 세피, 카미카제(12) |
| 9 | 111100111110 | 투마(5), 세피, 카미카제 |
| 8 | 111100111010 | 투마, 세피, 로네리스(10), 카미카제 |
| 1 | 000000010000 | 치즈코만 (테스트용) |
| 그 외 | — | "사람 수가 부족합니다!" 패배 처리 |

- 진영 등록과 시작 안내 `Bi`(`Ni()` 분기):
  - 슬롯 1~6 → `B[1]`. 카이: "가디언의 세력을 파멸시켜야 합니다. 샤이닝과 기사단을 모두 살해하면 승리합니다. 당신이 살해당하면 다크니스는 게임에서 패배합니다." 2~6도 같은 목표 문구(패배 문장 없음).
  - 슬롯 7~12 → `B[2]`. "카이를 살해하면 승리합니다." 샤이닝·유이·로네리스·수프라(7, 9, 10, 11)에게는 "샤이닝과 기사단이 살해당하면 가디언은 게임에서 패배합니다."가 추가됨.
  - **추가 목숨** `j[슬롯]`: `j[5]=1` (투마: 2번 맞아야 사망), `j[12]=2` (카미카제: 3번 맞아야 사망). 수프라 `j[11]`은 0에서 시작하고 기사도·천사의 세례로 늘어남. 나머지는 모두 0(1번 맞으면 사망).
- 다이얼로그 구성 `Fi`(`Di()` 분기):
  - 공격 `G[1]` = b[1..6] (다크니스 이름) / `G[2]` = b[7..12] (가디언 이름). **다크니스 소속 시전자는 G[2], 가디언 소속 시전자는 G[1]만 볼 수 있음** (`rn`/`on`). 즉 상대 진영 이름만 고를 수 있음.
  - 스캔 `c` = b[2..6] + b[8..12] (**카이·샤이닝은 목록에 없음**).
  - `av[1]` = b[2..6], `av[2]` = b[8..12] (아군/적군 스캔용, 이 역시 카이·샤이닝 없음).
  - 천사의 세례 `ev` = 버튼 "유이"(xv[9]), "로네리스"(xv[10]), "수프라"(xv[11]). 인원과 관계없이 3개 고정.
  - 제외된 슬롯(b[i]=="")은 모든 목록에서 빠짐.
- 공표 텍스트태그 색(`zi`): 슬롯 >6 이면 파란색, ≤6 이면 빨간색.

## 2. 승리 판정 (`wb`, 트리거 `yo`)

`yo`가 실행되는 시점: 모든 사망(`Lr` 내부), 공격 다이얼로그 처리 직후(`cn`), 매 턴 시작(`qi`), 위대한 의지 실패 3초 후(`zR`). 검사 순서(먼저 만족하는 것만 처리하고 트리거를 파괴함):

1. `Pb` — 다크니스 승리: 샤이닝(O[7]), 유이(O[9]), 로네리스(O[10]), 수프라(O[11])가 **모두 살아있지 않음**. 메시지 "다크니스측이 승리했습니다."
2. `qb` — 다크니스 승리(특수): 샤이닝의 `A02N`(위대한 의지) 레벨이 0(= 사용했다가 실패해서 제거됨) **이고** 유이·로네리스·수프라·**카미카제(O[12])** 모두 사망. 메시지 "가디언에는 더 이상 공격할 힘이 남아 있지 않습니다! 다크니스측이 승리했습니다." 이 경우 **샤이닝이 살아있어도 다크니스가 승리함.**
3. `Qb` — 가디언 승리: 카이(O[1]) 사망. 메시지 "가디언측이 승리했습니다."

- 치즈코는 어느 조건에도 들어가지 않음.
- 같은 사건으로 두 조건이 동시에 성립하면 **다크니스 판정이 먼저**임.
- 승리 시 `Yo`→`yb`가 실행됨: 게임 일시정지, 턴 타이머 정지, 4초 뒤 전원의 실제 역할을 공개함.
- [unverified] 제외된 슬롯(8인의 로네리스, 8~10인의 카미카제)에서는 `O[i]=null`이라 `IsUnitAliveBJ(o[1+GetPlayerId(null)])`를 평가하게 됨. `GetPlayerId(null)`의 반환값을 코드만으로는 확정할 수 없음. 0을 돌려준다면 o[1](빨강 플레이어 영웅)의 생사를 검사하게 되어 판정이 꼬일 수 있음. **구현 권장: 제외된 슬롯은 "사망"으로 취급**(설계 의도로 보임).

## 3. 공통 판정 중 이 모드 전용 분기

### 공격 (`rn` → 다이얼로그 `cn` → `Pr`/`qr`)
- 고른 이름 == 대상의 실제 역할(`b[D[f]]==b[clicked]`)이면 → 보디가드 검사 `nn`: **황야이고, 대상 실제 이름이 카이이고, 아린(O[2])이 살아있으면** → `qr`(공격 실패로 처리하고 페널티 적용). 아니면 `Pr`(명중).
- 이름이 틀리면 → `qr`.
- `qr`: 대상에게 전용 메시지 "<공격자 영웅명>가 당신을 공격하였으나 실패하였습니다." 이어서 공격자 쪽 처리:
  - `A003`(상급 공격) 레벨 1 → 레벨을 2로 올리고 "공격에 한번 더 실패하면 사망합니다." (전체)
  - `A01Z`(최상급 공격) → 페널티 없음.
  - 그 밖(`A002`, 또는 A003 레벨 2) → 공격자 사망(`Lr`)과 정체 공개.
- `Pr`: `j[대상슬롯]>0`이면 1을 깎고 "X는 N회 더 공격받으면 사망합니다."(전체, 영웅명이 공개됨). 아니면 대상 사망. 살해한 쪽이 `S003`(카스파 정기 흡수)을 갖고 있으면 마나 +50.

### 아군 확인 A009/A02J (`Ca`) · 적군 확인 A008/A03H (`Fa`) · 배틀 센스 A03B (`hn`)는 아래 개별 스킬 참조.

### 스캔류 (`Sa`/`Ua`, `La`·`ja`/`Pa`)
- 시전하면 전체에 "누군가가 <대상 플레이어> 을 살피고 있습니다."를 띄우고 다이얼로그를 표시함.
- 성공 조건: 고른 버튼의 슬롯 플레이어 == 대상. 성공 시 본인에게 "성공했습니다. 이 사람은 X입니다."
- 대상이 공표한 가짜 이름을 고르면 `S00A`/`S001`(이 모드엔 없음) 분기를 거쳐 "스캔에 실패하였습니다."가 **두 번** 출력됨(코드 버그, 결과는 실패).
- 목록에 카이·샤이닝이 없으므로 이 둘은 스캔으로 알아낼 수 없음.
- A00T 아군 스캔: 시전자가 B[1]이면 av[1], 아니면 av[2] (샤이닝 → 가디언 b[8..12]).
- A040 적군 스캔: 시전자가 B[1]이면 av[2], 아니면 av[1] (치즈코 → 다크니스 b[2..6]).
- A036/A037: 다이얼로그 `c` (양 진영, 카이·샤이닝 제외). 둘은 쿨다운만 다름(30 / 40).

## 5. 고유 스킬 상세

마나/쿨다운은 오브젝트 데이터(amcs1/acdn1) 값. 쿨다운 3600 = 1회용이며, 실제로는 스크립트가 `UnitRemoveAbility`로 스킬을 제거함.

### 다크니스

**소울 리버 A00B (카이, V, 50마나, 1회)** — `fE`
1. `k[대상]`(영혼의 벽, 다른 모드용)은 이 모드에서 항상 false.
2. 전체: "카이가 <대상플레이어>에게 소울 리버를 시전하여 살해합니다!" → `Lr(대상)` (추가 목숨·보디가드 무시) → 전체: "<대상플레이어>의 정체는 <영웅명>입니다!"
3. 전체: "카이의 정체가 20초 후 드러납니다." → 20초 대기 → 전체: "카이의 정체는 <카이플레이어>입니다!"
- 스크립트가 스킬을 제거하지 않음(쿨다운 3600으로 1회).
- 대상이 샤이닝이어도 즉시 승리하지 않음. 승패는 `wb` 조건으로만 결정됨.

**충복 A00V (아린/카스파, Z, 25마나, 쿨 40)** — `hE`
- 대상 실제 이름이 카이면 → 본인: "이 사람의 정체는 카이입니다!" → 0.2초 뒤 **A00V 제거**(성공하면 소멸).
- 아니면 → 본인: "이 사람은 카이가 아니다." (계속 사용 가능)

**룬 프로텍션 A00W (아린, X, 40마나, 쿨 60)** — 스크립트 없음. 베이스 Aams(안티매직 셸), 지속 45초.
- [unverified] 엔진 효과로 대상이 45초 동안 마법 면역이 되어, 대상 지정 스킬(공격 포함, 모두 커스텀 주문 베이스)의 대상이 될 수 없는 것으로 보임. 구현 권장: 45초 동안 이 유닛을 대상으로 하는 모든 대상 지정 스킬 차단.

**보디가드 A00X (아린, 패시브)** — 더미. 실제 로직은 공격 판정의 `nn`.
- 아린이 살아있는 동안 카이를 정답으로 공격해도 실패로 처리되고 공격자는 페널티를 받음.
- 소울 리버·위대한 의지·매스 텔레포트 등 공격이 아닌 즉사기는 막지 못함.

**정기 흡수 S003 (카스파, 패시브)** — `Pr`. 공격으로 살해 시 마나 +50 (S003 레벨 × 50).

**종교 동맹 A02Y (카스파, 50마나, 1회) / A02Z (프레이아, X, 50마나, 1회)** — `AR`, SPELL_CAST 이벤트.
1. 진명이 아니면 → 시전 취소(stop) + 본인: "자신의 진명을 공표하고 있어야 합니다." (스킬 유지)
2. `A02Z(O[4]) 레벨 × A02Y(O[3]) 레벨 == 0`(상대가 이미 사용해서 제거됨)이면 → 취소 + 본인: "이미 상대방 측에서 종교 동맹의 서신을 보냈습니다."

## 7. 위키와 차이 (코드 기준)
1. **유이 기사도 보상**: 위키는 "성공 시 적군 확인 습득"이라고 함. 코드는 **스캔(A037)**을 주고, 세례까지 받으면 상급 스캔(A036). 적군 확인(A008)은 **로네리스**의 보상임.
2. **배틀 센스 제한**: 위키는 "카미카제·투마 진명 대상 제외"라고 함. 코드에서 그 제한은 투마의 **돌격 감각**(공표 이름 기준)에만 있고, 배틀 센스에는 제한이 없음.
3. **기사단의 심문 대기**: 위키는 2분 30초(게임 내 공지 문구도 150초). **실제 코드는 60초**(툴팁도 1분).
4. **종교 동맹**: 둘 중 한 명만 쓸 수 있고(먼저 쓰면 상대는 막힘), 60초 뒤 **양쪽 모두** 상대 정체를 비공개로 알게 됨.
5. **천사의 세례**: 같은 대상에게 반복해서 성공 가능. 수프라 목숨은 상한 없이 +2씩 누적됨. 세례를 받은 유이가 4점을 채우면 처음부터 상급 매스 텔레포트를 얻고, 이미 매스 텔레포트를 가진 유이에게 세례를 주면 상급으로 교체됨.
6. **합류 대상**: 위키는 "수프라: 로네리스와 유이 대상 합류", "치즈코: 유이·샤이닝 대상 합류"라고 쓰지만 코드에서 성공 대상은 **유이 하나뿐**. 실패하면 시전자 정체가 전체 공개됨. 포인트 상한은 4이며, 8인에서는 보유자가 3명뿐이라 매스 텔레포트를 얻을 수 없음.
7. **다크니스 특수 승리(`qb`)**: 위대한 의지 실패 + 유이·로네리스·수프라·카미카제 전멸이면 샤이닝이 살아있어도 다크니스가 승리함. 치즈코는 어떤 승리 조건에도 관여하지 않음.
8. **보디가드**: 아린이 살아있으면 카이를 정답으로 공격해도 공격자에게 실패 페널티(사망)가 적용됨. 즉사기(위대한 의지·매스 텔레포트·소울 리버)는 막지 못함.
9. **충복·혈족·사령관 탐색**: 성공하면 해당 스킬이 사라짐(위키에는 언급 없음).
10. **미명의 안개**: 지속시간 없이 다음 1회 적군 확인/배틀 센스까지 유지됨. 적군 확인에 걸린 경우에도 프레이아에게는 "배틀 센스"로 통보됨(문구 버그).
