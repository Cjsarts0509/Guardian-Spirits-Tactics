# 정보 수집 대상 단일 교체의 대응 진단

## 결론

새 시드의768대응쌍에서 첫 적격 정보 수집 대상 하나를 교체했을 때 **529→539승**, 점수차이 **+1.3021%p(시드블록 부트스트랩95%+0.2604~+2.4740)**를 관측했다. 해당 고정 합성 조건에서 긍정적인 총효과 신호다.

이것은 **학습 모델의 승률 향상 결과가 아니다.** 앞선6셀 학습 모델은 여전히 모든 조건에서 기존 대상을 선택한다. 이번에는 학습에 쓰던 수동 대안 생성 규칙을 한 판에 한 번 강제로 적용해, 대상 변경에 최종 보상 차이가 있는지 확인했다. 운영 정책에는 연결하지 않았다.

## 고정 조건과 비교

새98000–98015의16시드,4모드×3합성 상대×진영/순서 교차4판으로768fixture, 각각 기존/대체 두 번씩 총1,536실행.8–12인,250ms 틱·활동확률0.012,90분 제한이다.

각 판의 current 진영에서 처음으로 적격한 정보 수집 장면 하나만 선택했다. 대안은 기존 정보 스킬·지정 이름을 유지하면서, 자기 배정 확률상 적일 확률이 높고 예상 정보량이 기존의50% 이상인 다른 대상이다. 나머지 모든 행동은 기본 정책으로 복귀한다. 동맹 제안을 직접 바꾸거나 스킬 사용을 대기로 바꾸지 않는다.

763쌍에서 개입이 발생했고 변경 직전 전체 게임 상태·해당 봇 기억의 해시, 플레이어·시각·원래/대체 행동·마나가 모두 일치했다. 스킬·이름은 동일하고 대상만 다른지도 검증했다. 개입 없는5쌍은 최종 MatchResult까지 일치했다. 다른 봇의 기억 전체를 해시로 보존한 것은 아니며 동일 fixture/정책/RNG로 시작하고 개입 전에는 행동을 바꾸지 않는다.

행동 하나를 바꾼 뒤 난수 소비 순서·후속 판단·전투 궤적이 달라지는 효과까지 포함한다. 고정 시뮬레이터에서의 총효과이며 사람 상대나 여러 봇의 반복 대상 교체 효과를 뜻하지 않는다.

다음 자기 행동 선택은495쌍, 다음 행동 시각은123쌍에서 달랐다. 행동·시각·허용 결과를 합친 다음 시도 기록의 차이는499쌍이다(요약 nextActionDifferent). 대체 실행에서 원래 대상에게 이후 허용된 대상 지정 행동을 한 경우549개입, 그 시각 중앙값60초다. 이는 같은 정보 스킬의 재시도가 아니라 **아무 대상 지정 스킬의 재방문**을 센 지표다. 나머지214개입은 종료까지 관측되지 않아 지연 평균에 포함하지 않았다.

## 학습에 대한 의미와 후속 결정

최종 승패에 대상 선택 신호가 전혀 없다고 보기는 어렵다. 다만 이전 학습은 각 봇이 한 번씩 무작위 대상을 선택하고 같은 판의 최종 보상을 공유했으며, 이번 진단은 판 전체에서 단 한 번의 선택을 비교했다. 효과를 추정하는 대상과 데이터 분포가 다르므로 이전 학습 실패를 특정 원인 하나로 설명할 수 없다. 기존0.03 후보 선택 기준과 이번+0.0130 전체 판 효과도 서로 다른 지표라 단순 비교해 기준을 낮추지 않는다.

이 결과로 즉시 모델을 승격하지 않는다. 다음은 이 고정 대상 교체 규칙을 변경하지 않은 채 새 시드에서 재확인하고, 대상만 다른 대응 실행의 보상 차이를 학습 레이블로 쓰는 설계를 분리하는 것이다. 이번98000–98015를 향후 최종 검증에 재사용하지 않는다. 이전에 보존한96000/97000 구간은 이번에도 사용하지 않았다.
