# 내전 재검증·탐색 최적화·인물별 후속 스킬

후속 성장·희생·다음 턴 평가와 최종 검증은 [BOT_SEQUENCE_EXTENDED.md](BOT_SEQUENCE_EXTENDED.md)를 참조한다.

기존 확인/공표 탐색의 내전 개선 재현성, 판단을 보존하는 계산 최적화, 인물별 후속 후보 확장을 각각 구분해 검증했다. 스킬 확장은 `sequenceSearch: true, sequenceSkills: true`일 때만 사용한다. 기본값은 둘 다 비활성화다.

## 내전 독립 재검증

이전 고정 코드 `cfafcb94c15d1ac99cb8c4ba533ebd4deeadf0e5`(같은 로컬 소스 `539f64a`)를 별도 체크아웃에서 실행했다. 기존 4모드 평가에서 내전을 선택한 뒤, 정책을 바꾸지 않고 새 시드 46000–46199의 200블록을 평가했다. 8–12인, 진영/순서 교환, 같은 최신 규칙 엔진의 운영 기본 정책과 비교한 800판이다.

| 결과 | 값 |
| --- | --- |
| 승 / 패 / 미종료 | 432 / 368 / 0 |
| 점수 | 54.0% |
| 시드 부트스트랩 95% 구간 | 51.5–56.625% |
| 초반 공격 실패 | 두 정책 모두 0회 |

이전에 내전 400판에서 나온 54.25%의 개선 신호가 새로운 표본에서도 재현됐다. 이 결과는 **기존 기본 후속 정책의 내전 한정 결과**다. 모든 모드·인간 상대·인물 스킬 확장 정책의 개선을 뜻하지 않는다. 원자료/실행 설정/해시는 `evaluations/sequence-civil-revalidation-200.json`에 보존했다.

## 판단을 보존하는 최적화

동일한 원본 본인 기억에서 자기 뷰와 본인 수신 이벤트가 모두 같은 경우, 후속 판단을 한 번 계산하고 재사용한다. 캐시 키에 가설 배정이나 상대의 숨은 자원을 넣지 않는다. 캐시는 한 번의 탐색에서만 사용하며 다른 실제 호출로 넘어가지 않는다. 후속 판단이 필요한 경우에만 본인 기억을 복제한다. 가상 상태의 실제 행동·자원/대응 끝점·8개 배정·최대 128수순은 줄이지 않았다.

최적화 고정 소스: 원격 `021f3c79396969f1bc84adf7660d9024c0f47619`, 로컬 `d872c93`.

같은 합성 위치 400개에서 측정 순서를 번갈아 비교했다. 선택·점수·수순 수가 전부 일치했다. 후속 실제 계산은 1,426회, 재사용은 26,350회였다.

| 로컬 비용 | 이전 | 최적화 |
| --- | ---: | ---: |
| 중앙값 | 28.62ms | 24.60ms |
| p95 | 64.07ms | 36.89ms |
| 최대 | 93.11ms | 60.12ms |

추가로 탐색을 켠 4모드 80개 대전 조건을 각각 두 번 실행해 전체 대전 결과 객체가 동일함을 확인했다. 스킬 옵션은 꺼진 호환성 검증이며 새 성능 표본이 아니다. 원자료는 `sequence-optimization-audit.json`, `sequence-optimization-compatibility.json`이다. 확장 모듈 통합 후에도 같은 80개 조건의 결과가 모두 일치했다(`sequence-optimization-final-compatibility.json`). 비용은 동시 검증 작업이 진행되는 로컬 Node 환경 수치이며 VM/라이브 서버 지연이나 최악 실행 시간 보장이 아니다.

## 인물별 후속 후보 25종

후속 후보의 추가 범위다. 첫 행동은 여전히 확인/스캔/공표이고, 실제 봇에 두 번째 행동을 예약하지 않는다. 다음 실제 호출은 기존 우선순위와 활동 확률에 따라 다시 판단한다.

| 범위 | 스킬 |
| --- | --- |
| 즉사/직접 공격 8종 | 마황자의 명령, 소울 리버, 라엘·킬데르 마스터 권능, 학살, 백스탭, 피닉스의 불꽃, 울프스 슬러쉬 |
| 행동 불능 4종 | 블랙 스펠, 교란, 나이트메어, 플레임 쉐클 |
| 아군 지원/보호 7종 | 인챈트먼트 머슬, 천사의 세례, 차크라 매직, 사신트 지원, 지원, 룬 프로텍션, 영혼의 회복 |
| 아군 해제 1종 | 중화의 주술 |
| 정보/성장 5종 | 라엘·엘타스 기본 리더쉽, 리비도의 여사제, 저주, 기사도 |

자기 관찰로 확정한 적/아군만 공격·제어·지원 대상으로 삼는다. 마황자의 명령은 확인된 카이, 피닉스는 확인된 컨슘, 백스탭은 나에게 동맹을 건 확인된 적으로 제한한다. 이미 행동 불능인 적에게 제어를 반복하지 않고 아군 해제는 확인된 아군에게만 사용한다. 세례는 확인된 기사 이름과 이전 세례 기억을 검사한다. 패시브를 액티브 후보로 넣지 않으며 자기 마나·쿨다운·횟수·스킬 차단 사유·공표 조건은 새 뷰와 엔진으로 검사한다. 상대 쿨다운/방어 자원은 기존 관찰 기반 가설을 사용한다.

정보기는 후속 행동을 실제 엔진에서 처리한 뒤 본인에게 전달된 사실에 따른 후보 엔트로피 감소로 평가한다. 실패나 모호한 지휘관 결과를 가설의 실제 정체로 대체하지 않는다. 예를 들어 공표 후 열린 리더쉽/리비도의 여사제와 저주를 평가하되, 저주가 숨은 마나 조건 때문에 실패하면 그 실패 자체를 정체 확인 성공으로 점수화하지 않는다. 확장 옵션에만 아군 마나 증감·제어/보호·영혼의 회복 보조 가치를 더한다. 이 보조 가중치는 학습된 승률/인간 전략 모델이 아니다.

확장 정책 고정 소스: 원격 `47c1c090deeff0317dc17df0c071e51938118b44`, 로컬 `71d8c37`. 개발 시드 48000–48009의 160판은 48.125%(45.625–51.25%)였고 모두 종료했다. 이 점수를 보고 정책을 다시 튜닝하지 않았다. 새 시드 49000–49099의 1,600판 독립 평가 결과는 다음과 같다.

| 모드 | 승 / 패 | 점수 | 시드 부트스트랩 95% 구간 |
| --- | --- | ---: | --- |
| 내전 | 217 / 183 | 54.25% | 51.5–57% |
| 태초 | 212 / 188 | 53% | 50.25–56% |
| 황야 | 205 / 195 | 51.25% | 47.75–55% |
| 트롤 | 189 / 211 | 47.25% | 44.25–50.25% |
| 전체 | 823 / 777 | 51.4375% | 50.0625–52.875% |

모든 대전이 종료했고 두 정책의 초반 공격 실패는 0회다. 전체 구간 하한은 50%를 근소하게 넘는 약한 개선 신호지만, 트롤은 열세이며 황야도 개선을 확정할 수 없다. 모드별 구간은 다중 비교를 보정하지 않았다. 비교 상대는 운영 기본 정책이고, 새 확장 옵션과 기본 후속 탐색 옵션을 직접 대전시킨 결과는 아니다. 이전 단계와 시드가 다르므로 50.125% → 51.4375%를 인물 스킬 추가만의 개선 폭으로 해석하지 않는다. 트롤 열세와 VM 미실측 비용을 포함해 전 모드 기본 활성화·운영 배포는 하지 않는다. 독립 평가 이후 정책을 다시 튜닝하지 않았다.

원자료/실행 설정/소스 해시는 `sequence-skills-heldout-100x4.json`에 보존했다.

확장 옵션의 합성 400위치 비용은 중앙값 25.12ms, p95 34.84ms, 최대 66.59ms다. 이전 최적화 비교와 시드/정책이 다르므로 비용 차이를 추가 개선 폭으로 해석하지 않는다. 원자료는 `sequence-skills-audit.json`이다.

개발용 32판에서 같은 실제 위치의 본인 기억을 복제해 확장 옵션과 기본 후속 옵션을 비교했다. 총 161,694회 호출 중 행동 857회, 선택 차이 30회였다. 같은 스킬의 대상/이름 차이도 포함한다. 추가 진단은 실제 기억과 행동 RNG를 바꾸지 않았다. 이때 행동을 반환한 호출(탐색 외 기존 행동도 포함)의 로컬 비용은 중앙값 0.30ms/p95 26.78ms/최대 49.30ms였다. `sequence-skills-decisions.json`은 후보 확장이 실제 선택에 영향을 주는지 확인한 개발 진단이며 독립 성능 표본은 아니다.

## 검증과 남은 범위

전체 330개 테스트(규칙 311 + 서버 19), 타입 검사, 클라이언트/서버 빌드가 통과했다. 새 테스트는 진명 전후 사용 가능 여부와 개인 정보 이득, 미확인 대상 공격 금지, 즉사기의 대상·쿨다운·횟수, 제어 중복 방지, 아군 해제, 세례 조건, 지원 마나, 패시브 제외, 입력/정체 기억/RNG 보존과 수순 상한을 검증한다.

모든 인물의 모든 스킬 수순은 아직 구현하지 않았다. 고급 리더쉽 등 나머지 정보기, 광역·희생·진화 수순, 다음 턴 패시브/공표 노출의 장기 가치, 상대의 과거 비공개 기억, 모든 예약 작업과 조건부 flags의 상관관계가 남아 있다. 현재 스트레스 끝점은 확률도 전체 도달 가능한 자원 이력의 증명도 아니다. 자기 상태 효과가 있으면 탐색을 건너뛰는 제한도 유지한다.

```bash
# packages/rules에서. 내전 기존 결과를 재현할 때는 이전 고정 소스에 동일 검증 스크립트를 복사한다.
node --import tsx scripts/sequence-validation.ts 200 46000 civil_war plain
node --import tsx scripts/sequence-validation.ts 100 49000 all skills
node --import tsx scripts/sequence-skills-audit.ts
node --import tsx scripts/sequence-skills-decisions.ts
# 이전 체크아웃의 절대 경로를 지정하는 비교
node --import tsx scripts/sequence-optimization-audit.ts /path/to/frozen/packages/rules/src/bot-sequence.ts
node --import tsx scripts/sequence-optimization-compatibility.ts /path/to/frozen/packages/rules/src/bot.ts
```
