# 전술 우선순위 복구와 독립 검증

요청한 1·2·4단계(판단/패배 원인 진단 → 정책 수정 → 독립 성능 검증)를 한 묶음으로 진행했다. 기본 AI 설정은 변경하지 않았다. 수정 정책 고정 소스는 원격 `890edc85e6d88ba35fe4e33dd5fa92c13d4a4211`, 로컬 `4962900`, 트리 `57b95bf1dc4de463289385a00b1f6f7bcb8277bc`다.

## 1. 관측된 판단 결함

이전 확장(`68de00c`, 로컬 `85038b9`)은 독립 400판에서 25종 정책 대비 47.5%였다. 이 승률만으로 모든 패배의 원인을 알 수 없으므로, 별도 개발 시드 55000–55001의 32판에서 실제 호출 직전 기억을 복제해 25종 정책의 선택을 같은 위치에서 비교했다. 그림자 선택은 실제 게임이나 행동 RNG에 반영하지 않았다.

| 진단 | 수정 전 | 수정 후 |
| --- | ---: | ---: |
| 실제 호출 | 193,517 | 189,016 |
| 행동 반환 | 1,058 | 1,027 |
| 같은 위치의 25종 정책과 선택 차이 | 122 | 5 |
| 기존의 확인된 공격 대신 비공격 행동 선택 | 13 | 0 |
| 위 전술 지연 중 성장 후보가 없는 경우 | 13 | 0 |
| 모델 후속에서 성장 때문에 공격이 밀린 사례 | 0 | 0 |

수정 후에는 같은 시드/좌석 조건을 다시 실행했지만 게임 경로가 달라지므로 두 열은 동일 위치 1:1 비교가 아니다. 각 열 안의 그림자 비교가 동일 위치 비교다. 이 수치는 개발 진단이며 승률의 독립 검증이나 개별 패배의 인과적 귀속이 아니다.

구체적으로 아린이 확인한 프레이아를 공격할 수 있는데 다른 대상을 상급 적군 확인하거나, 단테스가 확인한 카이를 마황자의 명령으로 처치할 수 있는데 아군 확인을 택했다. 또한 보석·리더쉽·종교적 결속·유이 합류·야생 성장 등 기존 역할 행동을 확장 확인 탐색이 먼저 가로채는 사례가 있었다. 수정 전 코드가 확정 공격 루프 앞에서 탐색을 실행하면서, 첫 후보에는 해당 전술 행동을 넣지 않은 것이 이 지연의 구현상 이유다.

모델 후속 정책도 성장 행동을 공격보다 먼저 반환하는 구조였다. 이 개발 표본에서는 그 구조 때문에 공격이 밀리는 사례를 관측하지 못했다. 실제로 성장 조건을 갖춘 컨슘에게 확인된 적과 준비된 공격이 동시에 있는 경우를 회귀 테스트로 구성해 보완했다. 이를 관측된 패배 빈도로 표현하지 않는다.

원자료: `sequence-priority-diagnosis.json`, `sequence-priority-revised-diagnosis.json`. 수정 전 진단은 커밋 `64936ea`(로컬 `9a4c8bc`)에서 고정했다.

## 2. 수정 내용과 검증

- 실제 봇의 기존 확정 공격·역할 행동을 보존했다. 기존 첫 공표·해금 우선순위는 유지하며, 확인 수순 탐색을 원래 정보 수집 지점에서만 실행한다.
- 가설 후속에서도 전용 처치/긴급 해제와 준비된 확인 공격을 먼저 선택하고, 그런 행동이 없을 때 성장 후보를 선택한다. 패시브를 시전 후보로 넣지 않는다.
- 사용 가능한 성장 후보도, 30초 이내 예측 가능한 턴도 없으면 기존 25종 탐색과 같은 후보를 사용한다. 이 경우 첫 확인 후보를 3개에서 2개로 잘라내거나 세 번째 행동을 추가하지 않는다.
- 평가 가중치를 독립 결과에 맞춰 튜닝하지 않았다. 희생·보석·생존의 기존 평가 점수와 관찰 기반 정보 경계는 유지했다.

전체 345개 테스트(규칙 326 + 서버 19), 타입 검사, 클라이언트/서버 빌드를 수행했다. 추가 6개 회귀 테스트는 확인된 카이 처치, 아린의 확인된 적 공격, 최종 진화보다 준비된 공격 우선/공격 쿨다운 시 진화 허용, 확장 기회가 없는 경우 결과·수순·캐시 지표 일치, 공표만 한 대상 공격 금지, 기존 보석 선택 보존을 검증한다. 입력 관찰·정체 기억·행동 RNG 보존도 검사했다.

새 옵션을 끈 정책과 고정 이전 소스를 4모드 80개 대전 조건에서 각각 실행한 160개 결과 객체가 모두 동일했다. 이 비교는 기존 25종 비교 정책의 호환성 확인이며 개선 성능 표본으로 세지 않는다. 원자료는 `sequence-priority-compatibility.json`이다.

## 4. 정책 고정과 독립 비교

개발 시드 56000–56009의 160판에서 수정 전 확장 대비 52.5%(시드 부트스트랩 95%: 48.125–56.875%)였고 모두 종료했다. 개발 결과를 보고 정책을 재조정하지 않았다.

최종 비교는 두 종류를 사전에 고정해 서로 다른 새 시드에서 진행했다. 각 모드의 같은 시드에 대해 양 진영과 정/역방향 좌석을 교차한 4판을 한 블록으로 묶는다. 인원 8–12명, 틱 250ms, 행동 확률 0.012, 시간 제한 90분이다. 구간은 시드 블록 부트스트랩 2,000회이며 모드별 다중 비교는 보정하지 않았다.

| 비교 상대 | 시드 | 판 수 | 목적 |
| --- | --- | ---: | --- |
| 수정 전 확장 `68de00c` | 57000–57099 | 1,600 | 우선순위 수정으로 퇴행을 복구했는지 확인 |
| 이전 25종 정책 `b7c56ee` | 58000–58099 | 1,600 | 복구를 넘어 추가 개선이 있는지 확인 |

## 처리 비용과 완료 범위

정체 공개 여부와 턴까지 남은 시간을 나눠, 동일한 합성 800위치에서 수정 전/후 전체 `smartBotAction` 호출을 교차 순서로 측정했다. 각 조건 200위치, 마나 100, 모든 생존자는 진명 공표 상태다. 정책의 탐색 함수만 측정한 기존 비용 표와 구분한다.

| 관측 조건 | 중앙값 이전 → 수정 | p95 이전 → 수정 | 최대 이전 → 수정 |
| --- | ---: | ---: | ---: |
| 정체 비공개 / 턴 50초 전 | 19.77 → 0.42ms | 33.87 → 40.76ms | 55.55 → 64.12ms |
| 정체 공개 / 턴 50초 전 | 0.21 → 0.18ms | 7.90 → 0.45ms | 19.99 → 15.08ms |
| 정체 비공개 / 턴 10초 전 | 29.09 → 0.39ms | 49.40 → 61.03ms | 65.13 → 89.31ms |
| 정체 공개 / 턴 10초 전 | 0.22 → 0.18ms | 8.05 → 0.35ms | 26.14 → 14.79ms |

중앙값은 크게 낮아졌지만 정체 비공개 조건의 p95/최대는 악화됐다. 기존 보석·역할 정보기를 바로 실행하는 경로에는 별도 계산 비용이 있어 보편적인 지연 개선으로 해석하지 않는다. 정체 공개 조건에서는 p95도 낮아졌다. 합성 위치의 선택 차이는 총 190/800개였고 실제 호출 분포나 VM 수치가 아니다. 로컬 Node 24에서 다른 대전 프로세스가 끝난 뒤 측정했으며 VM Node 22 실측은 하지 않았다.

이번 정책은 기본 비활성화로 유지하고 PR 초안에 코드·진단·독립 결과·비용 자료를 보존했다. 개선이 확인되지 않은 변형을 운영 릴리즈나 VM에 반영하지 않았다.

원자료는 `docs/evaluations/sequence-priority-*`에 정책 소스 해시와 함께 보존했다. 진단·정책 수정·회귀/통합 테스트·독립 비교·비용 비교가 이번 요청의 완료 범위다. 장기 수순 확장(3단계), 운영 병합/릴리즈/VM 실측(5단계), 인간 상대 검증(6단계)은 이번 범위에 포함하지 않았다. 새 결과만 보고 특정 모드에 과적합한 가중치 변경이나 기본 활성화를 하지 않았다.

```bash
# packages/rules에서. 첫 경로는 68de00c 정책의 고정 체크아웃이다.
node --import tsx scripts/sequence-priority-validation.ts 100 57000 all extended /path/to/68de00c/packages/rules/src/bot.ts
node --import tsx scripts/sequence-priority-validation.ts 100 58000 all roles
node --import tsx scripts/sequence-priority-report.ts /path/to/68de00c/packages/rules/src/bot.ts
node --import tsx scripts/sequence-priority-cost.ts /path/to/68de00c/packages/rules/src/bot.ts
```
