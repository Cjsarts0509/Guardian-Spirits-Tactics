# GST AI 평가 기준 — 행동 품질, 대전 성능, 게임 균형

2026-10-15 사용자 요청 반영. 034회차 재개부터 적용한다. 과거 평가의 수치나 당시 미채택 판단을 소급 변경하지 않는다.

## 세 가지 독립적인 질문

| 평가 | 확인할 질문 | 측정 단위와 기준 |
|---|---|---|
| 행동 품질 | 알고 있는 정보를 기억하고 일관되게 사용하는가? | 실제 기회 대비 이행률, 잘못된 확정·정보 누출·오보고 수, 구체적인 행동 재현 |
| 상대 전투 성능 | 같은 상대·배정에서 이길 가능성이 달라졌는가? | 고정 상대 풀, 진영·순서 교환, 시드 단위 신뢰구간, 모드별 부작용 |
| 게임 균형 | 같은 정책으로 플레이할 때 특정 진영·조합이 유리한가? | 동일 정책 자기대전의 진영/모드/인원/역할 조합별 결과. 캐릭터 생존과 팀 승률을 구분 |

같은 정책끼리 양쪽 진영을 교환한 대전에서는 정책 전체 점수50%가 구조적으로 성립할 수 있다. 이 값만으로 지능이나 균형을 증명하지 않는다. 비대칭 역할의 개별 승률을 모두50%로 만드는 것도 목표가 아니다. 역할 선택 빈도·인원·진영 편성과 조건부 스킬 사용 가능성을 함께 기록해야 한다.

## 행동 품질의 요구

1. 확인된 아군 동맹·지원과 확인된 적 동맹 파기를 상황에 맞게 수행한다. 마나/쿨다운/보호/확정 공격 등 실제 불가능·상충 조건을 분모에서 분리한다.
2. 아군에게 실제 게임 대화로 정보를 전달한다. 직접 증거와 전달받은 보고를 구분하며 위장·미확인 발신자·상충 보고를 확정 사실로 올리지 않는다.
3. 자기 실제 행동과 본인이 본 결과를 기억한다. 명중으로 확정할 수 있는 정체는 이후 공격·동맹·공유 판단에 반영하고, 실패 원인이 모호하면 정체 부정으로 해석하지 않는다.
4. 공표·성장·탐색의 목적과 자원 비용을 함께 본다. 행동 횟수 증가·마나 절약·보석 완성 자체를 종합 개선으로 간주하지 않는다.
5. 같은 실패를 새 근거 없이 반복하는지, 이미 확정한 사실을 불필요하게 재확인하는지 측정한다. 재확인에 별도 전술 가치가 있으면 구분한다.

구현 정확성은 실제 엔진 재현·정보 은닉·호스트 기억 복원·관측ON/OFF 경기 동일성으로 검증한다. 숨은 정체는 선택이 끝난 뒤 외부 채점에만 사용한다. 성공 사례만으로 이행률을 만들지 않고 적격 기회·실제 이행·종료/사망 등 제외 사유를 모두 남긴다.

## 채택과 운영 반영

- 명백한 기억/논리 오류 수정은 기능 정확성을 먼저 판정한다. 고정 상대 승률이 기준보다 낮다는 사실만으로 기능 가치가 없다고 결론내리지 않는다.
- 실제 성능 저하가 있으면 크기·불확실성·모드·원인을 기록하고 다음 전술 보완 대상으로 남긴다. 기능 검증 통과를 전투 성능 개선이나 운영 검증 완료로 표현하지 않는다.
- 탐색/공표 등 경험적 전략 후보는 새 표본에서 행동 목적과 부작용을 함께 검증한다. 기존 최종 평가 자료로 다시 조건을 맞추지 않는다.
- 개발 평가로 운영 배포하지 않는다. 사람 상대 검증은 실제 사람 참가 기록으로만 주장한다.
- 스킬 수치 조정은 AI 수정과 별도로 한다. 먼저 정책 활용 누락을 점검하고, 고정된 AI에서 진영·조합의 지속적인 불균형이 관측될 때 단일 변경을 비교한다.

## 034회차 사전 평가

자기 명명 공격 성공을 대상ID와 연결하는 단일 옵션 learnOwnAttackOutcome을 기본OFF로 검증한다. 다른 실험 옵션은 추가하지 않는다. 새 개발145000–145007,4모드×3상대×진영/순서4교환×main/control/후보=1,152실행. 독립121000은 이번에 사용하지 않는다.

핵심 품질: 이름을 모르고 성공한 공격 중 경기 계속/본인 생존/대상 생존인 적격 기회가 본인 다음 관측에서 정확히 기억되는지. 잘못된 기억0, 실패/타인 응답의 확정0, 공개 이벤트·상대 뷰 변경0. 이어서 같은 대상의 공격/기타 스킬·정보 전달을 기술 집계하되 인과적인 승률 기여라고 주장하지 않는다.

기존 검증기의 developmentGatePassed는 역사적인 승률 기준의 진단값으로 보존한다. 이 회차의 기능 정확성 판정과 혼동하지 않는다. 후속 동일 정책 자기대전은 별도 시드/보고서로 진행한다.
