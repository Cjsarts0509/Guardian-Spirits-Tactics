## 이번 라운드에서 확정한 사항

- 공표 배율4의 추론 오차 개선은 대전 실력 개선으로 이어지지 않았다. 정보 선택만 보정한 변형도 독립 기준 미통과다.
- 보호 거절 재시도 지연은 반복 거절을 줄였지만 승률 개선 근거가 없으며 기본OFF다.
- 동맹을 정보 수집으로 미루는 후보는 독립 평가와 단일개입 진단을 거쳐 미채택 종료했다.
- 정보 대상 교체에는 탐색적 긍정 신호가 있었으나 고정 규칙의 새 재현과 실제 개인별 적용 최종평가에서 채택 근거를 얻지 못했다.
- 기본 AI는 기존 규칙·자기 관찰 기억·배정 확률 추론을 유지한다. 게임 간 사용자 학습이나 실시간 강화학습을 구현했다고 표시하지 않는다.
