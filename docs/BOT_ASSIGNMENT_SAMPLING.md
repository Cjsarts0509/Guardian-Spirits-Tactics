# 전체 정체 배정 생성 기반

## 현재 단계

정체 확률·스킬 판단·황야 확인 탐색 다음에 전체 배정 생성 API를 추가했다.
실제 행동 선택에는 연결하지 않는다. 다음 단계는 가설 배정과 공개 관찰만으로
불확실한 자원/방어 상태를 구성하고 확인 이후의 행동을 비교하는 것이다.
상대의 실제 숨은 마나·쿨다운·패시브 상태를 복사해서 시뮬레이션해서는 안 된다.

## 알고리즘과 경계

`sampleAssignments(view, knowledge, memory, searchRng, count = 32)`는 역할 중복 없는
전체 배정을 반환한다. 입력은 자기 뷰와 정당한 확인 기억뿐이다.
자기 정체는 고정하고 죽은 사람도 전체 배정의 제약에 포함한다.
주변 확률을 독립으로 뽑거나 중복 역할을 사후 교체하지 않는다.

기존 믿음의 부분집합 DP에서 역할을 사용한 집합을 `mask`라 할 때, 다음 역할
`j`의 조건부 가중치는 `weight[i][j] * suffix[mask | (1 << j)]`다.
이는 동일 공표 가중치와 확인 제약으로 계산한 결합 배정 분포를 표본화한다.
공표 가중치 자체의 정확성이나 실제 정체를 보장하지 않는다.

한 호출은 최대 256개다. 모순되거나 맞지 않는 배정 차원에서는 빈 배열을 반환하며
숨은 정답으로 대체하지 않는다. 표본은 가설이므로 확인 사실이나 배제 사실로
기억에 넣지 않는다. 호출자는 행동 RNG와 별도의 RNG를 사용해야 한다.
표본 Map은 서로 독립이며 반환값의 수정은 확인 기억이나 다음 표본에 영향을 주지 않는다.

표본화용 DP는 요청할 때만 보관한다. 기존 믿음 캐시가 이미 있으면 첫 표본 요청에
suffix DP를 생성하고 기존 믿음 객체를 보존한다. 새 관찰로 시그니처가 바뀌면
새 모델을 사용한다. WeakMap은 믿음 객체가 수거될 때 모델도 해제한다.
일반 정책은 표본 API를 호출하지 않으므로 이 모델을 보관하지 않는다.

DP 생성은 `O(n² 2ⁿ)`, 캐시 사용 후 K개 표본 생성은 `O(K n²)`다.
12인 게임에서는 다른 사람 n=11의 suffix 버퍼가 16KiB이며, 역할/가중치 배열과
반환 Map에는 추가 메모리가 필요하다. 메모리 크기나 시간의 실시간 상한은 보장하지 않는다.

## 검증

- 4개 모드의 전체 배정에서 자기 정체·역할 유일성·확인 후보 제약 보존.
- 3개 미확정 역할의 6개 순열을 직접 열거해 가중 결합 확률 계산. 16,384개
  고정 난수 표본의 결합 빈도가 각 확률의 6 표준오차 이내인지 확인.
- 모순된 후보에서 빈 배열과 RNG 보존, 표본 수 제한, 별도 RNG 강제.
- 실제 숨은 배정을 바꿔도 같은 자기 관찰이면 같은 난수 표본 생성.
- 새 후보 제약의 캐시 무효화와 반환 Map 변경의 독립성.
- 표본 생성 전후 기존 행동·행동 RNG·확인 기억의 보존.

시드 27000–27019, 8–12인, 네 모드에서 시드당 진영/순서 교환 4판씩 총 320판을
실행했다. 비교 양쪽 모두 운영 `8be1574`의 행동 정책이며 한쪽은 행동 결정 뒤
32개 표본을 생성해 검증한다. 표본은 행동 선택에 사용하지 않는다.
총 333,408개 가설 배정에서 제약 위반은 없었고, 모든 판이 종료했다.
네 모드 각각 40승/40패, 50%였다. 이는 정책 보존 확인이며 승률 개선 실험이 아니다.
두 쪽은 동일한 새 믿음 계산을 쓰므로 이전 바이너리와 CPU 비용 비교도 아니다.

12인 내전, 관찰 없는 뷰, 32개 표본의 로컬 측정:

| 측정 | 시간 |
| --- | ---: |
| 첫 호출 | 0.445ms |
| 캐시 사용 중앙값 | 0.029ms |
| 캐시 사용 95백분위 | 0.044ms |
| 캐시 사용 최대, 1,000회 | 0.179ms |

이 측정은 실행 환경과 부하에 의존하며 VM의 처리 지연이나 최악 시간 보장이 아니다.
