# 공표 자원 보호 비교

`claimStrategy: 'adaptive-resources'`는 기존 적응형 공표의 비교용 옵션이다. 기본 `truthful`과 기존 `adaptive`의 동작은 유지한다. 태초 모드의 한 별도 시드 묶음에서 개선됐으나 추가 시드와 다른 모드에서 일관성이 없어 기본 정책으로 채택하지 않는다.

## 확인한 누락과 보완

진명 공표는 턴마다 마나 10과 보석 성장의 이익을 제공한다(`engine/time.ts`). 기존 적응형 공표는 진명 의존 액티브·패시브 스킬을 보호하지만 이 자원 이익은 판단하지 않았다.

새 옵션은 자기 뷰만 읽어 다음 조건이면 진명을 유지한다.

- 보석이 아직 완성되지 않았음(`gem < 3`).
- 다음 턴까지 쿨다운이 끝나는, 사용 횟수가 남은 이름 공격의 마나를 공표 비용을 지불한 뒤 확보하지 못함.

이름 공격 범위는 기존 `NAME_ATTACKS`를 사용한다. 소모된 스킬과 패시브는 마나 예약 대상에서 제외한다. 상대의 숨겨진 마나·쿨다운은 읽지 않는다. 진명 필수 스킬과 공개된 자기 정체에 대한 기존 보호도 유지한다. 공격할 대상이 실제로 있는지까지 최적화하는 정책은 아니며, 보석과 마나의 효과를 각각 분리한 실험도 아니다.

## 평가 설계

세 정책을 같은 시드·역할 배정으로 비교했다. 각 시드마다 진영·플레이어 순서를 교환한 4판이다. 상대는 고정 기준(c505d4b), 진명 강제, 거짓 공표 강제, 진명 필수 스킬을 보호하는 거짓 공표 강제의 네 종류다. 합성 상대이며 사람의 성향을 대표하지 않는다.

| 결과 파일 | 시드 | 범위 | 판수 |
|---|---|---|---:|
| claim-resources-diagnostic.json | 12000–12019 | 태초 | 960 |
| claim-resources-holdout.json | 13000–13029 | 태초 | 1,440 |
| claim-resources-cross-mode.json | 14000–14014 | 네 모드 | 2,880 |

총 5,280판. 제한 미종료는 0.5점으로 집계한다. 아래 수치는 승리 점수이며 엄밀한 승률과 구분한다.

고정 기준·진명 강제 상대에서는 모든 묶음·모드에서 세 정책 모두 50%점수이고 가명 공표는 0회다.

별도 태초 시드의 강제 블러핑 상대에서 기존 적응형은 가명 공표 146회 중 보석 미완성 상태 105회, 공표 후 공격 마나 부족 상태 50회였다(두 조건은 중복될 수 있다). 자원 보호 옵션은 두 항목 모두 0회였다. 평가 관측자는 합성 상태에서 자기 자원을 집계하며 이 집계 결과를 봇 의사결정에 전달하지 않는다. 이 수치만으로 패배의 원인을 확정할 수는 없다.

별도 태초 시드에서 자원 보호−기존 적응형 점수 차이는 +10.0%p, 동일 시드 차이 2,000회 부트스트랩(random.Random(1), 2.5–97.5 백분위 근사)의 95% 구간은 [+3.3, +17.5]%p였다. 그러나 진명 고정 대비 +3.75%p의 구간은 [0.0, +7.5]%p이고, 추가 태초 시드에서는 진명 고정보다 낮았다. 다중 비교·적은 시드 수를 고려해 전체 개선으로 해석하지 않는다.

공표 왕복도 늘었다. 별도 태초·강제 블러핑 상대에서 기존 적응형은 진명 공표 602회·가명 146회, 자원 보호는 진명 670회·가명 146회였다. 자원 보호 조건이 변할 때 재공표 비용이 생기므로, 현재 옵션을 기본 적용하거나 모든 모드의 기존 적응형을 대체하지 않는다.

미종료 1판은 진명 고정 대 강제 블러핑 상대(seed 13008, 11인, 역순, 현재 진영 2)에서 발생했다. 기존 적응형과 자원 보호 옵션은 평가한 모든 판이 종료됐다. 모든 정책의 초반 공격 실패는 0건이다. 스킬 거절은 원본 결과에 따로 집계했다.

## 재현 및 검증

`packages/rules`에서 실행한다.

```sh
node --import tsx scripts/claim-resources.ts 20 12000 all primordial > ../../docs/evaluations/claim-resources-diagnostic.json
node --import tsx scripts/claim-resources.ts 30 13000 all primordial > ../../docs/evaluations/claim-resources-holdout.json
node --import tsx scripts/claim-resources.ts 15 14000 all all > ../../docs/evaluations/claim-resources-cross-mode.json
```

원본 결과의 소스 해시를 실제 파일과 대조했다. 타입 검사, 전체 테스트 279개(규칙 260개·서버 19개), 서버·클라이언트 빌드 통과. 신규 테스트 2개는 보석 완성 여부, 공표 비용을 포함한 마나 경계, 쿨다운 경계, 횟수 소진, 성향 증거가 있어도 자원을 보호하는지 검증한다.

다음 검토 대상은 수동 공표를 왕복하는 비용과 보석·마나 보호를 분리한 비교다. 현재 결과로 새로운 기본 정책을 정하거나 운영 옵션을 바꾸지 않는다.
