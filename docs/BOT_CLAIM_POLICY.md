# 공표 전략·트롤 안전 탐색 보완 — 2026-10-06

이전 [공표 상대 검증](BOT_CLAIM_STRESS.md)의 미종료 8건을 수정하고 진명 상대에게 열세였던 자기 공표 선택을 보완했다. 기본 공표 이름은 자기 진명으로 선택한다. 공표를 강제 추가하거나 실제 정체를 공개하는 규칙을 바꾼 것은 아니다. 기존 행동 선택이 공표를 고른 경우에만 이름을 바꾸며, 상대의 공표는 여전히 약한 확률 증거다.

## 트롤 반복 공격

이름을 순환하는 것만으로는 8건 모두 미종료가 남았다. 실제로는 같은 대상의 같은 적 후보가 공표 가중치로 계속 우선했고, 실패가 누적되어도 다른 대상보다 앞섰다. 따라서 실패 사망이 없는 최상급 공격에서 대상과 이름을 함께 순환한다.

- 자기에게 온 `attack.fail.self`의 대상·이름·시점만 기록한다. 다른 봇의 수신 결과는 읽지 않는다.
- 트롤·12분 이후·마나 100 이상·최상급 공격 사용 가능 조건에서만 미시도/오래전에 실패한 대상·이름 조합을 먼저 비교한다. 기존 후보 수 제한과 공격 가능한 적 후보 조건을 유지한다.
- 이름 오류와 보디가드 실패를 구별하지 않는다. 후보를 지우거나 확정 사실을 추가하지 않는다. 실패 이력은 안전한 탐색 순서에만 반영한다.
- 일반·상급 공격과 확정 적 공격은 기존 확률 판단을 유지한다. 최상급 공격도 마나·쿨다운을 소모하므로 무비용 정보 스킬로 취급하지 않는다.

기존 공표 전략을 고정한 재현에서 7001·7011·8001·8002·8005·8006·8026·8035가 모두 종료됐고, 종료 시간은 23.48~39.77분이었다. 기존 90분 제한 미종료를 회귀 검사로 고정했다. 대상·이름 실패 이력의 개인 수신 경계와 후보 비배제도 검사한다.

## 공표 전략 선택

안전 탐색 수정은 동일하게 적용하고 공표 이름 전략 세 가지를 개발 시드 9000~9014에서 비교했다. 상대는 직전 판단 본문(로컬 446d213 / 원격 7faac91)을 고정한 정책과, 그 정책의 공표만 진명·강제 블러프·스킬 고려 블러프로 바꾼 세 가지다. 각 전략·모드·상대는 60판, 개발 합계 2,880판이다.

| 모드 | 기존 공표: 기존 / 진명 상대 점수 | 전원 진명: 기존 / 진명 상대 점수 | 일반 인물만 진명: 기존 / 진명 상대 점수 |
|---|---|---|---|
| 내전 | 50.00% / 28.33% | 71.67% / 50.00% | 56.67% / 36.67% |
| 태초 | 50.00% / 38.33% | 61.67% / 50.00% | 48.33% / 40.00% |
| 황야 | 50.00% / 31.67% | 68.33% / 50.00% | 55.00% / 30.00% |
| 트롤 | 50.00% / 31.67% | 68.33% / 50.00% | 60.00% / 36.67% |

전원 진명이 개발에서 기존 상대에게 네 모드 모두 우세하고, 네 종류 상대 중 최저 점수도 네 모드 모두 50%였다. 이를 기본값으로 선택했다. 일반 인물만 진명은 지휘관·변장 인물의 선택을 달리하면 충분하다는 가설을 검사한 비교 정책이다. 전원 진명보다 좋은 상대도 있어 모든 상대에 대한 지배 정책으로 해석하지 않는다. 예를 들어 개발 트롤 강제 블러프 상대 점수는 기존 공표 88.33%, 전원 진명 71.67%, 일반 인물 진명 93.33%였다.

진명에는 턴 자원·진실의 조각·진명 의존 스킬의 이익과 노출 비용이 함께 있다. 이 실험은 합성 상대에서 공표 선택의 전체 효과를 비교했으며 각 이익의 기여를 분리해 증명하지 않았다. 실제 상대 공표 성향을 학습해 전략을 바꾸는 기능은 아직 없다. 기존·일반 인물 진명 전략은 평가 옵션으로 남겼다. 6분 리더쉽 지연 실험은 기본 진명 전략을 덮어쓰지 않도록 기존 공표 선택을 유지한다. 태초 과거 비교 도구도 명시적으로 기존 공표 전략을 사용한다.

## 별도 시드 검증

시드 10000~10049에서 선택한 전원 진명 정책을 같은 네 상대에 평가했다. 8~12인 순환, 시드마다 같은 배정의 진영 교환·정순/역순 네 판이며 모드·상대당 200판, 총 3,200판이다. 250ms 틱, 행동 확률 0.012, 제한 90분, 기억·역할별 난수 초기값을 분리한다. 95% 구간은 시드 블록 2,000회 bootstrap이다. 고정 정책은 판단 본문을 보존하고 import/export 경로만 수정했으며 양쪽에 현재 엔진·관찰 기억을 사용한다.

| 모드 | 기존 상대 승/패·점수 (95% 구간) | 진명 상대 점수 | 강제 블러프 상대 점수 | 스킬 고려 블러프 상대 점수 |
|---|---|---|---|---|
| 내전 | 140/60 · 70.00% (65.00~75.00%) | 50.00% | 77.00% | 77.00% |
| 태초 | 130/70 · 65.00% (60.00~70.50%) | 50.00% | 82.50% | 87.50% |
| 황야 | 133/67 · 66.50% (59.50~73.00%) | 50.00% | 91.00% | 79.50% |
| 트롤 | 133/67 · 66.50% (60.50~72.50%) | 50.00% | 73.00% | 77.00% |

진명 상대 점수 50%는 양쪽의 공표 선택이 같아져 생기는 교환 대결 대칭성의 영향이 있다. 이 값 자체를 독립적인 강화 증거로 쓰지 않는다. 다른 상대와의 대결 및 기존 정책 비교를 함께 보고, 사람 상대 성능이나 최적 블러핑 정책이라고 주장하지 않는다. 여러 상대·모드를 비교했으며 검증에도 네 제한된 합성 상대만 사용했다.

개발 2,880판·검증 3,200판 모두 종료했다. 검증 양쪽의 초반 4분 공격 실패는 모든 구성 0건이었다. 현재 정책의 구성별 최대 행동 거절률은 1.087%로 황야 강제 블러프 대결에서 나왔다. 모든 행동이 승인된다고 주장하지 않는다. 새 기본 정책에서도 기존 정보 은닉·80판 완주·거절률 검사와 여덟 미종료 회귀 검사가 통과했다.
