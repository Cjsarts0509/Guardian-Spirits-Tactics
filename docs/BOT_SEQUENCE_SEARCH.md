# 확인·공표 후 관찰 기반 수순 — 기본 비활성화

`sequenceSearch: true`만 켜는 별도 실험이다. 기존 공격 탐색 옵션과 독립적으로 평가한다. 기본 운영 정책은 변경하지 않는다. 가설에서 확인을 쓴 뒤 본인에게 전달된 결과를 기억에 반영하고, 그 관찰로 새로 확정한 적에게 후속 이름 공격을 고른다. 확인 실패나 변장 가능한 성공을 가설의 실제 배정으로 보충하지 않는다.

## 범위와 정보 경계

첫 후보는 공통 확인·스캔, 기존 정책이 고른 공표, 자기 진명으로 변경하는 공표다. 기존 첫 후보를 앞에 보존하고 정보 점수 상위 확인을 추가해 최대 네 개를 비교한다. 확인 후보가 없으면 기존 정책으로 돌아간다. 공격은 첫 후보에 넣지 않는다.

두 번째 행동은 동일한 관찰 정책으로 고른다. 자기 뷰·본인 수신 이벤트·기존 본인 기억만 입력받아 확인된 적의 준비된 이름 공격을 우선하고, 없으면 공통 확인·스캔을 선택한다. 영구 보디가드가 살아 있는 지휘관에 대한 일반 공격은 제외한다. 자기 마나·스킬 차단 사유·쿨다운·잔여 횟수·대상 보호는 새 뷰와 실제 엔진으로 다시 검사한다. 공표 직후 마나 +5도 실제 공표 처리로 반영한다. 상대 공표와 정체 일치 여부에 따른 확인/변장 판정은 엔진이 수행한다.

복제한 기억에 가상 이벤트를 적용한다. 가상 로그의 seq를 기존 기억 다음으로 연결해 새로운 사건을 누락하지 않는다. 배정 샘플링은 행동 RNG와 분리하고 원본 뷰·정체 기억·행동 RNG를 보존한다. 실제 서버 상태나 상대의 실제 비공개 기억은 탐색 함수에 전달하지 않는다.

가중 공동 배정 8개, 자원 끝점 2개, 대응 유무 2개, 첫 후보 최대 4개로 최대 128수순이다. 각 배정에서 자원/대응 최악값을 취한 뒤 표본 평균을 사용한다. 끝점은 확률 분포가 아니고 8개 배정은 전체 후속 결과의 정확한 적분이 아니다. 점수는 전투 결과·방어 자원 소진·자기 마나와 비용/쿨다운으로 나눈 확인 정보량을 합친 실험값이다. 서로 다른 점수 단위의 가중치는 학습하지 않았다.

후속 시점은 최대 10초이며 다음 턴 직전까지만 진행한다. 모델의 후속 정책을 실제 봇에 예약하지는 않는다. 실제 봇은 다음 호출에서 기존 우선순위와 행동 확률로 다시 판단하므로 모델의 두 번째 행동/시점과 일치한다고 보장하지 않는다. 기존 상대 대응의 이름 공격·조건부 즉사·행동 불능기를 재사용한다. 첫 수순에서 공표했다고 상대가 정체를 확정하게 만들지는 않는다.

## 고정 코드와 평가

정책 소스는 로컬 `c5f0716`, 원격 `70db67002717c141ae5d4aa1c1d1757fbe58a419`에서 고정했다. 이후 정책 소스를 튜닝하지 않는다. 평가 원자료는 실행 설정과 SHA-256을 포함한다. 비교 상대는 동일 최신 규칙 엔진에서 실행하는 `fe4ccaa` 기본 운영 정책이며 모든 탐색 실험은 꺼져 있다.

개발 시드 40000–40009, 8–12인, 진영/순서 교환의 160판에서 79승 81패, 49.375%였다. 시드 블록 부트스트랩 95% 구간은 45.625–53.125%다. 모드별로 내전 55%, 태초 47.5%, 황야 52.5%, 트롤 42.5%이며 모두 종료했다. 이 결과만으로 개선이라고 판단하지 않는다.

고정 코드로 독립 시드 42000–42099, 8–12인, 진영/순서 교환 1,600판을 평가했다. 독립 단위는 시드 블록이며 구간은 2,000회 시드 부트스트랩이다.

| 모드 | 승 / 패 | 점수 | 시드 부트스트랩 95% 구간 |
| --- | --- | ---: | --- |
| 내전 | 217 / 183 | 54.25% | 51.25–57.5% |
| 태초 | 194 / 206 | 48.5% | 46.25–50.5% |
| 황야 | 195 / 205 | 48.75% | 45.5–52% |
| 트롤 | 196 / 204 | 49% | 46–52% |
| 전체 | 802 / 798 | 50.125% | 48.6875–51.5625% |

모든 대전이 종료했고 두 정책 모두 초반 공격 실패는 0회였다. 전체 개선을 확정할 수 없어 기본 비활성화·초안을 유지한다. 내전에서 개선 신호가 있지만 네 모드를 본 뒤 이 모드를 선택한 결과이므로, 내전 한정 활성화를 결정하려면 별도 새 시드로 다시 확인해야 한다. 모드별 구간은 다중 비교를 보정하지 않은 참고 구간이다. 이전 이름 공격/액티브 대응 평가와 시드 및 정책 범위가 다르므로 49.875% → 50.125%를 개선 폭으로 해석하지 않는다. 독립 검증 후 정책 코드를 다시 튜닝하지 않았다.

원자료는 `sequence-search-heldout-100x4.json`에 보존했다.

실험 비활성 기본 정책은 직전 코드와 비교한 80개 대전 조건(총 160회 실행)에서 대전 결과 객체가 모두 정확히 같았다. `sequence-default-compatibility.json`은 동작 호환성 확인이며 개선의 독립 성능 근거가 아니다. 재현 스크립트는 지정한 이전 커밋의 봇 소스를 일시적으로 읽고 실행 후 제거한다. 로컬 분기 이력은 `66095a8`, 같은 원격 소스는 `720888270de82f366db31ac7d685a55da94310e3`다.

## 비용과 행동 진단

`sequence-search-audit-5x4.json`: 시드 44000–44004, 모두 진명 공표하되 정체는 미공개인 합성 위치 400개. 자기 마나는 60/100이며 최대 96수순을 관찰했다(정책 상한은 128). 입력/행동 RNG 보존을 검사한다. 대전 평가와 함께 실행한 로컬 측정으로 중앙값 29.42ms, p95 65.36ms, 최대 111.61ms다. 실제 VM/라이브 서버 지연이나 실행 시간 보장은 아니다.

`sequence-search-decisions-2x4.json`: 개발 진단용 32판에서 본인 기억을 복제해 같은 위치의 기본 정책 선택을 비교했다. 146,880번 호출, 행동 809회 중 선택 차이 62회다. 같은 스킬에서 대상/이름만 바뀐 경우도 포함하며 전체 호출 중 차이 비율과 행동 중 차이 비율은 다르다. 행동을 반환한 호출의 로컬 결정 비용은 중앙값 0.34ms, p95 36.05ms, 최대 56.02ms다. 새 탐색을 쓰지 않는 행동도 포함한다. 추가 진단이 실제 게임의 기억·난수에 영향을 주지 않도록 기본 정책은 복제한 기억에서만 실행했다. 독립 성능 근거가 아니다.

## 실행과 남은 한계

```bash
# packages/rules에서
node --import tsx scripts/sequence-search.ts 100 42000
node --import tsx scripts/sequence-search-audit.ts
node --import tsx scripts/sequence-search-decisions.ts
node --import tsx scripts/sequence-default-compatibility.ts
```

현재 자기 후속 후보는 이름 공격과 공통 확인뿐이다. 인물별 진명 조건 액티브, 아군 지원·보호·광역 스킬은 후보에 없다. 진명 공표의 다음 턴 마나/조각·패시브 이득, 상대가 공표를 확인해 공격하는 추가 노출 위험, 관측 불가능한 예약 작업·획득/방어 flags 상관관계·상대의 과거 비공개 기억도 완전하게 재현하지 않는다. 자기 상태 효과가 있으면 탐색을 건너뛴다. 공표 변경의 전체 장기 가치를 계산했다고 해석하지 않는다.

확인 후 관찰에 따른 후속 공격을 구현한 것과 운영 AI가 더 강해졌다는 것은 별개다. 독립 성능과 계산 비용 근거 없이 운영 기본값을 켜거나 VM에 배포하지 않는다.

타입 검사·전체 322개 테스트(규칙 303 + 서버 19)·클라이언트/서버 빌드가 통과했다. 새 테스트는 자기 확인 전 공격 금지, 다른 사람의 비공개 확인 제외, 공표 직후 마나 증가, 공격 쿨다운, 변장 가능한 성공, 살아 있는 영구 보디가드, 높은 과거 seq 뒤 새 확인 처리, 탐색 상한/입력/RNG 보존을 검증한다.
