# 동맹 행동 가치 학습 1차

## 무엇을 학습했나

이전 거절 재시도 실험은 고정 규칙이었다. 이번에는 합성 대전의 최종 승패로 **각 봇의 첫 동맹 제안에서 즉시 실행할지, 이번 행동 기회만 기다릴지**의 가치를 추정하는 작은 표형 모델을 학습했다. 기다린 다음에는 기존 정책으로 복귀한다. 다른 스킬이나 다른 동맹 대상을 고르는 모델은 아직 아니다.

입력은 자기 마나(<60/≥60), 경과 시간(<6분/≥6분)의4개 셀이다. 상대 실제 정체·숨은 보호·엔진 효과는 입력에 없다. 각 current 진영 봇의 첫 제안만 별도 탐색 RNG로50%씩 실행/대기를 무작위 배정했다. 이 RNG는 봇이나 엔진 RNG를 소비하지 않는다. 같은 게임의 여러 봇이 각각 배정되므로 가치 추정은 다른 봇도 탐색하는 분포에서의 값이다.

보상은 최종 자기 진영 승리1/패배0/90분 제한 미종료0.5다. 동일 게임 내 보상을 공유하는 행을 독립 실험처럼 세지 않는다. 셀별 실행/대기 보상 평균에 Beta(2,2) 의사 관찰을 적용했다. 이는 보수적 평균 보정이며 독립 베르누이 표본 가정의 신뢰구간을 계산한 것은 아니다.

사전에 양쪽32개 이상 관찰 및 대기 추정값이 실행보다0.03 초과 높을 때만 대기로 전환하도록 고정했다. 0.03은 효과 확정 기준이나 통계적 유의성 기준이 아니라 후보 선택 규칙이다. 결과를 보고 기준·특징을 변경하지 않았다.

## 학습 결과

4모드×3합성 상대×32시드×진영/순서 교차4판 = **1,536판**, 첫 제안 **3,803개**. 시드는88000–88031이며 각 조건은8–12인이다.1,535판 종료, 태초/블러프/88022/정순/current진영2의1판은90분 미종료다. 이 판도 기록과0.5점 보상에 포함했다.

| 자기 관찰 조건 | 실행 관찰 수 | 대기 관찰 수 | 실행 가치 | 대기 가치 | 선택 |
|---|---:|---:|---:|---:|---|
| 6분 전·마나60 미만 | 513 | 562 | 0.7311 | 0.7147 | 실행 유지 |
| 6분 전·마나60 이상 | 1,026 | 1,028 | 0.7248 | 0.7282 | 실행 유지 |
| 6분 이후·마나60 미만 | 185 | 195 | 0.7566 | 0.7789 | 실행 유지 |
| 6분 이후·마나60 이상 | 129 | 165 | 0.7820 | 0.7160 | 실행 유지 |

가치는 탐색 분포의 학습 표본 추정치이며 독립 대전 승률이 아니다. 가장 큰 대기 이득도 약0.0223으로 사전0.03 규칙을 넘지 못했다. 네 셀 모두 실행을 유지하므로 후보가 기존 정책과 같다. 설계에 따라 개발89000–89007과 최종90000–90015는 실행하지 않고 보존했다. 독립 검증으로 개선을 확인했다는 뜻이 아니다.

**모델 학습은 완료했지만 행동 변경 후보는 얻지 못했다.** 학습 코드·모델·보상 연결 기록을 남겼으며 운영 정책은 변경하지 않았다. 마나·시간만으로는 부족하거나 한 번의 동맹 지연 효과가 작을 수 있으나, 이번 결과만으로 어느 쪽인지 결론낼 수 없다. 다음 실험에서는 공개 관찰에 기반한 동맹 필요도와 대체 행동 후보를 검토하고 설계를 새로 고정해야 한다.

## 검증과 재현

- 관찰별 원본 대전의 최종 보상, 두 입력값의 셀 매핑, 플레이어별 첫 제안 유일성3,803개, 원자료 재학습 모델 동일성, 소스 해시를 대조했다.
- 4테스트: 보상에 따른 선택 반전, 표본 부족/동점 보수 처리, 특징 경계·다른 정보 불변성, 저장/복원·순서 불변성·입력 오류.
- 전체420테스트(규칙373·서버47), 타입 검사, 서버·웹 빌드가 통과했다.
- 자료: `docs/evaluations/ally-value/`의 설계/모델/학습 요약/압축 관찰·대전/검증 결과. 대전의 실제 배정은 평가 기록에만 있고 모델은 명시된 셀·처치·보상만 입력으로 받는다.

저장소 루트에서:

```bash
cd packages/rules
node --import tsx scripts/ally-value-experiment.ts
node --import tsx scripts/verify-ally-value.ts
```

학습 실험은 오프라인 스크립트에만 있으며 서비스 봇의 옵션이나 기본값에 연결하지 않았다. 게임 간 사용자 성향 학습, 일반 행동 가치 모델, 실시간 강화학습은 구현하지 않았다.
