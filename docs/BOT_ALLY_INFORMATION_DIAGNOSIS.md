# 동맹 대체 정보 수집의 후속 행동·비용 진단

## 범위와 재현

2차 동맹 가치 후보는 독립 대전에서520→518승으로 개선을 확인하지 못했다. 이번 작업은 당시 최종 시드93000–93015를 **진단에만 재사용**했다. 모델·정책·보상·선택 기준은 변경하지 않았고 새 성능 검증으로 세지 않는다.

기존1,536판을 재실행해 각 판의 MatchResult(승패·종료 시간·행동 통계·역할별 생존자)가 저장 결과와 정확히 일치함을 확인했다. 과거의 전체 행동 시퀀스는 저장돼 있지 않아 시퀀스 동일성을 증명한 것은 아니다. 후보가 첫 동맹 대신 정보 수집을 고른246장면을 기록했다.

정보 직전 지식과 직후의 **복제 봇 기억**에서 얻은 지식을 비교했다. 종료 후 전체 공개되는 정체는 정보 성과로 세지 않는다. 실제 정책에는 진단 결과를 돌려주지 않는다. 원래 동맹의 즉시 결과와 마나 비교 역시 복제 엔진에서만 실행했다. 이는 같은 순간의 국소 비교이며 원래 동맹을 택한 장기 미래를 재실행한 것은 아니다.

후속 대상 겹침188회는 **활용 가능성이 있는 흔적**이다. 그 정보가 없었으면 행동이 달라졌을 것이라는 인과 검증은 아니다. 같은 대상에 추가 정보가 도착했을 수도 있다. 이름 공격3회도 새로 알게 된 이름과의 일치를 센 좁은 지표이며 모든 공격·간접 활용을 포괄하지 않는다. 원자료에는 각 후속 행동의 시각·허용 여부·대상 겹침·이름 일치를 보존했다.

## 즉시 마나·동맹 기회 비용

정보 수집은 총4,305마나(평균17.5)를 소비했다. 동일 시점 복제 상태의 원래 동맹은244회 허용·2회 거절, 총2,440마나(평균9.92)를 소비했다. 차이는 총1,865, 개입당 평균 **+7.58마나**다.

7개입에서는 정보 실행 직후 마나 부족으로 막힌 스킬이, 원래 동맹 실행 직후 복제 뷰에서는 사용 가능했다. 이는 바로 그 시점의 사용 가능성 차이이며 이후 실제로 그 스킬을 쓰려 했다는 증거는 아니다.

원래 대상과 나중에 동맹을 맺은99개입만 보면 지연 중앙값 **118.5초**,90백분위308.25초다. 나머지147개입은 판 종료까지 같은 동맹이 성립하지 않았다. 이147개입을 지연0 또는 무한 지연으로 계산하지 않았다. 사망·다른 동맹 선택·판 종료 등이 섞이므로147회를 모두 ‘동맹을 맺을 수 있었는데 놓친 손해’라고 해석하지 않는다. 원래 즉시 동맹부터 거절되는2개입도 전체 분모에 포함돼 있다.

원자료의 사망 관련 시각은 **행동 결과 콜백에서 처음 관측한 시각**이다. 예약 효과에 의한 사망의 정확한 엔진 시각이나 모든 종료 직전 사망을 보장하지 않아 본 보고서의 비용 근거로 사용하지 않는다.

## 승패 변화와 판단

기존/후보의768대응쌍 중764쌍은 승패가 같고,1쌍은 후보가 이기도록,3쌍은 후보가 지도록 바뀌었다.4쌍의 개입 장면은 verification.json에 따로 보존했다. 한 판에서 여러 봇이 개입하며 이후 궤적도 변하므로 어떤 스캔이나 동맹 지연이 그 승패를 일으켰는지는 분리하지 못했다.

확인한 것은 **정보 증가와 동시에 추가 마나 지출·원래 동맹 지연이 발생했다**는 점이다. 정보 증가만으로 장기 행동 가치를 설명하기는 부족하다. 다음 연구는 새 시드에서 한 번의 선택만 바꾼 대응 분기를 만들어, 후속 행동과 자원·생존·승패를 함께 기록하는 설계가 적절하다. 보상 가중치는 이번 최종 자료에 맞춰 조정하지 않는다. 현재 후보는 계속 미채택이다.

## 검증·재현

전체424테스트·타입 검사·서버/웹 빌드 통과. 이번 변경은 진단 스크립트·기록·문서만 추가한다. 기록의 개입 유일성, 지식 변화와 후속 대상 겹침, 주요 요약 재집계, 모델/과거 대전 입력 해시, 소스 해시를 별도 검증 스크립트로 대조했다.

자료는 `docs/evaluations/ally-context-diagnosis/`의 records.json.gz, summary.json, verification.json에 있다. 저장소 루트에서:

```bash
cd packages/rules
node --import tsx scripts/ally-context-diagnosis.ts
node --import tsx scripts/verify-ally-context-diagnosis.ts
```
