# 상대 공표 성향을 반영하는 적응형 공표 실험

`claimStrategy: 'adaptive'`를 선택하면 확정된 적의 최신 수동 공표를 관찰해 사령관의 공표를 바꾼다. 기본값은 기존 `truthful`을 유지한다. 합성 상대 비교에서 일부 모드는 개선되지만 태초 모드의 일관된 개선은 확인되지 않았다.

## 판단 범위

- 봇에게 전달된 PlayerView와 관찰 이벤트, 확정 정체만 사용한다. 실제 숨겨진 배정은 정책에 전달하지 않는다.
- 플레이어별 최신 수동 공표 하나만 집계한다. 반복 공표로 증거 수를 늘리지 않는다. 정체 미확정, 아군, 자동 공표는 성향 집계에서 제외한다.
- 확정된 적 중 거짓 공표가 2명 이상이며 집계의 2/3 이상일 때 블러핑 성향으로 분류한다. 이 문턱은 보수적인 휴리스틱이며 학습된 확률이 아니다.
- 진명 의존 액티브·패시브 스킬, 유지 중인 진명 효과, 이미 공개된 자기 정체를 보호한다. 기존 스킬·쿨다운 판단은 그대로 사용한다.
- 보호 조건이 없는 사령관만 자기 진영 비사령관 이름으로 공표한다. 이미 유효한 가명을 쓰면 유지한다. 증거 또는 보호 조건이 바뀌면 자신의 수동 가명을 진명으로 되돌린다.
- 블러핑 증거가 없는 상황에서는 초기 공표와 자동 공표 복구 시점, 행동 및 난수 소비를 기존 정책과 동일하게 유지한다.

사망한 적의 확정 정체와 최신 공표도 집계에 남는다. 따라서 살아 있는 상대만의 성향과 다를 수 있다. 게임 간 사용자 성향 학습이나 사람 상대 승률을 의미하지 않는다.

## 검증 방법

기준 정책은 main `c505d4b`와 동일한 소스의 로컬 `f0e58d1`을 `scripts/baselines/pre-adaptive.ts`에 고정했다. 개발 시드는 11000–11014, 별도 검증 시드는 12000–12029다. 각 모드·상대·시드에 진영과 순서를 교환한 4판을 실행했다. 인원은 8–12명, 틱 250ms, 활동도 0.012, 제한 시간 90분이다.

상대는 고정 기준, 진명 강제, 거짓 공표 강제, 진명 필요 스킬을 보호하는 거짓 공표의 네 종류다. 거짓 공표 상대는 합성 정책이며 실제 사람의 플레이 분포를 대표하지 않는다. 표의 수치는 현재 정책의 승리 점수다. 미종료는 없었다.

별도 검증 시드의 강제 블러핑 상대에서 내전은 +7.5%p, 트롤은 +19.2%p, 태초는 −5.8%p였다. 같은 시드끼리 차이를 계산한 2,000회 부트스트랩(random.Random(1), 2.5–97.5 백분위 근사)의 95% 구간은 각각 [+1.7, +13.3], [+13.3, +25.0], [−12.5, +0.8]%p다. 모드별 다중 비교와 작은 시드 수를 고려해 전체 기본값으로 승격하지 않는다.

총 5,760판이 모두 종료했고 초반 공격 실패는 0건이다. 스킬 실행 거절은 기존과 같이 일부 존재하므로 거절 0건을 주장하지 않는다. 원본 결과에는 승패, 진영·순서별 집계, 거절 사유, 시드별 점수, 공표 전환 횟수 및 소스 해시가 포함되어 있다.

## 재현

`packages/rules`에서 다음 명령을 실행한다.

```sh
node --import tsx scripts/adaptive-claims.ts 15 11000 all > ../../docs/evaluations/adaptive-development.json
node --import tsx scripts/adaptive-claims.ts 30 12000 all > ../../docs/evaluations/adaptive-holdout.json
```

타입 검사, 전체 테스트 277개(규칙 258개·서버 19개), 릴리즈 빌드가 통과했다. 신규 7개 테스트는 미확정·아군 증거 제외, 반복 중복 방지, 자동 공표 제외, 진명 보호, 숨겨진 배정 독립성, 증거 없는 경우의 기존 행동·난수 일치를 검증한다.

이번 변경은 실험 옵션과 비교 도구를 담은 초안이다. 기본 정책이나 현재 VM 릴리즈를 변경하지 않는다.
