# 인간 상대 검증을 위한 기록과 사실 재현

현재 실제 사람 대전 원자료를 확보하지 못했다. 자동 봇 경기·자동 UI 입력·클라이언트 입력 기록만으로 실제 인간 상대 승률이 검증됐다고 표시하지 않는다. 이 문서는 준비된 기록·검증 경로와 남은 증거를 구분한다. 운영 배포나 Supabase 변경은 수행하지 않았다.

새 로컬 서버 기록은 기존 RECORDS_DIR 설정이 있을 때만 저장된다. 추가된 replay에는 초기 전체 상태·시작 시 봇 ID·서버/방장 호스팅 출처가 있고 행동별 controller는 human-input, bot, away-bot이다. away-bot은 사람 자리를 자동 대행한 행동이다. human-input은 입력 경로일 뿐 사람 참여 인증이 아니다. 비공개 정보가 들어 있는 원본 기록은 기존 로컬 기록처럼 취급하며 공유 보고서는 닉네임·채팅·숨은 배정을 내보내지 않는다.

저장소 루트에서 실제 확보한 파일을 읽기 전용으로 검사한다.

```
node --import ./apps/server/node_modules/tsx/dist/loader.mjs apps/server/scripts/audit-human-records.ts /path/to/match.json
```

파일, json.gz 또는 기록 디렉터리를 입력할 수 있다. 도구는 초기 상태에서 같은 시각/순서로 실제 행동을 재생하고 허용/거절·오류·최종 전체 상태·승자·시간을 대조한다. 초기 상태가 없는 과거 파일, 변조된 순서/결과, 다른 엔진 버전 또는 기록하지 않은 이탈 등의 외부 변경 때문에 정확히 재현되지 않는 파일은 제외한다. 확인되지 않은 사실을 추정해서 채우지 않는다. 검증된 입력 재현도 과거 상대가 새 봇의 행동에 적응해 대응한 경기는 아니므로 새 봇의 인간 상대 승률을 추정하지 않는다.

실제 검증에 남은 자료는 실제 참가 확인이 있는 사람-봇 대전의 완료 기록이다. 같은 불변 후보/비교 정책·모드별 사전 경기 계획으로 새 대전을 수집해야 하며, 위장 발신자/충돌 보고/확정 아군 협력/확정 적 동맹 파기/대화와 전투 분리도 함께 관측한다. 참가자가 없는 현재 단계에서는 인간 상대 검증을 완료할 수 없다. 현재 보존한 human-audit는 단위 테스트 합성 한 판(봇 행동59/사람 입력0)의 재현 도구 검사이며 실제 인간 대전 자료가 아니다.
