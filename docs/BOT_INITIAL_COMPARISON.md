# 최초 AI 대비 현재 수준

현재 운영 행동 정책 `58ff60d`를 초기 정책과 같은 최신 규칙 엔진에서 직접 대결했다.
초기 엔진의 버그나 예전 서버까지 복원한 비교가 아니라 행동 정책 비교다.

| 기준 | 범위 | 판 수 | 현재 승/패 | 점수 | 시드 95% 구간 |
| --- | --- | ---: | --- | ---: | --- |
| 최초 스마트 봇 `e9063f9` | 내전 | 400 | 338 / 62 | 84.50% | 80.75–88.25% |
| 초기 4모드 정책 `b9b802b` | 네 모드 | 1,600 | 1,190 / 410 | 74.375% | 72.1875–76.25% |

최초 봇은 내전 시기의 구현이므로 다른 모드의 수준을 대표하지 않는다.
초기 4모드 비교 정책은 고정 의사결정 본문과 현재 공통 확인 기억 경계를 사용한다.
최초 봇 본문은 해당 Git 커밋에서 그대로 가져오고 import 경로만 현재 위치에 맞췄다.
각 단계에서의 직전 버전 대비 승률을 더하거나 곱해 누적 향상률로 계산하지 않았다.

| 모드 | 초기 4모드 정책 대비 현재 점수 |
| --- | ---: |
| 내전 | 77.50% |
| 태초 | 84.75% |
| 황야 | 74.00% |
| 트롤 | 61.25% |

새 시드 28000–28099, 8–12인, 진영/순서 교환 4판, 활동 확률 0.012,
250ms 틱, 90분 제한이다. 두 비교는 같은 시드를 공유하므로 독립 표본을
2,000개로 해석하지 않는다. 모두 종료했다. 네 모드 점수는 모드별 점수를
동일 가중 평균한 시드 블록을 2,000회 재표본화한다.
결과와 소스 해시는 `docs/evaluations/{first-ai,early-four-mode}-comparison.json`에 보관한다.

사람 상대 기록이 없으므로 입문자·중급자·숙련자 수준이나 인간 상대 승률은
판정하지 않는다. 현재는 정체 확률과 규칙/스킬 조건을 활용하는 전술 봇이다.
사람의 채팅·협상·전략적 블러프에 대응하는 능력과 실제 인간 대결 성능은 별도 검증해야 한다.
