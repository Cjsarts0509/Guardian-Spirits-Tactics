# 확인 후 공격과 확인 후보 비교

## 동작

기존 정책은 30분 뒤 확인 정보가 전혀 없는 상대에게도 즉사기를 시도할 수 있었다.
이 초안은 공표나 경과 시간만으로 공격 증거를 만들지 않는다. 확정 정체,
확인 결과의 배제/후보/지휘관 제약, 다른 정체의 확인으로 발생한 배정 소거를
얻은 뒤에만 미확정 상대에 대한 공격 추측을 허용한다. 확인 정보가 있다고
공격 성공을 보장하지는 않으며, 기존 후보 수·진영 확률·보디가드·스킬 조건도 통과해야 한다.

정보 획득을 목적으로 한 불태우기–저주 연계, 확인 스킬, 공표와 자기 성장,
지원은 유지한다. 이미 정체를 아는 적의 공격 우선순위도 유지한다.

`confirmationSearch: true`는 초기 자원 비교 실험 옵션이며 기본값으로 승격하지 않았다.
후속 단계에서 검증한 황야 한정 공격 활용도 탐색을 기본값으로 적용했다.
현재 정책과 검증은 `BOT_CONFIRMATION_COMBAT.md`를 참고한다.
사용 가능한 확인/스캔의 대상과 이름 후보를 열거하고 성공·실패 결과의
정보량을 `정보량 / (1 + 마나/50 + 쿨다운 초/60)`으로 비교한다.
보석과 혼돈의 주술은 기존 우선순위를 유지한다. 한 단계의 관찰 결과 비교이며,
전체 배정 샘플링이나 후속 전투 시뮬레이션을 구현한 것은 아니다.
자원 가중치는 실험값으로 학습되지 않았다.

## 정보와 스킬 경계

입력은 자신의 `PlayerView`, 정당한 확인 기억과 배정 확률뿐이다.
패시브, 사용 불가 사유, 진명 조건, 마나, 남은 횟수, 자신의 현재 쿨다운과
공개된 대상 무적 상태를 검사한다. 기존 공격 예약 마나에 따라 제거된 스킬은
비교 후보에 들어가지 않는다. 상대의 실제 숨겨진 정체·마나·쿨다운은 읽지 않는다.
상대 스킬에 관한 관찰과 시간 범위는 기존 전투 정책에서 유지하며, 이 선택기는
상대의 미래 행동이나 숨은 방어 자원을 시뮬레이션하지 않는다.

## 전체 대결 검증

고정 운영 기준은 `b95a326`의 의사결정 본문이다. 4개 모드, 8–12인,
같은 배정에서 두 진영과 두 순서를 교환한 시드당 4판을 사용한다.
250ms 틱, 활동 확률 0.012, 최대 90분을 사용한다.
개발 시드 21000–21019와 별도 검증 시드 22000–22099를 구분한다.
신뢰구간은 시드 블록을 2,000회 재표본화한 95% 구간이다.

| 검증 정책 | 판 수 | 전체 점수 | 95% 구간 | 미종료 |
| --- | ---: | ---: | --- | ---: |
| 확인 증거 제한, 기존 확인 선택 | 1,600 | 50.00% | 50.00–50.00% | 0 |
| 확인 증거 제한 + 자원 비교 선택 | 1,600 | 49.5625% | 48.50–50.625% | 0 |

| 모드 | 기존 확인 선택 | 자원 비교 선택 |
| --- | ---: | ---: |
| 내전 | 50.00% | 50.25% |
| 태초 | 50.00% | 49.75% |
| 황야 | 50.00% | 49.00% |
| 트롤 | 50.00% | 49.25% |

개발 표본은 정책당 320판이다. 총 3,840판이며 검증 두 정책은 같은 시드를
공유하므로 독립 시드 200개나 독립 실험 3,840개로 해석하지 않는다.
확인 증거 제한은 이 표본에서 대결 점수가 동일했다. 이 정책 차이는 정보 없는
장기전에서 발생하므로, 전용 회귀 테스트를 함께 사용한다. 일반 리그의 50:50만으로
모든 상태에서 행동이 동일하다고 주장하지 않는다.
자원 비교 선택은 전체 성능 개선이 입증되지 않아 기본 정책으로 승격하지 않는다.
이 결과는 인간 상대 승률이나 실제 서버 처리 시간에 대한 측정이 아니다.

## 재현

`packages/rules`에서 실행한다.

```bash
node --import tsx scripts/confirmation-selection.ts 20 21000
node --import tsx scripts/confirmation-selection.ts 20 21000 search
node --import tsx scripts/confirmation-selection.ts 100 22000
node --import tsx scripts/confirmation-selection.ts 100 22000 search
```

결과는 `docs/evaluations/confirmation-{gate,search}-{development,holdout}.json`에
보관한다. 각 결과는 관련 실행 소스의 SHA-256 해시를 포함한다.
