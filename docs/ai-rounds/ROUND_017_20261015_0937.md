## 단일 가설·고정 범위

엔진 공표는 같은 이름 재공표를 허용하며 마나+5·40초 재사용 대기가 있다. 기본 정책은 같은 이름 공표를 피한다. 다음은 **원래 주 행동이null인 실제 활동 기회에서만, 이미 수동 공표해 진명인 자기 이름을 다시 공표**하면 협력/정보 지출로 부족한 마나를 일부 회복할 수 있는지 검증한다. 미래의 공표 전환이40초간 막히는 비용과 노출 유지도 포함해 실제 전체 승패로 평가한다. 마나+5만으로 개선을 주장하지 않는다.

옵션 `idleClaimMana:true`, 기본OFF·모드/인물별 선택 없음·016과 조합 없음. 조건은 다음과 같다.

- 기존 주 행동 선택이null이며 기존 활동 추첨을 통과해 자기 `communicationAt`이 현재 시각과 같다. 비활동/종료/죽음은 행동을 새로 만들지 않는다.
- 현재 자기 뷰가 진명이고, 자기 기억의 실제 수동 공표 이름도 그 진명과 같다. 자동 공표만 한 경우·현재 가명·변장 인물·새 정체 노출은 제외한다.
- 공표 스킬이 실제 사용 가능하고 진명 이름이 합법이며 자기 마나 여유가+5 전체를 받을 만큼 있다.150상한의 가상+5를 실제 수령과 혼동하지 않는다.
- 공격·동맹·정보 등 다른 주 행동이 선택됐으면 그대로 실행한다. 추가 RNG/대화 기회를 만들지 않고 기존 비공개 보고는 별도 경로로 계속한다.

정책 입력은 자기 뷰·자기 수신 이벤트·자기 기억뿐이다. 수집기에서 실제 재공표가 나올 때는 **해당 봇의 원래 자기 기억/RNG 복제만** 사용해 옵션OFF의 제안이null이고 판단 후 자기 기억/RNG가 같은지 대조한다. 그 검증 결과는 외부 출력에만 쓰며 실제 선택을 고르거나 다른 봇에게 전달하지 않는다. 관측ON/OFF의 실제 경기 동일성도 회귀 검증한다. 보고를 직접facts로 승격하지 않고 확정 아군 동맹·적 동맹 파기·위장 경계·실제 비공개 대화를 유지한다.
