# AI 개선 005회차 — 지휘관의 보석 성장과 위장

## 후보와 개발 조건

`claimCommanderGrowth:'shining'|'all'` 옵션을 추가했다. 필수 진명 스킬과 공개 자기 정체를 먼저 처리하고, 변장 인물은 위장을 유지한다. 지정된 지휘관은 보석 단계3 미만이면 진명을 선택하고 완성 후 기존 위장 정책으로 돌아간다. 단계2 보석의 기존 사용은 막지 않으므로 소비 후 단계0이 되면 다시 진명을 유지한다. **완성 시점이나 고정된 짧은 노출 기간을 보장하는 정책은 아니다.** 기본 none을 유지한다.

새 **119000–119004**, 8–12인, 4모드 × 3상대 × 순서/진영 4교환 × 5정책 = **1,200실행**. 샤이닝 한정/모든 지휘관 후보는 002회차의 성장 단계3·동맹 예산 옵션을 함께 켜고, 미채택 요청자 우선 확인은 끈다.

| 개발 점수 | main 기준 AI | 기존 후보 | 002 두 수정 | 샤이닝 성장 | 모든 지휘관 성장 |
|---|---:|---:|---:|---:|---:|
| 내전 | 73.33% | 61.67% | 61.67% | 61.67% | 68.33% |
| 태초 | 75.00% | 73.33% | 73.33% | 73.33% | 78.33% |
| 황야 | 71.67% | 68.33% | 65.00% | 71.67% | 66.67% |
| 트롤 | 66.67% | 65.00% | 63.33% | 63.33% | 70.00% |
| 전체 | 71.67% | 67.08% | 65.83% | 67.50% | 70.83% |

모든 지휘관 성장은 기존 후보보다 +3.75%p지만 main 대비 -0.83%p이고 황야/내전은 각각 -5.00%p다. 개발 자료로 승격을 주장하지 않는다. 샤이닝 한정의 다른 3모드 경기/진단은 combined와 정확히 같아 적용 범위를 확인했다.

황야의 가명 턴 보석 성장 누락은 combined 320 → 모든 지휘관 성장0, 트롤565→175로 줄었다. 트롤 변장 인물의 위장 예외는 남는다. 종료 시 샤이닝 생존은17/30→20/30, 카이는20/30→17/30, 치스29/30→27/30, 데카19/30→18/30이었다. 양 진영의 노출/승패가 함께 바뀌는 작은 개발 표본이며 자원 회복을 승리 원인으로 단정하지 않는다.

모든1,200판 종료, 후보 초반 공격 실패·잘못된 아군 동맹·거짓 보고0. **469개 테스트(규칙401·서버68)**·타입 검사·서버/화면/Worker 빌드 통과. 실제 샤이닝 공표→턴 성장→완성 후 위장과 공개 정체 유지, 카이 한정 제외/전체 적용, 변장 유지, 숨은 배정 불변을 검증했다.

## 독립 평가 후보 고정

개발 후보 중 전체 점수가 가장 높고 안전 위반이 없는 **commanderGrowth** 하나를 다음 독립 평가에 고정한다. 이번 회차 커밋의 전체 규칙/정책 SHA256과 아래 옵션을 사용하고 평가를 보는 동안 바꾸지 않는다. 003/004 요청자 우선 옵션은 켜지 않는다. 모드별 최고 정책을 골라 혼합하지 않는다.

```json
{"claimGemGoal":3,"teamworkBudget":true,"claimCommanderGrowth":"all"}
```

사전 승격 기준: 새 독립 평가에서 main 기준 AI 대비 전체 차이의 시드 부트스트랩95% 하한>0, 각 모드 점수 차이≥-2%p, 미종료/초반 공격 실패/잘못된 동맹/거짓 보고0. 개발 점수 또는 기존 실패 최종112000 결과는 승격 표본에 합치지 않는다. 평가 후 같은116000 자료로 튜닝/모드 선택을 하지 않는다. main 병합/운영 배포는 여전히 하지 않는다.

| 시드 | 상태 |
|---|---|
| 119000–119004 | 005회차 개발 완료 |
| 116000–116015 | 006회차 고정 후보 독립 평가 시작 예약 |
| 120000–120004 | 이후 별도 개발 예약·미사용 |
