# AI 개선 015회차 — 첫 가명 공표 한 번의 진명 개입 대응 진단

**예약·진행 중. 실행/학습 완료 아님.** 014 완료 기록을 커밋한 직후 시작한다. 보고 재확인 순서/대기 수정이 기준 AI 격차를 해소하지 못해, 공표의 자원 이득과 노출을 한 번의 실제 개입으로 분리한다. 이전 미채택 옵션은 모두 OFF이고 기본 PR 정책을 사용한다.

## 데이터 보기 전 고정할 설계

공개 ID `p1`만 대상으로 한다. 자기 정책이 처음 제안한 **비변장 인물의 가명 공표** 한 번을 진명으로 바꾸는 판과, 원래 행동을 유지하는 대응 판을 비교한다. `p1`이 비교 진영에 없거나 해당 제안이 없으면 개입하지 않으며 두 판의 결과/행동 통계가 정확히 같아야 한다. 다른 봇의 기억·숨은 배정으로 개입 대상/시점을 고르지 않는다. 변장 스킬 보유 인물은 제외하고 자기 뷰에서 진명 공표가 사용 가능할 때만 개입한다. 다른 판단·대화는 원래 정책대로 실행한다.

개입 전 전체 상태 해시는 **외부 검증 출력에만** 쓰며 선택 입력에 넣지 않는다. 자기 뷰/자기 기억 해시와 원래 제안도 대응 쌍에서 같아야 한다. 이후 정책이 공표를 되돌릴 수 있으므로 진명 유지 시간을 보장하지 않는다. 경기 승패와 선택 인물의 생존/진명 시간·실제 자기 턴 수신 보너스/보석 성장·행동 비용을 따로 기록한다. 원시 보너스는 마나 상한 전 값이다.

이 자료는 새 **학습/개발 진단**이며 독립 승격 결과가 아니다. 후보가 생기면 별도129000 개발, 그 기준을 통과해 불변 고정한 뒤에만 독립121000을 사용한다. 과거112000/116000 최종은 재튜닝/모드 선택에 재사용하지 않는다.

## 사전 고정한 작은 학습 규칙

결과를 보기 전에 수집기와 학습기를 커밋한다. 선택 특징은 자기 뷰의3개 이진 값, **지휘관 여부 × 보석 미완성(gem<3) × 다음 턴43초 이내**의8셀이다. 역할별 이름·상대 실제 정체·숨은 보호·다른 봇 기억은 특징에 넣지 않는다. 시간/마나 등 추가 관측값은 진단용이며 새 특징/문턱을 사후 추가하지 않는다.

셀마다 실제 개입24쌍 이상·독립 시드8개 이상이 있어야 한다. 각 시드 안의 대응 승리 점수 차이를 평균한 뒤 고정 RNG `0x475354`로10,000번 시드 블록 부트스트랩한다. **차이95%하한>0**일 때만 해당 셀에서 진명 대체를 선택하고 나머지는 기존 행동을 유지한다. 자료 부족/차이 불확실이면 원래 정책 유지다. 모든 셀이 기존 유지라면 행동 변경 후보를 얻지 못한 결과로 남기고 개발/독립 평가를 억지로 실행하지 않는다. 이때 더 느슨한 문턱으로 같은 표본을 재튜닝하지 않는다.

후보를 얻어도 한 번 개입의 보상과 모든 봇에 적용했을 때의 상호작용은 다르다. 후속 개발 검증을 생략하지 않으며 사람 상대 실력/운영 모델 개선으로 표시하지 않는다.
