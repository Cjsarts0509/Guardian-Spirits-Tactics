# AI 개선 037회차 — 태초 지휘관 보호 기회의 관측 전용 재생

036 완료 자료의 태초 12인·기억 수정 정책 32경기를 전부 재생한다. 사전 대상은 147004부터 5 간격으로 147079까지 16시드 × 순서 2다. 승패를 보고 일부 경기만 고르지 않는다. 연구 누적은 44,736으로 유지하며 새 시드 148000·독립 121000은 사용하지 않는다.

가설: 컨슘/쿠마린이 지휘관 정체를 알고 보호 스킬의 마나·쿨다운·사용 횟수·행동 및 대상 조건을 충족한 실제 선택 기회에서 다른 행동을 택하는 사례가 있는가. 실제 이행/기회, 지연 행동, 적격 기회가 있는 경기의 최종 보호 여부를 구분한다. 공격의 전술 가치가 있을 수 있으므로 모든 지연을 오류로 분류하지 않는다. 비활성 폴링은 분모에서 제외한다.

정책 선택 직후 자기 뷰·자기 수신 이벤트·자기 기억의 복사본으로만 분모를 판단한다. 관측 전후 실제 기억·엔진 상태의 불변을 확인하고, 원자료의 경기 전체 결과·역할·스킬 집계와 일치해야 한다. 숨은 배정/외부 결과를 정책에 전달하지 않는다. 정책 소스는 7a05fcf8be4017ac51f2bdebbd8437153dd7ec98로 고정, 새 정책/스킬 변경은 없다. 도구는 selfplay-guard-audit.ts이며 실행 전 계획을 기록한다.


## 완료 — 동맹이 보호보다 먼저 선택되는 실제 사례 확인

32경기 전체에서 원본의 경기 결과·시간·접수/거절·역할·모든 스킬 집계가 관측 재생과 정확히 일치했다. 관측에 사용한 지식 계산은 복사한 자기 기억에서만 수행하며 실제 엔진·기억이 변경되지 않음을 각 관측에서 확인했다. 원자료 소스 해시와 관측기 코드/옵션 해시를 압축 결과에 보존했다. 메타데이터 보강 뒤 재실행한 동일 32경기도 중복 자료로 제외한다. 새 연구 실행 0, 누적 44,736 유지.

|역할|보호 가능한 실제 선택 기회|그때 보호 선택|동맹을 먼저 선택|적격 기회가 있던 경기|이후 보호한 경기|전체 보호 성공/시도|오대상|
|---|---:|---:|---:|---:|---:|---:|---:|
|컨슘|56|23|33|24|23|23/23|0|
|쿠마린|16|8|8|8|8|20/20|0|

선택 기회는 한 경기에서 반복될 수 있다. 준비되지 않은 스킬 선택 시점(컨슘 3/쿠마린 7), 지휘관 정체 미확정 시점(98/238), 사용 완료 이후와 비활성 폴링을 적격 분모에 포함하지 않았다. 쿠마린의 전체 성공 20건 중 12건은 공표를 참고한 미확정 대상 보호 시도였으므로 확정 대상 기회 분모 16에 섞지 않았다. 이 12건이 우연히 정확했다고 미확정 공표를 사실로 승격하지 않는다.

컨슘의 적격 기회 후 보호 성공까지 지연은 2.25~161.5초(23경기)였다. 쿠마린은 1~27.75초(8경기)였다. 관측한 모든 적격 보류 행동은 동맹이었으며 공격과의 우선순위 충돌은 이 표본에서 없었다. 동맹에도 자원 이득이 있으므로 지연 전체를 무조건 오류라고 분류하거나 보호 우선화의 승률 효과를 추정하지 않는다.

구체적 사례: seed 147004 / 역순 / 12인. 컨슘은 369.5초에 노예 본능으로 엘타스 p8을 확인했다. 374.5초에 마나 70·보호 비용 50·사용 횟수 1의 적격 기회가 있었지만 p8과 동맹을 맺었다. 384.25초 지상 연합 승리로 종료됐고 주인 보호는 쓰지 않았다. 현재 코드에서 확정 아군 동맹 분기가 조건부 아군 보호보다 앞에 있어 이 선택과 일치한다. 이 경기를 더 빨리 보호했다면 이겼을지는 아직 검증하지 않았다.

다음 가설은 `knownCommanderGuardBeforeAlly` 단일 기본OFF 후보다. 먼저 위 사례를 기본 연구안에서도 재현한 뒤, **새 동맹을 선택하려는 순간에만** 자기 지식으로 확정한 생존 지휘관의 사용 가능한 횟수제 보호를 우선한다. 기존 확정 적 공격·기타 행동 우선순위와 스킬 수치를 함께 바꾸지 않는다. 실제 엔진 회귀·정보 은닉·관측 불변·타입·빌드 뒤 소스를 고정하고, 사용 전 새 148000 시드 범위/실행수를 기록해 행동 이행과 고정 상대 성능을 따로 비교한다. 112000/116000 및 최종 표본으로 재튜닝하지 않는다.
