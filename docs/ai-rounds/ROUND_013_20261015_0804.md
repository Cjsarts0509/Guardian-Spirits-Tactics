## 가설·관측 설계

012에서 강제 보고 검증을 일반 정보 수집 순서로 돌리면 확인 마나가 줄었지만 main 격차가 남았다. 같은 실제 상태에서 보고 우선 정책이 선택한 검증과 일반 순서의 제안을 자기 기억 복제로 비교해 **어떤 행동을 대신 고르는지**를 측정한다. 새 후보/가중치/문턱을 만들지 않으며 이 새 표본의 점수로012 미채택 결정을 뒤집지 않는다.

관측기는 활성 판단에서 자기 뷰/자기 수신 이벤트와 **복제한 자기 기억·RNG**만 사용한다. 우선검증 제안이 실제 신뢰 보고 대상의 스캔/보석 검증인 순간에 우선/일반 제안·보고 이름/나이·명목 마나·자기 믿음의 기대 정보량을 기록한다. 복제 제안은 엔진에 실행하지 않는다. 실제 선택된 행동만 기존 엔진에서 실행하고 허용/거절·자기 수신 이벤트의 즉시 정체 변화도 따로 기록한다. 종료 후 전원 공개는 정보 성과에서 제외한다. 추후 전투/승패의 직접 인과나 복제 대안의 실제 허용을 입증하는 자료로 해석하지 않는다.

실제 게임/기억/RNG·대화/행동을 바꾸지 않는 회귀가 필요하다. 보고 신뢰/가중치8과 직접facts 구분, 미확인/위장/충돌 보고 경계, 확정 동맹/적 동맹 파기, 대화와 전투 분리를 유지한다. 다른 봇의 기억/숨은 배정은 관측 입력에도 읽지 않는다. 원자료의 별도 경기 정답/안전 집계는 정책에 전달하지 않는다.
