# AI 개선 003회차 — 미확인 동맹 요청자 검증

## 구현

`verifyIncomingAllies:true` 개발 옵션을 추가했다. A가 B에게 동맹을 걸어도 B가 A를 모를 수 있으므로, 받은 동맹 중 미확인 대상의 유효한 확인/스캔과 보석을 일반 정보 탐색보다 우선한다. 확정 공격·진명 필수 스킬·기존 확정 아군 동맹·이미 신뢰한 보고의 검증은 앞선 우선순위를 유지한다. 동맹·공표·보고를 정체 facts로 취급하지 않으며 변장 확인 성공의 oneOf 후보도 그대로 남긴다.

실제 귓속말을 받은 B가 A를 모르는 동안 C 보고를 보류하고, 보석으로 A를 직접 확인한 뒤 C 보고를 참고하면서 A에게 답례 동맹을 거는 회귀를 추가했다. 변장한 소엔이 카이에게 동맹/거짓 보고를 보내고 아군 확인에 성공해도 신뢰 발신자나 아군으로 확정되지 않는 회귀도 추가했다. 숨은 배정을 바꿔도 새 옵션의 자기 행동이 같음을 검증했다.

## 새 개발 비교

**117000–117004**, 8–12인, 4모드 × 3상대 × 순서/진영 4교환 × 5정책 = **1,200실행**. main 기준 AI(baseline), 기존 후보(control), 002회차 두 수정(combined), 요청자 검증(approach), 모든 수정(coordinated)을 비교했다. 002회차와 다른 시드이므로 점수의 절대값을 회차 간 개선으로 해석하지 않는다.

| 개발 점수 | main 기준 AI | 기존 후보 | 002 두 수정 | 요청자 검증 | 모두 결합 |
|---|---:|---:|---:|---:|---:|
| 내전 | 63.33% | 75.00% | 73.33% | 70.00% | 70.00% |
| 태초 | 71.67% | 71.67% | 73.33% | 73.33% | 73.33% |
| 황야 | 68.33% | 75.00% | 75.00% | 61.67% | 61.67% |
| 트롤 | 63.33% | 68.33% | 66.67% | 55.00% | 58.33% |
| 전체 | 66.67% | 72.50% | 72.08% | 65.00% | 65.83% |

요청자 검증의 보고 횟수는 기존 후보 3,380 → approach 3,784로 늘었지만 전체 점수는 -7.50%p였다. coordinated도 기존 후보보다 -6.67%p, 황야 -13.33%p·트롤 -10.00%p다. 더 많은 보고가 더 좋은 행동을 보장하지 않는다. 무조건 요청자 확인을 앞세우는 후보는 **미채택**하며 옵션 기본은 false다.

002회차 combined는 이번 시드에서 기존 후보보다 -0.42%p였다. 개발 소표본의 부호가 변하므로 앞선 +1.67%p를 승률 개선이라고 표시하지 않는다. 독립 116000–116015는 아직 사용하지 않았고 운영을 바꾸지 않는다.
