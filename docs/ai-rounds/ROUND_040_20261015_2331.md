039완료 뒤 연속 진행한다. 새 연구 실행0, 누적46,208 유지. 039의 전320경기(양 정책160씩)를 승패/개입 유무로 선별하지 않고 고정 정책으로 결정론 재생한다. 원본 경기 전체와 모든 실제 행동의 시각·주체·선택·접수·전후 마나·영수증 종류가 일치해야 한다.

가설: 조기 보호가 실제 추가 공격 흡수로 이어지는가, 아니면 보호 대상이 공격받지 않거나 보호자 사망/경기 종료 때문에 준비된 횟수가 남는가? 보호자별 시전·보디가드 흡수 사건·잔여 횟수·사망 시점과 같은 대상/시전자 대응 시점을 기술한다. 최종 승패로 경기/조건을 고르거나 후보를 재튜닝하지 않는다.

정책은039의 규칙 소스(038과 동일), 기본/보호옵션2개 그대로다. 외부 피격/정체/보호자 상태는 실제 선택 후 평가 관측에서만 읽고 정책·기억에 전달하지 않는다. 관측ON/OFF 동일성과 원본 전체 행동 일치를 확인한 후 자료로 삼는다. 전투 피격 집계의 차이를 해당 스킬의 독립적인 인과 승률 기여로 표현하지 않는다. 스킬수치·기본 옵션·배포·Supabase·main 변경0. 독립121000·150000은 미사용이다.
