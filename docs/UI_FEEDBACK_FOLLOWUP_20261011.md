# 추가 UI 수정사항 (5장)

- 로그인: 세 줄 엠블럼만 크게 표시. 두 줄 워드마크 제거. 제작 문구는 로그인창 바로 아래 가운데 정렬.
- 로그인·내 정보 탭: 내용 전환 애니메이션, 모션 감소 설정 준수.
- 효과음 후보 선택 제거. 사용자 음원 파일명은 AUDIO_FILES.md.
- 로그인 계정의 BGM·효과음 볼륨 및 음소거는 Supabase Auth user_metadata.gst_sound에 저장. 계정 연결 시 복원, 설정 변경은 토큰으로 저장. 권한 판단에 사용하지 않으며 비밀 키와 스키마 변경이 필요하지 않음. 저장 실패는 설정 화면에서 표시, 브라우저 저장 유지.
- 역할 설명: 각 스킬 왼쪽에 아이콘 표시.
- 전투 준비: 방장 버튼은 전투 준비. 바로 게임 화면의 battleWaiting 상태로 이동. 각 플레이어가 역할 확인 후 화면에 입장하면 game.enter를 보냄. 서버가 실제 참가자 전원 입장을 확인한 후 battleCountdown 5초, 이후 running. AI는 입장 완료. 입장 전 회색 카드/중앙 표식, 입장 완료 색상 카드/전투대기 표식. 전투 전 채팅 가능. 게임 시간·AI·행동 진행은 서버에서 정지.
- 카드 효과: 카드 내부 중앙 아이콘 확대, 효과 문구 잘림 보정.
- 복기: 카드 하단 전체 비율 유지, 최신 로그 자동 스크롤(이전 기록 조회 시 자동 이동하지 않음). 채팅 버튼 제거, 큰 채팅창 기본 표시와 이동·불투명도 유지.

운영 기준은 main 4e02fda. 이 추가 수정분은 별도 PR로 검증 후 반영한다.
