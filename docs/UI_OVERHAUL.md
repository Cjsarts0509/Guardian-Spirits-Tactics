# 카드 UI 개편 구현 현황

2026-10-08 · 작업 브랜치 `feat/card-ui-overhaul` · 운영 배포 전

## 적용한 흐름

| 구간 | 구현 |
|---|---|
| 로그인 | 승인된 로그인 키비주얼·로고, 실제 입력 컨트롤, 데스크톱 73:27 구성 |
| 방 목록 | 방제 검색, 모드 필터, 방제·모드·방장·사람/AI 인원, 참가·생성·메인 이동 |
| 방 생성·슬롯 | 모드 카드, 방제, 인원, 턴 시간, 호스트의 슬롯별 AI/사람 변경·강퇴·인원 조정 |
| 준비 | 사람 전원 준비/취소 토글, AI 자동 준비, 슬롯 충족 확인, 실제 5초 카운트다운 |
| 역할 배분 | 호스트가 1회 배분, 카드 뒷면 셔플→자기 역할 공개, 준비 화면 자유 채팅 |
| 전투 시작 | 호스트 버튼→실제 5초, 그 전까지 엔진 시간·스킬 사용 정지 |
| 전투 UI | 모드별 새 배경, 승인된 반신상/진영 프레임, 미확인 상대는 Unknown, 내 정보 표시 |
| 연출 | 승인된 내 스킬 사용, 수신 가능한 공격·확인·사망 이벤트의 카드/효과/문구 |
| 종료·복기 | 진영별 승패 이미지, 전체 정체·로그, 시간 이동·배속·로그 페이지 |
| 내 정보 | 인증 계정의 모드별 경기/승/패/승률, 게스트 안내 |
| 저장 | 서버 계정 연결, 동일 경기 ID로 재시도, 디스크 outbox 복구 |

신규 UI의 방은 서버 권한 방식으로 실행한다. 클라이언트에 전체 비공개 배정을 전송하지 않는다. 구형 진단 도구의 `capacity` 없는 생성 요청은 기존 시작/호스팅 경로를 유지한다. 신규 화면은 항상 `capacity`를 보낸다.

## 아트

`apps/client/public/ui`에 런타임 파일을 둔다. 승인된 Library 자산과 사용자 제공 시트를 사용했다. 캐릭터 원화는 재생성하지 않았으며 프레임의 마젠타 키만 브라우저 캔버스에서 제거한다.

- 기존: 로그인/브랜딩/패널, 4개 모드 카드, 공통·모드별 카드 뒷면, 반신상, P1~P7 및 Unknown 프레임.
- 새 이미지: 전장 배경 4종, 투명 효과 5종(strike/shield/reveal/curse/shatter), 진영별 승패 배너 14종, 기능군 스킬 아이콘 20종.
- 139개 스킬 키가 20개 기능군으로 연결된다. 139개 개별 일러스트가 아니며 이름·설명·비용은 각 스킬 정의를 유지한다.
- 44개 엔진 캐릭터 키의 초상화 매핑을 확인했다. 이름 변형은 `art.tsx`의 별칭으로 처리한다.
- `reference-7.png`의 네 영역은 목록 배경·회의실·사람/AI 슬롯 배경에 사용한다. `reference-8.png`는 공통 프레임 디자인 참고 원본이며 실제 패널 테두리는 승인 로그인 패널 자산을 사용한다.
- 생성 결과 목록: `docs/art/ui-generated-results.json`, `docs/art/ui-generated-icons.json`. 원본 경로는 생성 당시 출처이며 배포 의존성은 아니다.
- 원본 WC3 맵/블리자드 아트를 새 자산으로 복사하거나 생성 입력으로 사용하지 않았다.

## 저장 및 복기 범위

`RECORDS_DIR`를 영속 디스크 경로로 설정해야 재시작 후 미전송 기록을 복원한다. outbox 파일은 0600 권한으로 저장하며 30초마다 재시도한다. `SUPABASE_URL`과 서버 전용 키가 있어야 DB 전송 및 계정 전적 조회가 동작한다. 기본키 기준 upsert로 부분 실패 재시도 시 중복을 방지한다.

복기는 현재 종료된 방에서 제공한다. 상태는 초 단위 최대 약 1,200개로 저장하고 긴 경기에서는 간격을 넓힌다. 전체 이벤트 로그는 별도로 보존한다. 방이 정리된 뒤 과거 경기를 다시 불러오는 UI와 전체 랭킹 화면은 아직 없다. 모드별 계정 전적 조회는 구현되어 있다.

## 검증과 남은 확인

- 규칙 테스트 381개 및 정보 은닉 테스트 통과.
- 서버 테스트 59개: 기존 47개 + 준비/배분/복기 10개 + 저장 재시도/전적 페이지 2개.
- 전체 패키지 타입 검사, 서버/클라이언트 빌드 확인.
- 실제 운영 Supabase 연결은 이 환경에서 확인하지 못했다. 다른 프로젝트 DB는 변경하지 않았다.
- Playwright 브라우저 설치 파일 다운로드 실패, 클라우드 브라우저의 로컬 미리보기 연결 무응답으로 실제 화면 스크린샷 검증은 미완료다. 화면 배치·크로마 키 가장자리·작은 화면 가독성은 배포 전에 브라우저에서 확인해야 한다.
- 운영 배포 및 main 병합은 하지 않았다. AI 학습은 종료 상태를 유지한다.
