# AI 오류 점검

수정 전 로컬 `f1c64e9` / 원격 `56f9ca5e21bfbbc1f4f194a7757bb5d4ee4e5869`의 후속 스킬 선택과 가설 상태 복원을 점검했다. 실제 규칙 엔진은 변경하지 않았다.

## 재현한 오류와 수정

1. `roleFollowup`의 확인된 아군 목록에 본인이 포함됐다. 토크라의 마나가 100이고 확인된 다른 아군이 없으면 자기 대상 `support`를 반환했다. 엔진은 모든 대상 지정 스킬의 자기 대상 사용을 거절한다. 후보 대상에서 본인을 제외했다. 다른 아군을 확인하면 실제로 허용되는 지원을 선택하는 회귀 테스트를 추가했다.
2. `rolloutState`가 복원한 모든 효과에 `announced: true`를 설정했다. 본인이 비공개 룬 프로텍션을 받은 상태를 복원하면 가설 속 상대 뷰에도 그 보호가 보였다. 현재 탐색 입구는 본인에게 효과가 있으면 탐색을 생략하므로 이 재현은 상태 복원 함수의 결함이며 운영 서버의 정보 유출을 의미하지 않는다. 공개 상태 목록과 종류·시전자 스킬·남은 시간을 대조해 공개 여부를 복원하고, 중복 항목도 하나씩 대응시킨다. 본인에게 보이는 비공개 효과와 공개 효과를 모두 검증했다.

두 회귀 테스트가 수정 전에 실패하고 수정 후 통과했다. 기본 정책의 대상 선택은 이미 본인을 제외하며 탐색 옵션 기본값도 변경하지 않았다.
