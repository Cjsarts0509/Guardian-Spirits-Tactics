# AI 협력·정보 공유·상황별 공표 후보 — 2026-10-15

## 작업과 결정

사용자 요청으로 이전 미채택 학습 라운드와 별개인 새 행동 정책 개발을 시작했다. 학습 모델이나 사람 상대 승률 개선을 구현했다고 표시하지 않는다. 현재 후보는 기능 구현과 비교 평가가 끝났지만 **운영 승격은 보류**한다. 독립 비교에서 전체 점수가 개선되지 않았다.

PR #10(호스트 계산)과 #11(과거 AI 연구)은 커밋이 main에 포함되어 있어 닫았다. #4의 공표 자원 실험은 미채택 연구로 닫고 브랜치·자료를 보존했다. UI PR #13/#14/#15는 이미 main에 병합돼 있다. 실제 VM 설치 버전은 이번 작업에서 확인하지 않았다.

## 구현

- 확정 아군과 동맹을 정보 수집보다 우선한다. 나에게 동맹을 건 확정 아군과 지휘관을 먼저 선택한다. 확정 공격과 진행 중인 버닝·저주 연계는 유지하며 공격 마나 예약을 침범하지 않는다.
- 적으로 확인된 대상에게 내가 건 동맹은 먼저 파기한다. 상대가 나에게 건 단방향 동맹을 강제로 끊는 기능은 원래 규칙에 없다.
- 공표 이름·동맹 요청·변장 확인의 oneOf 후보만으로는 동맹하지 않는다. 기존 확률 동맹은 teamwork:false 비교 옵션에서만 유지한다.
- 알고 있는 정체를 `확인 정보: [자리] 인물명` 형식으로 확정 아군에게 실제 비공개 귓속말로 전달한다. 최대 50자, 개인당 최소 12초 간격, 수신자/대상/정체당 한 번이다. 적 지휘관·적·아군 순으로 공유한다.
- 발신자는 서버가 찍은 data.from, 수신자는 이벤트의 vis로 판정한다. 다른 봇의 메모리·숨은 배정을 공유 저장소에서 읽지 않는다. 확인된 아군에게 내가 동맹을 건 경우만 전송한다. 서로를 아직 확인하지 못했다면 검증이 먼저 필요하다.
- A가 B를 확인하고, B가 C를 확인해 실제 보고를 보낸 경우 A는 C에 대한 보고를 기억한다. **보고와 직접 확인은 별개**다. 검증된 아군의 일관된 보고만 확률 가중치 8로 반영하며, 보고 이름에 대한 스캔/보석 확인을 우선한다. 적·미확인 발신자, 직접 증거와 모순되는 보고, 아군끼리 상충하는 보고는 신뢰하지 않는다. 동일 보고 반복으로 가중치를 부풀리지 않는다. 직접 확인 전 재전파하지 않아 순환 소문을 막는다.
- 공격/확인 등 주 행동과 대화는 같은 판단에서 별도로 실행한다. 대화 때문에 AI가 다음 활동 추첨까지 전투 행동을 미루지 않는다. 서버와 방장 Worker에 동일하게 연결했으며 기존 채팅 엔진·기록·복기 경로를 사용한다.
- 기본 후보 공표는 strategic이다. 지휘관·변장은 위장을 선택하며, 진명 스킬·공개된 자기 정체는 진명을 유지한다. 일반 인물은 보석 완성·충분한 공격/지원 예산·확정 적 존재 시 위장한다. 지휘관도 턴 직전 마나 부족이면 자원을 회복한다. 같은 이름의 불필요한 반복 공표를 피한다. truthful/current/adaptive 옵션과 고정 이전 정책을 비교용으로 보존했다.

## 독립 최종 비교

고정된 후보: 개발 후 112000–112015의 새 16시드, 4모드 × 진명/블러프/진명 스킬을 보존한 블러프 3상대 × 자리/진영 교환 4판 × 기존/후보 2버전 = **1,536실행**. 8–12인, 250ms, 활동 확률 0.012, 90분 제한. 학습·개발과 최종 시드는 분리했다. 아래 최종 결과를 보고 후보를 다시 튜닝하지 않았다.

| 태초 | 72.40% | 71.35% | −1.04%p |

시드 블록을 독립 단위로 한 전체 차이 95% 부트스트랩 구간은 −5.34~+0.26%p. 인간 대전 지표가 아니며 모드별 유의성을 주장하지 않는다. 모든 판 종료·초반 공격 실패 0, 후보의 잘못된 아군 동맹 0, 거짓 정보 보고 0. 행동 거절은 기존 117→후보 21. 후보 공표의 약 33.0%는 위장이지만 승률 개선 근거가 되지는 않았다.

최종 이후 113000–113003의 **별도 개발용 분리 진단 768실행**에서 협력만/공표만/둘 다/기존을 비교했다. 각 셀 16판의 소표본이며 최종 평가를 대체하거나 모드를 골라 승격하는 근거로 쓰지 않는다. 새로운 정책 튜닝을 하지 않았다. 후속은 황야·트롤의 동맹 마나 지출과 공표 진명 보너스 손실을 행동별로 분리해 진단하는 것이다.

초기에는 보고가 주 행동을 대체해 기회를 잃었고 공표 전환도 지나쳤다. 실패한 초기 개발과 첫 최종 111000–111015 결과도 압축 원자료로 보존했다. 이 결과들을 최종 승률에 합치지 않는다.

## 검증·재현

확정 동맹/적 동맹 파기/변장 접근/실제 비공개 보고/확률 갱신/보고 검증 우선/미확인 발신자/직접 증거 충돌/외부 비공개 상태 불변/주 행동+대화/비활동 대화 차단/공표 자원 보호 테스트를 추가했다. 과거 공표·재시도 실험 비교는 명시적으로 teamwork:false를 사용한다. 정보 은닉과 호스트 복원 테스트를 포함한 전체 검사를 수행한다.

원자료는 `docs/evaluations/cooperation-*.json.gz`, 고정 요약은 `cooperation-summary.json`이다. 각 정책의 SHA256, 시드, 상대, 좌석/진영 교환, 경기 결과와 행동 집계를 포함한다.

```bash
corepack pnpm --filter @gst/rules exec node --import tsx scripts/cooperative-evaluation.ts 16 112000 ../../docs/evaluations/cooperation-holdout.json
python tools/verify-cooperation.py docs/evaluations/cooperation-holdout.json
# 보존된 압축 결과 재집계·정책/기준 코드 해시 확인
python tools/verify-cooperation.py docs/evaluations/cooperation-holdout.json.gz
```

기존 botKnowledge/직접 facts와 별개인 보고 기억을 추가했다. 맵과 집합은 기존 호스트 기억 직렬화/변경분 경로로 보존한다. 스키마·Supabase·배포 설정을 바꾸지 않는다.
