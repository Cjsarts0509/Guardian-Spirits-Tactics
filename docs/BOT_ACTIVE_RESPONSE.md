# 가설 상대 액티브 스킬 대응 — 기본 비활성화

`attackSearch`, `attackResponse`, `attackResponseSkills` 세 옵션을 모두 켤 때만 사용한다. 기존 이름 공격 대응은 별도 경로로 유지한다. 실제 상대의 상태/기억을 읽지 않고 가설 상대의 자기 뷰와 수신 가능한 이벤트로 확인한 적만 대상으로 고른다.

| 범위 | 대응 스킬 |
| --- | --- |
| 조건/자원에 따른 즉사 | 마스터의 권능(라엘·킬데르), 학살, 백스탭, 피닉스의 불꽃 |
| 직접 공격 | 울프스 슬러쉬 및 기존 이름 공격 |
| 마나 감소/행동 불능 | 블랙 스펠, 교란, 나이트메어, 플레임 샤클 |

고정된 우선순위의 스트레스 정책이다. 모든 인물의 모든 액티브 스킬이나 실제 인간/AI의 전략을 예측하는 모델은 아니다. 즉사기·행동 불능기를 먼저 검토하고 이름 공격을 뒤에 둔다. 한 상대는 한 대응 시점에 최대 한 번 행동한다. 대상별 precheck, 마나, 쿨다운, 횟수, 진명 공표 조건, 행동 불능/보호 판정은 실제 규칙 엔진이 검사한다. 이미 행동 불능인 대상에게 같은 효과를 낭비하지 않는다. 피닉스의 불꽃은 확인된 컨슘만 대상으로 삼는다.

가설 획득 관계도 일부 제한했다. 에오릴이 살아 있는 배정에서 킬데르의 흡수 보상은 제거한다. 라엘에게 시련을 부여한 후 60초가 지나야 시험을 얻을 수 있으므로 게임 시작 60초 전 시험/마스터 권능은 가정하지 않는다. 자기 관측 스킬은 그대로 유지한다. 모든 조건부 스킬 이력과 도달 가능성을 증명한 것은 아니다.

## 개발과 호환성

첫 액티브 대응 버전 `201e83bbc5a1080dd9993b00c8a326bf27a44cd1`은 개발 시드 36000–36019의 320판에서 운영 정책 대비 50%였다. 획득 관계를 제한한 버전 `8c62522a7b51d8dbf3bf4ce5dbe446afe7e0a815`도 같은 개발 시드에서 50%였다. 둘 모두 종료했고 이 같은 시드 비교는 독립 표본이 아니다.

별도 이름 공격 대응 옵션만 켠 31000–31019의 320판을 재실행해 이전 단계와 모드별 승패·행동 통계·전체 시드 점수가 정확히 같음을 확인했다. `response-attack-compatibility.json`은 호환성 확인이며 새로운 독립 성능 표본이 아니다. 초기 액티브 결과와 보정 결과는 각각 `response-active-development.json`, `response-active-constrained-development.json`에 보존했다.

## 고정 코드 독립 검증

코드를 고정한 뒤 새로운 시드 38000–38099, 8–12인, 진영/순서 교환으로 1,600판을 평가했다. 동일 최신 규칙 엔진의 기본 운영 정책 `fe4ccaa`와 비교한다.

| 모드 | 승/패 | 점수 | 시드 부트스트랩 95% 구간 |
| --- | --- | ---: | --- |
| 내전 | 201 / 199 | 50.25% | 49–51.75% |
| 태초 | 200 / 200 | 50% | 50–50% |
| 황야 | 197 / 203 | 49.25% | 48–50.5% |
| 트롤 | 200 / 200 | 50% | 49–51% |
| 전체 | 798 / 802 | 49.875% | 49.3125–50.4375% |

모두 종료했다. 독립 단위는 시드 블록이다. 이전 이름 공격 대응 검증과 시드가 다르므로 49.8125%에서 49.875%로 개선됐다고 해석하지 않는다. 운영 정책보다 개선됐다는 근거가 없어 초안·기본 비활성화를 유지한다. 검증 후 이 액티브 정책을 다시 튜닝하지 않았다.

```bash
# packages/rules에서
node --import tsx scripts/response-active.ts 100 38000
node --import tsx scripts/response-active-audit.ts
```

원자료·실행 설정·소스 SHA-256은 `evaluations/response-active-heldout.json`, `response-active-audit.json`에 보존했다. 2,400개 공개 정체 합성 위치에서 입력/RNG 보존과 최대 128회 수순 평가를 확인했다. 로컬 중앙값 15.15ms, p95 28.14ms, 최대 37.09ms다. 대전/빌드가 겹친 참고 수치이며 실제 VM이나 라이브 서버 지연이 아니다.

확인·공표 후 관찰에 따른 자기 후속 수순 실험은 [BOT_SEQUENCE_SEARCH.md](BOT_SEQUENCE_SEARCH.md)에 이어서 기록한다. 이 문서는 액티브 상대 대응 단계의 고정 평가다.

## 검증과 남은 작업

타입 검사, 전체 315개 테스트, 클라이언트·서버 빌드 통과. 새 테스트는 미확인 대상 공격 금지, 이름 공격 없는 상대의 행동 불능기, 쿨다운/사용 횟수, 조건부 즉사 대상 제한, 불가능한 보상/지연 획득 가설 제거를 확인한다.

확인→공격 연계, 공표 변경 수순, 아군 지원·보호·광역 액티브 스킬, 상대의 과거 비공개 확인 기억, 미관측 예약 효과, 조건부 방어 flags와 전체 획득 상관관계가 남아 있다. 현재 자기 행동 후보는 확인된 적에 대한 이름 공격과 대기뿐이다. 상대 액티브 대응 범위를 확장한 것이 자기 모든 액티브 수순 탐색을 구현했다는 뜻은 아니다. 개선과 계산 비용을 검증하기 전 운영 병합이나 기본 활성화를 하지 않는다.
