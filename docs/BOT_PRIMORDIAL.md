# 태초 공표·성장 연계·정체 노출 분석 — 2026-10-06

이 문서는 당시 슬러쉬 정책 평가다. 이후 모든 모드의 공표 전략을 보완한 결과는 [공표 정책 보완](BOT_CLAIM_POLICY.md)에 기록한다. 태초 비교 도구는 `claimStrategy: current`를 명시해 당시 공표 선택을 유지한다.

케인이 아직 공개되지 않았을 때 울프스 슬러쉬를 마무리에 아끼도록 변경했다. 이 스킬은 보디가드를 무시하지만 케인의 정체를 공개한다. 여러 목숨을 가진 엘타스에게 초반에 사용하면 죽이지 못한 채 케인만 노출되는 경로가 반복됐다. 공개 관찰상 잔여 목숨이 하나인 알려진 적에게는 사용하고, 케인이 이미 공개됐다면 기존 사용 판단을 유지한다. 숨겨진 케인이 장기전에서 미확인 대상에게 슬러쉬를 추측 사용하는 경로도 제외한다. 일반 이름 공격은 계속 사용할 수 있다.

마무리 판단은 공개 목숨 관찰·역할 기본 목숨으로 계산한다. 슬러쉬가 무시하는 보디가드 횟수는 더하지 않는다. 상대의 비공개 상태나 실제 배정은 판단에 사용하지 않는다. 규칙 엔진을 변경하지 않았다.

## 정책 분리 실험

같은 역할 배정과 역할별 봇 난수로 정순·역순을 실행했다. 각 정책·시드 묶음은 100시드, 서로 다른 200판이다. 8~12인 순환, 250ms 틱, 행동 확률 0.012, 제한 90분이며 개발 시드는 4000~4099, 검증 시드는 5000~5099다. 양 진영에 동일 정책을 적용하므로 아래 비율은 지상연합의 자기 대전 결과이며 정책 간 대결 승률이 아니다. 구간은 시드별 두 판을 묶어 2,000회 bootstrap한다. 미종료는 0.5점으로 따로 기록한다.

사망 중앙값은 사망한 경우만 계산하므로 생존자를 포함한 생존 시간 추정치가 아니다. 역할별 생존·공표·시전 경로를 함께 보면 초반 정체 노출 비용을 줄이는 설명과 일치한다. 다만 자기 대전 진영 비율이 50%에 가까워졌다는 것을 목표나 개선의 증거로 삼지 않는다.

평가 관측자가 실제 역할을 읽어 집계한 자료는 합성 판의 결과 분석에만 사용한다. 봇 입력·기억에 반환하지 않는다. 시전 집계의 `accepted`는 엔진이 행동을 접수한 횟수이며 스킬 효과가 성공했다는 뜻은 아니다. 개발 원자료는 선택 이전 소스 해시, 검증 원자료는 선택 이후 소스 해시를 보관하며 모든 비교 정책의 옵션을 명시했다.

## 기존 정책과 교환 대결

선택 후 별도 시드 6000~6099에서 원격 c29c3ad(로컬 b1dc606)의 판단 본문을 고정한 `pre-primordial`와 대결했다. 기존 리그와 같은 진영 교환·정순/역순 네 판 구성으로 모드당 400판, 총 1,600판이다. 고정 정책은 import/export 경로만 바꿨으며 양쪽은 현재 관찰 기억과 엔진을 사용한다.
