# 오류 수정 후 AI 독립 평가

정책 소스는 로컬 `1b83ade` / 원격 `b1925aba87889aaf38f65a9fb470cb223c878c17`에 고정했다. 평가 결과를 본 뒤 가중치나 후보를 바꾸지 않았다. 기본 설정은 그대로 두고 `sequenceSearch`, `sequenceSkills`, `sequenceExtended`를 켠 실험 정책을 평가했다.

## 비교 설계

- 수정 전 AI: 로컬 `f1c64e9` / 원격 `56f9ca5e21bfbbc1f4f194a7757bb5d4ee4e5869` 고정 체크아웃. 같은 세 탐색 옵션을 켰다. 새 시드 60000–60049, 800판.
- 운영 설정 AI: 현재 소스에서 실험 옵션 기본값 false, `confirmationSearch` 기본값 `combat-lidellut`. 새 시드 61000–61049, 별도 800판. 실제 운영 VM의 대전 기록을 수집한 평가가 아니다.
- 각 모드 50시드 × 진영/좌석 교환 4판 = 200판. 8–12인 조건을 순환한다. 250ms 틱, 활동 확률 0.012, 최대 90분의 기존 평가 조건을 유지했다.
- 독립 단위는 시드다. 각 시드의 진영/좌석 교환과 4개 모드 점수를 묶어 전체 95% 부트스트랩 구간을 계산했다. 모드별 구간은 다중 비교 미보정이다. 비교 집합의 시드가 달라 두 승률을 빼서 오류 수정의 효과로 해석하지 않는다.

운영 소스와의 호환성도 별도로 확인했다. 원격 main `fe4ccaa7ec872d134a9bcfddebf70758ff279ee3`와 로컬 `13af50b`의 트리는 모두 `8c24d554e4342b9387b52aac82bce4d1ae7f38e3`다. 규칙 엔진·모드·공통 스킬은 현재 소스와 같고, 확인 후보 정렬과 기본 옵션의 동작을 고정 운영 소스와 32개 조건에서 비교했다. 결과 객체 및 2,218회 시도 행동의 시각·시전자·내용·허용 결과·수신 이벤트가 모두 일치했다(64회 실행). 이는 검증한 조건에서의 일치이며 모든 가능한 상태의 동등성 증명은 아니다.

현재 실험 정책 전체가 운영 설정 AI에 우세한 결과이며 전체 구간 하한이 50%를 넘었다. 이는 지정한 합성 상대·활동률·시드의 결과다. 수정 전 대비 구간에는 50%가 포함되어 이번 두 오류 수정의 승률 개선이나 퇴행을 확인하지 못했다. 그 결과가 두 정책의 동등성이나 비열등성을 증명하는 것도 아니다. 특정 모드만 사후 선택해 운영 활성화하지 않았다. 인간 상대 수준은 평가하지 않았다.

## 판단 비용

대전·검사 프로세스가 모두 끝난 뒤 로컬 Node `v24.19.0`에서 새 시드 62000–62004의 동일 합성 800위치를 측정했다. 각 조건 200위치, 마나 100, 전원 진명 공표, 역할별 초기 기억 조건이다. 현재/수정 전의 전체 판단 호출 순서를 번갈아 실행했으며 별도 워밍업 표본을 제외하지 않았다. 상태·자기 뷰 불변식도 확인했다.
