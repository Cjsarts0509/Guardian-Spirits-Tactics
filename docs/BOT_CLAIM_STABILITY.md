# 가명 유지와 반복 공표 비교

`claimStrategy: 'adaptive-stable'`는 자원 보호 비교 정책의 후속 실험이다. 가명 진입 시 보석·공격 마나 조건을 확인하지만, 진입 후 보석이 완성된 상태에서 마나가 낮아졌다는 이유만으로 진명에 복귀하지 않는다. 기본 truthful 및 기존 adaptive/adaptive-resources의 정책은 유지한다.

## 규칙 설명 정정

공표(`skills/common.ts`)는 소비 마나 **0**, 성공 시 마나 **+5**, 쿨다운 **40초**다. 앞선 문서와 PR의 ‘반복 공표 마나 비용’ 설명은 잘못되었다. 공표할 때 마나를 잃는 규칙은 없다. 가명으로 턴을 넘길 때 포기하는 것은 진명 턴 보너스 **+10**과 보석 성장이다. 현재 브랜치의 이전 보고서와 PR 설명을 정정했으며, 이전 평가의 원본 JSON은 당시 소스 해시와 함께 보존했다.

반복 공표는 추가 마나를 제공하면서 공표 쿨다운·노출 양상·행동 선택 시점을 바꾼다. 따라서 공표 횟수 감소 자체를 성능 개선으로 판단하지 않는다.

## 비교 정책

- 가명 진입 전: 기존 자원 보호 조건을 그대로 확인한다.
- 유지 중: 자기 최신 수동 공표가 현재 유효한 가명과 같고 보석이 완성된 경우, 현재 마나 부족만으로 진명 복귀를 요청하지 않는다.
- 자동 가명은 유지 근거로 인정하지 않는다.
- 진명 필수 스킬·진명 유지 효과·자기 정체 공개·상대 성향 증거 소멸·보석 훼손은 여전히 진명 복귀 사유다. 실제 행동 실행은 공표 사용 가능 여부와 쿨다운을 따른다.
- 자기 뷰와 관찰 기억만 사용한다. 상대의 실제 마나·숨겨진 정체를 읽지 않는다.

## 평가

기존 시드 태초 13000–13019(20시드), 새 시드 네 모드 15000–15014(15시드). 세 정책(진명 고정·자원 보호·가명 유지), 네 합성 상대, 시드당 진영·순서를 교환한 4판으로 총 **3,840판**이다. 미종료는 0.5점으로 집계하므로 표는 승리 점수다. 상대 행동은 c505d4b 고정 기준을 사용하며 강제 블러핑 정책은 사람의 플레이 분포가 아니다.

진명 복귀 횟수는 자동 가명에서 진명으로 돌아오는 공표도 포함한다. 공표 횟수는 판 길이에 따라서도 달라지므로 그 수치만으로 특정 원인이나 왕복 쌍의 수를 확정하지 않는다. 가명 진입 횟수·진명/가명 전체 공표·시드별 점수는 원본 결과에 별도로 기록했다. 고정 기준·진명 강제 상대에서는 모든 정책·모드의 점수가 50%, 가명 진입은 0회다.

새 시드의 강제 블러핑 상대에서 태초 점수는 자원 보호 81.7%→가명 유지 70.0%, 트롤은 83.3%→90.0%였다. 동일 시드 차이의 2,000회 부트스트랩(random.Random(1), 2.5–97.5 백분위 근사) 95% 구간은 각각 [−20.0, −3.3]%p, [+1.7, +13.3]%p다. 15시드와 다중 비교의 한계가 있으며, 이 실험은 마나 증가·턴 보너스·노출·공표가 차지하는 행동 기회를 개별적으로 분리하지 않았다.

**판단:** 가명 유지로 반복 공표가 줄지만 전 모드 성능 개선은 아니다. 태초 하락이 새 시드에서도 반복되어 기본 정책 승격은 보류한다. 트롤의 개선만으로 일반 플레이에서 우세하다고 주장하지 않는다. 다음 후보 선택은 공표 횟수 자체가 아니라 턴 보너스·공표 마나 이익·쿨다운을 함께 다루어야 한다.

미종료 1판은 기존 시드 진명 고정 대 강제 블러핑 상대(seed 13008, 11인, 역순, 현재 진영 2)다. 다른 3,839판은 종료했으며 모든 정책의 초반 공격 실패는 0건이다.

## 재현과 검증

`packages/rules`에서 실행한다.

```sh
node --import tsx scripts/claim-stability.ts 20 13000 all primordial > ../../docs/evaluations/claim-stability-diagnostic.json
node --import tsx scripts/claim-stability.ts 15 15000 all all > ../../docs/evaluations/claim-stability-holdout.json
```

원본 결과의 소스 해시를 실제 실행 파일과 대조했다. 전체 테스트 **281개**(규칙 262개·서버 19개), 타입 검사 및 서버·클라이언트 빌드가 통과했다. 신규 테스트 2개는 가명 진입 전·후의 마나 하락, 자동 가명 제외, 보석 훼손, 진명 효과, 성향 증거 소멸을 검증한다. 현재 PR #4의 자원 보호 평가 5,280판과 이번 3,840판은 별도 실험이며, 합계 9,120판이다.
