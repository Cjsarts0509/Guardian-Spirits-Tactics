## 구현 결과

- 로그인·대기실·방 준비·역할 배분·전투·복기를 뷰포트 기준으로 재배치. 페이지 스크롤을 제거하고 목록·로그·상세 정보 영역 내부에서만 스크롤한다.
- 앞면 프레임 8종을 v3로 새로 생성, 기존 앞면·뒷면 원본은 보존. 빈 슬롯 카드 추가. 이름/클래스 밴드의 보석 제거.
- 방 목록/대기실 채팅 1:1, 준비 화면 모드 카드/4×3 슬롯/채팅, 배분·브리핑 오른쪽 채팅. 팝업 바깥 클릭으로 닫히지 않음.
- 방장이 배분 전 익명 모드를 선택하면 이름·ID를 대체하고 자리 순서를 섞는다. 상대 전적 조회는 서버에서 차단. 자신의 역할은 확인 버튼 전까지 배경 화면에 노출하지 않음.
- 자신의 스킬은 아이콘 격자에 배치, 대상 카드 우클릭 메뉴 추가. 설명과 메뉴를 뷰포트 안으로 보정. 하단 스킬 카드 제거.
- 공개 행동은 이름을 굵은 색상 텍스트로 표시. 비살해 효과는 대상 카드 안으로 한정하고 살해는 찢어진 두 카드 조각으로 연출.
- 종료 연출 5초 후 결과·복기. 카드 축소, 행동 로그 확대, 이동/불투명도 조절이 가능한 채팅창 제공.
- 닉네임 영문20/한글8, 화면 채팅50줄/발언50글자, 5초10회 발언 시20초 제한. 준비·본게임·복기 대화를 전체 기록에 보존하며 순서와 시각을 저장.
- 계정별 상대 전적은 같은 경기의 반대 진영 계정 기록으로 계산한다. 모드 전적/상대 전적/소리 설정을 탭으로 분리.
- 게임 외 30분 비활동 시 로그아웃. 화면/팝업 전환 애니메이션 및 모션 감소 설정 지원.
- 무료 효과음 12개 후보를 설정 화면에서 듣고 선택 가능. 사용자 제작 음원 파일명은 `AUDIO_FEEDBACK_20261011.md` 참고.

## 검증

- 서버 타입 검사와 계정 연동·채팅 정책·익명 ID/이름/슬롯·상대 전적·채팅 저장 테스트.
- 4개 모드 실제 브라우저: 로그인→대기실→방 만들기→준비→셔플→확인→전투→5초 결과 연출→복기.
- 1366×768 / 1440×1000 / 1920×1080 / 390×844. 메뉴·툴팁 보정, 외부 클릭 유지, 역할 미리 노출 차단, 12칸 배치, 익명 이름, 복기 채팅 이동/불투명도, 이미지 디코딩.
- DB 스키마 변경 없이 기존 경기/참가자/채팅 테이블 사용. 기존 사용자 전적을 그대로 집계한다.

실서비스 배포 여부는 PR/릴리스 상태로 확인한다. 로컬 구현 완료는 운영 서버 교체를 의미하지 않는다.
